# 石矶事件与阐截教派冲突

## 适用场景
- 处理哪吒误杀石矶徒弟的后果
- 描述阐截两派的对峙与谈判
- 执行太乙真人的处理逻辑
- 解释教派火拼的起因

## 事件起因
- 哪吒射出震天箭
- 箭飞数百里落入骷髅山白骨洞
- 凢碎石矶娘娘门人女童身体

## 身份背景

**石矶娘娘：**
- 派系：截教
- 师承：通天教主
- 辈分：与太乙真人同辈

**哪吒：**
- 派系：阐教
- 师承：太乙真人
- 辈分：阐教第三代

## 冲突升级流程

### 1. 追溯阶段
- 石矶通过箭上微雕信息定位
- 抓捕李靖到骷髅山白骨洞

### 2. 对质阶段
- 李靖供出哪吒
- 李靖带哪吒去谢罪

### 3. 交手阶段
- 哪吒与石矶对战
- 法宝被收
- 哪吒逃回乾元山

### 4. 质问阶段
- 石矶追至乾元山
- 质问太乙真人

## 太乙真人处理逻辑

**态度：**
- 阐截两派结怨已久
- 绝不认错
- 推卸责任给"天定"和"劫数"

**行动：**
1. 使用九龙神火罩
2. 将石矶罩住
3. 倒上汽油点火
4. 乱剑刺入
5. 炼化石矶

## 后果
- 石矶死亡
- 截教与阐教矛盾激化
- 引发旷世大火拼

## 变量说明
| 变量 | 类型 | 说明 |
|------|------|------|
| 石矶派系 | String | 截教 |
| 太乙派系 | String | 阐教 |
| 处理手段 | String | 九龙神火罩炼化 |

## 输出结果
石矶死亡，阐截两派全面开战
