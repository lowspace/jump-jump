# 神族封神转化分析

## 使用场景
当遇到以下情况时使用此技能：
- 角色接受封神/位列仙班后行为发生根本性改变
- 分析神仙为何缺乏善恶判断或同理心
- 解释封神过程中的生理或心理改造机制
- 探究"心"与"记忆"的关系设定
- 分析杨戬等特殊角色的例外情况

## 转化分析流程

### 第一步：识别转化主体

检查角色是否符合以下条件：
- **转化前身份**：凡人或妖怪
- **转化触发事件**：接受封神仪式、进入天庭编制
- **目标状态**：位列仙班成为正神

**确认方式**：
```
IF (主体接受封神/进入天庭编制) THEN
    应用无心转化规则
ELSE
    保持原有设定
END
```

### 第二步：分析生理结构改变

评估以下生理特征：
1. **心窍状态**：物理或形而上层面失去"心"
2. **视觉表现**：被封神者看起来没有心窍
3. **心跳特征**：无心跳闪烁，无法通过脉搏检测情绪波动

**结果判断**：
- 心窍存在 = 保留人性/记忆（如杨戬）
- 心窍缺失 = 标准神族/无情状态

### 第三步：评估行为与心理改变

分析转化后的行为特征：

| 维度 | 转化前 | 转化后 |
|------|--------|--------|
| 情感体验 | 有善恶悲喜 | 无情感表现，丧失同理心 |
| 谎言检测 | 说谎时心会闪烁，可被察觉 | 无心跳反应，谎言无法被凡人识破 |
| 道德判断 | 受良知约束 | 遵循"天数"（剧本），作恶无罪 |

### 第四步：判定记忆与身份影响

评估转化代价：

1. **核心风险识别**：
   - 没有心 → 失去情感 → 遗忘重要羁绊
   - 记忆依赖于情感体验的保留

2. **记忆丧失机制**：
   - 重要的人际关系记忆（如亲人、爱人）会随情感一同消失
   - 自我身份认知可能模糊化

3. **关键证据引用**：
   > "若是我也没了心窍，如何还能记着杨婵？如何还能记着我自己？"
   > ——杨戬拒绝封神时的担忧

### 第五步：识别例外情况

检查是否存在以下例外：

**杨戬特例**：
- **特征**：未上天受封，保留心窍
- **后果**：
  - ✓ 保留情感和痛苦感知
  - ✓ 能分辨善恶是非
  - ✗ 无法心安理得地作恶或冷漠
  - ✗ 处于"人"与"神"之间的夹缝状态

## 常见问题排查

### Q: 神仙为何能毫无负罪感地作恶？
A: 因无心导致情感缺失，罪恶感知度为零。遵循"天数"即为正义，行为结果不计入道德评判。

### Q: 如何判断一个角色是否已完成封神转化？
A: 检查三个关键指标：①是否有心窍（生理）；②是否表现出情感波动（心理）；③是否遵循天数行事而无道德负担（行为）。

### Q: 杨戬保留心窍是优势还是劣势？
A: 既是优势也是劣势。优势是保留了人性、记忆和善恶判断；劣势是承受痛苦，无法融入神族体系的无罪化逻辑。
