# 心窍与记忆关联性详细说明

## 记忆形成的生理基础

在这个设定中，记忆的形成和维持与"心"的存在直接相关：

### 1. 情感锚定机制
- 重要记忆需要情感体验作为锚点
- 失去心 → 失去情感体验能力 → 锚点消失 → 记忆消退

### 2. 羁绊记忆的脆弱性

| 记忆类型 | 情感依赖度 | 封神后保留概率 |
|----------|------------|----------------|
| 技能记忆 | 低 | 高（神仙可保留神通法术） |
| 知识记忆 | 中 | 中（部分天数相关知识保留） |
| 羁绊记忆 | 高 | 低（需情感维系，极可能丧失） |
| 自我记忆 | 高 | 低（自我认知依赖情感体验） |

### 3. 杨婵案例分析

杨戬的担忧核心：
- 杨婵是其最重要的情感羁绊
- 若失去心窍，对杨婵的情感会消失
- 没有情感维系，关于杨婵的记忆也会随之淡去
- 最终：既不记得妹妹，也不记得"记得杨婵的自己"

## 剧情应用参考

### 典型对话场景

**场景1**：杨戬拒绝封神
> **姜子牙**："杨戬，只要你点头，便可位列仙班，长生不老。"
> **杨戬**："若是我也没了心窍，如何还能记着杨婵？如何还能记着我自己？"

**场景2**：凡人质问神仙
> **凡人**："你们杀了我的家人，难道没有一丝愧疚吗？"
> **神仙**："此乃天数。吾等心中无悲无喜，何来愧疚？"

### 检测方式对比

| 检测对象 | 情绪激动的生理表现 | 说谎时的特征 |
|----------|-------------------|--------------|
| 凡人 | 心跳加速、面红耳赤 | 心跳闪烁，脉象紊乱 |
| 神仙 | 无明显变化 | 无心跳反应，面无表情 |
| 杨戬（保留心窍） | 有心跳变化 | 心跳闪烁，但可掩饰 |
