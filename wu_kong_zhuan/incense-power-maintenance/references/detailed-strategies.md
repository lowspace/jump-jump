# 逼迫策略详细实施指南

## 灾难制造的具体方法

### 农业领域
- **苗死术**：在播种后或生长期，使秧苗枯萎
- **虫灾术**：释放害虫啃食作物
- **旱涝术**：控制降雨，制造干旱或水涝

### 建筑领域
- **火灾术**：使房屋在建时或建成后起火
- **倒塌术**：使墙体或梁柱突然倒塌
- **地陷术**：使地基下沉，建筑倾斜

### 水路领域
- **翻船术**：使船只突然失去平衡
- **风暴术**：制造局部风暴，打翻渔船
- **暗礁术**：使船只触礁沉没

### 岸边领域
- **洪涌术**：使江水突然涌上岸
- **堤溃术**：使堤坝决口
- **浪卷术**：用巨浪卷走岸边人员

## 苦难指数与香火回报关系

```
香火增量 = 苦难指数 × 0.7 + 恐惧系数 × 0.3
```

- 苦难指数：1-10级，10为毁灭性灾难
- 恐惧系数：0-1，取决于灾难的突然性和不可预测性

## 历史案例

### 土地神的成功实践
- 初始状态：庙宇破败，香火寥寥
- 实施策略：连续制造小规模灾难
- 三个月后：香火旺盛，庙宇翻新
- 一年后：法力充沛，受上级嘉奖

### 杨戬初期的失败教训
- 策略选择：仁慈，不愿利用凡人
- 结果：庙宇破败，香火冷清
- 后果：法力低微，受同僚轻视

## 许愿应答的悖论详解

### 悖论逻辑

1. 应验某人的许愿 → 其他人知道后也会求你
2. 每个人都求你 → 神仙精力有限，无法全部应验
3. 部分应验 → 被视为不公，失去威信
4. 全部应验 → 精力耗尽，法力枯竭

### 唯一解

**全都不理**
- 保持神秘感
- 避免陷入应验循环
- 偶尔的巧合被误认为显灵，维持信仰

## 层级保护机制

### 上级神仙的依赖

- 上级神仙依赖下级神仙聚敛香火
- 下级香火越多，上级分得的灵蕴越多
- 因此上级默许甚至鼓励下级的贪敛行为

### 利益分配

```
上级所得灵蕴 = 下级聚敛灵蕴 × 提成比例
```

通常提成比例为30%-50%，具体取决于层级差距。
