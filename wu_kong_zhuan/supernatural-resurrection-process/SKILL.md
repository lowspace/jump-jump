# 超自然复活机制

## 何时使用
- 角色肉体遭受致命打击或被彻底毁灭
- 角色的象征性物品（如金箍、法宝）与肉体分离并留存
- 需要表现角色超越物理形式的意志力量
- 剧情需要角色以更强精神形态回归的时刻

## 执行流程

### 1. 确认触发条件
检查是否满足以下条件：
- 肉体已被物理毁灭（如被斧劈、血溅、坠落等）
- 象征物已从肉体上脱落并留在原地
- 存在未死的意志或精神本体

### 2. 执行精神显化
- **肉体毁灭**：描述物理身体的终结
- **象征物剥离**：让象征物留在原地，标志肉体形式终结
- **精神显化**：真正的实体以纯粹能量/意志形式显现，不再依附肉体

### 3. 展现超凡力量
通过以下方式表现力量的超越性：
- 敌手看到的只是残留的象征物，本体已消失
- 天空裂开、红光显现等异象，象征打破界限
- 仅凭存在本身（眼神、气场）即可压制敌手，无需物理攻击

### 4. 确认真身回归
- 通过标志性符号（如旗杆上的"齐天大圣"字样）确认身份
- 借助周围角色的震惊反应强化回归效果

## 关键要素

### 变量说明
- **象征物**：束缚与肉体的象征（如金箍），脱落意味着摆脱束缚
- **意志实体**：无法被物理消灭的精神本体，代表着自由与反抗

### 预期结果
无敌的精神实体降临，敌手陷入绝望

## 注意事项
- 强调精神体的纯粹能量形态，避免描述新的物理躯体
- 突出"存在即力量"的意境，而非物理对抗
- 通过环境异象和象征物强化超自然色彩
