# 乾坤弓与震天箭使用规则

## 适用场景
- 描述上古神器的使用过程
- 处理箭矢命中后的因果后果
- 追踪使用者信息
- 解释"例不空发"的绝对规则

## 法宝来源
- 制造者：轩辕黄帝
- 时期：战蚩尤时
- 用途：镇关之宝

## 乾坤弓特性

**材质：**
- 弓身：神木所制，古朴粗重
- 弓弦：上古神兽的筋绷制

**重量：** 沉重如陨铁，常人无法拿动

## 震天箭特性

**数量：** 三支

**材质：**
- 箭翎：如火
- 箭头：铁铸刻成恶兽头状
- 箭杆：用上古恶怪的骨头刻成

**声音特征：** 射出时发出震天呼啸，破空而去，如魔灵直入天际

## 使用铁律

**核心规则：**
> "震天神箭既出，例不空发，必有伤殒。"

**执行机制：**
1. 箭如活物
2. 划破云天
3. 飞数百里
4. 俯冲锁定目标
5. 必定命中并造成死亡

## 追溯机制

**微雕信息（李靖刻制）：**
- 使用者姓名
- 详细地址
- 官职
- 身高体重

**追溯效果：** 一旦射出，失主可被迅速定位

## 变量说明
| 变量 | 类型 | 说明 |
|------|------|------|
| 弓重量 | String | 沉重如陨铁 |
| 箭数量 | Integer | 3 |
| 命中规则 | String | 例不空发，必有伤殒 |

## 输出结果
造成远距离致命击杀，并暴露使用者信息

## 注意事项
- 此因果机制不可逆
- 一旦射出无法收回
