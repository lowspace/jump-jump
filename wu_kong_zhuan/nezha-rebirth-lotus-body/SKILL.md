# 哪吒剔骨还父与莲藕重塑

## 适用场景
- 处理水淹陈塘关危机
- 执行哪吒自杀与剔骨过程
- 执行莲藕重塑仪式
- 描述重塑后的新状态

## 危机背景
- 事件：东海龙王水淹陈塘关
- 目标：灭李靖全族
- 转折：李靖为自保，当众否认哪吒为其子
- 李靖原话：称哪吒为"无父无母的妖孽"

## 自杀决定
**动因：** 哪吒心死，决定独自承担后果
**宗旨：** 断绝世间恩情牵挂
**宣言："取骨还父，割肉还母"**

## 自杀执行步骤

### 第一步：刎颈
- 拔剑刎颈
- 喉管断裂
- 喷血

### 第二步：剔肉
- 举剑将自己血肉一块块剔下

### 第三步：剔骨
- 弃剑
- 拔下左手臂骨
- 剔下肋骨
- 一根根弃于海中

### 第四步：崩散
- 只剩骨骼站立
- 大笑一声
- 身形崩散
- 坠入沧海

## 莲藕重塑过程

### 执行者
太乙真人

### 寻回灵珠
- 太乙真人寻回哪吒灵珠

### 重塑材料
| 材料 | 数量 |
|------|------|
| 莲花 | 2枝 |
| 荷叶 | 3片 |
| 莲藕 | 4节 |

### 催化剂
金丹

### 重塑方法
1. 将材料拼成人形
2. 放上金丹
3. 念念有词
4. 人形坐起

### 记忆处理
- 封印记忆
- 成为只听师父吩咐的"工具人"

## 新状态属性

**身体变化：**
- 不再有热血流动
- 不再有真正的魂魄
- 无法感知世间炎凉
- 成为精美的人偶

## 变量说明
| 变量 | 类型 | 说明 |
|------|------|------|
| 重塑材料 | List | 莲花2枝, 荷叶3片, 莲藕4节 |
| 催化剂 | Item | 金丹 |
| 新属性 | String | 无魂魄, 无情感 |

## 输出结果
旧哪吒死亡，新哪吒（莲藕化身）诞生

## 本质变化
从人到偶
