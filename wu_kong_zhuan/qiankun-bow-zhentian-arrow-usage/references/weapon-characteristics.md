# 乾坤弓与震天箭详细特性

## 法宝来源
轩辕黄帝战蚩尤时留下的镇关之宝。

## 乾坤弓特性

### 材质
- 神木所制
- 古朴粗重

### 重量
- 沉重如陨铁
- 常人无法拿动

### 弓弦
- 上古神兽的筋绷制

## 震天箭特性

### 数量
- 共三支

### 材质
- 箭翎如火
- 箭头铁铸刻成恶兽头状
- 用上古恶怪的骨头刻成

### 声音特征
- 射出时发出震天呼啸
- 破空而去
- 如魔灵直入天际

## 变量参数

| 变量名 | 类型 | 值 | 描述 |
|--------|------|-----|------|
| 弓重量 | String | 沉重如陨铁 | 乾坤弓的重量特征 |
| 箭数量 | Integer | 3 | 震天箭的总数 |
| 命中规则 | String | 例不空发，必有伤殒 | 因果律命中机制 |

## 追溯机制详解

李靖在箭上刻有详细微雕信息：
- 姓名
- 地址
- 官职
- 身高体重

一旦射出，失主可被迅速定位。

## 领域标签
- 法宝规则
- 因果律武器

高（high）
