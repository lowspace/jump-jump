# 哪吒法宝与灵体管理

## 触发条件

判定法宝灵体显现的启发性规则：

```python
IF (哪吒使用法宝) AND (长期杀戮 OR 长期玩耍):
    THEN 触发灵体显现
```

## 核心工作流

### 1. 识别与调用
- 确认当前场景涉及哪吒。
- 区分使用的法宝是**混天绫**还是**乾坤圈**。

### 2. 执行战斗功能
根据战斗需求选择对应法宝：
- **混天绫**：优先用于缠绕束缚，利用其高韧性抗住高手的法力攻击。
- **乾坤圈**：优先用于重击打击，利用其沉重和巨大威力攻击关键部位（如打断龙角）。

### 3. 处理灵体互动
当灵体显现时，遵循以下性格逻辑：
- **红绫**（混天绫灵体）：厌恶杀戮和血腥，性格温和。在血腥场景中应表现出不适或抗拒。
- **圈圈**（乾坤圈灵体）：滑稽且怕痛，喜欢红绫。注意**严禁**称呼其为“圈圈”，可使用“圆圆”、“扭扭”等昵称。

### 4. 执行隐藏协议
- **默认状态**：隐藏状态（`True`）。
- **风险规避**：若周围存在凡人（如李靖）或师父（太乙真人），必须隐藏灵体，否则会被一雷打爆或收去炼丹。

## 输出结果
- 获得两个具有自我意识的法宝伙伴及其在当前场景下的合理表现。
