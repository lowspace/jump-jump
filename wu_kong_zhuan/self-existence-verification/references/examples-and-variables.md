# 示例场景与变量定义

## 变量定义

### unique_identity
- **类型**: String
- **描述**: 个体的名字或唯一标识符
- **示例**: "一片叶子"、"小猴子"

### challenge_target
- **类型**: Object
- **描述**: 用于验证自我能力的极限目标
- **示例**: 瀑布、高处、难以跨越的障碍

## 叙事示例

### 场景一：叶子的存在焦虑
一片叶子在风中飘荡，突然意识到自己不是其他叶子，产生了"怕忘了自己"的恐惧。它选择**路径A**，寻找松鼠，要求松鼠叫它的名字，当松鼠回应时，叶子安心地睡着了。

### 场景二：猴子的自我挑战
一只猴子在瀑布前，感受到自己与群体的不同。它选择**路径B**，设定跳过瀑布的目标。虽然一次次跳入潭中失败，但通过"我在努力"的过程，它验证了自己的存在，获得了快乐。

## 约束条件

- 验证方式因个体性格而异（被动确认 vs 主动挑战）
- 必须基于真实的自我意识觉醒，而非单纯的模仿行为
