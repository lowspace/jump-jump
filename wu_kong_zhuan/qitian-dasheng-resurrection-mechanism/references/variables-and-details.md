# 关键变量定义

## 金箍
- **类型**: Object
- **描述**: 束缚与肉体的象征。
- **作用**: 脱落意味着摆脱物理束缚和规则限制，标志着肉体形式的终结。

## 齐天大圣意志
- **类型**: Entity
- **描述**: 无法被物理消灭的精神本体，代表着自由与反抗。
- **作用**: 复活的核心驱动力，是唯一真实的“本体”。

# 场景细节参考

## 肉体毁灭阶段
- 物理打击：斧劈、血溅、高空坠落。
- 结果：物理形态彻底崩溃。

## 显化阶段
- 敌人视角：只能看到金箍，本体消失。
- 环境变化：天空裂开，红光显现。
- 力量表现：眼神压制，敌手绝望。

## 结果状态
- 敌手状态：绝望。
- 自身状态：无敌的精神实体降临。
- 认知确认：通过旗杆文字“齐天大圣”和众妖反应确认真身。
