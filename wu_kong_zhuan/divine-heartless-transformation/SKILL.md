# 神族无心异化分析

## 使用场景

在以下情况时使用此技能：
- 分析凡人或妖怪接受封神后的状态变化
- 理解天庭众神的情感缺失特征
- 评估封神对记忆和身份的影响
- 判断角色是否保留人性（如杨戬）
- 解释神族为何能心安理得地作恶

## 核心分析流程

### 1. 识别封神状态

检查角色是否符合以下条件：
- 已通过封神仪式
- 位列仙班，进入天庭编制

**注意**：杨戬等特殊个体除外，他们未正式受封。

### 2. 生理结构分析

确认无心特征：
- 物理或形而上层面没有"心"
- 视觉特征：心窍消失
- 生理表现：心跳闪烁特征消失（无法通过心跳判断是否说谎）

### 3. 心理与行为评估

评估以下维度：

**情感状态**：
- 丧失善恶悲喜的感知
- 缺乏同理心
- 无法体验痛苦

**道德判断**：
- 只要按"天数"（剧本）行事，无论作恶多少都无罪
- 可获得封赏且无心理负担

**说谎能力**：
- 凡人说谎时心会闪烁，易被察觉
- 神族无心，说谎时无生理特征，无法被看穿

### 4. 记忆与身份代价评估

**核心风险**：
- 失去心后，会忘记过去的重要羁绊
- 自我身份认知逐渐模糊
- 人性情感完全剥离

**评估问题**：
- 角色是否还能记起重要的人？
- 角色是否还能记起"我自己"是谁？

### 5. 例外情况识别

**杨戬案例**：
- 未上天受封，保留了心窍
- 保留了情感和痛苦感
- 能分辨善恶
- 无法像其他神那样心安理得地作恶或冷漠

## 关键变量

| 变量 | 类型 | 说明 |
|------|------|------|
| 心窍存在性 | Boolean | True=保留人性/记忆；False=成为标准神族/无情 |
| 罪恶感知度 | Level | 无心神族对自身罪恶的感知度为零 |

## 输出结果

提供以下信息：
1. 角色的生理状态（有心/无心）
2. 情感能力评估
3. 记忆与身份保留程度
4. 道德判断能力
5. 是否属于例外情况

## 典型应用示例

**场景**：分析榜上诸神的状态

**分析步骤**：
1. 确认已通过封神仪式 ✓
2. 生理检查：无心窍 ✓
3. 情感评估：无善恶悲喜 ✓
4. 记忆评估：可能已忘记凡间羁绊
5. 结论：标准神族状态，无情无感

**场景**：分析杨戬的特殊性

**分析步骤**：
1. 确认封神状态：未正式受封
2. 生理检查：保留心窍
3. 情感评估：保留痛苦和善恶感
4. 记忆评估：能记住杨婵和自我
5. 结论：例外个体，保留人性
