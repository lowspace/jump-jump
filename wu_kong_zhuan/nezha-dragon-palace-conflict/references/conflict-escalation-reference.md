# 冲突升级流程

## 第一阶段：环境震荡
- 哪吒洗法宝
- 水波震荡
- 龙宫受影响

## 第二阶段：质问与反击
- 夜叉质问
- 哪吒反击
- 夜叉死亡

## 第三阶段：主将对决
- 敖丙现身
- 双方交战
- 敖丙死亡

## 第四阶段：战利品获取
- 拖尸上岸
- 剥鳞抽筋
- 获取龙筋

## 后果链
1. 龙族死亡
2. 获得龙筋
3. 龙王复仇
4. 哪吒面临更大危机
