# 哪吒龙宫冲突处理

## 使用时机
当满足以下任一条件时使用此技能：
- 哪吒在东海海边清洗法宝（混天绫、乾坤圈）
- 东海龙族阻碍哪吒的活动
- 哪吒需要龙筋作为礼物或战利品
- 龙宫因哪吒行为发生震动

## 前置条件
- 哪吒持有法宝：混天绫、乾坤圈、火尖枪
- 哪吒信奉天定劫数论（心理基础）
- 地点位于东海海域

## 执行流程

### 第一阶段：触发事件
1. 哪吒在海边晃动清洗混天绫和乾坤圈
2. 水波震荡达及深海，引得东海龙宫摇晃

### 第二阶段：初次冲突
1. 巡海夜叉质问哪吒
2. 哪吒使用乾坤圈将夜叉打死（特征：满脸桃花开）

### 第三阶段：主战对决
**敖丙技能：**
- 现出真身（苍龙）
- 搅起数十丈高水墙
- 巨浪吞没陆地

**哪吒技能：**
- 混天绫缠枪
- 乾坤圈击碎护心镜
- 火尖枪穿透胸膛

### 第四阶段：战后处理
1. 三太子被杀，化为龙形，血染数十里
2. 将龙尸拖上岸
3. 剥开龙鳞
4. 抽取龙筋

## 变量定义

| 变量名 | 类型 | 描述 |
|--------|------|------|
| 受害者1 | Entity | 巡海夜叉 |
| 受害者2 | Entity | 敖丙（龙王三太子）|
| 战利品 | Item | 龙筋 |

## 结果模板
```
龙族死亡，获得龙筋，引发龙王复仇
```

## 心理逻辑

### 表面理由
- 龙鳞龙筋是罕有之物
- 要给李靖做战甲和束带
- 希望父亲原谅自己

### 心理借口
- 师父说一切都是天定的劫数
- 龙死是它该着死
- 自己没有错

## 约束条件
- 哪吒必须信奉天定劫数论
- 行为具有残忍性特征
- 不考虑龙族的情感和反应

## 注意事项
- 此技能涉及暴力行为，需谨慎评估使用场景
- 结果将引发龙王复仇的连锁反应
- 龙筋作为战利品可用于制作装备
