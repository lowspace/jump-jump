# 哪吒重塑流程

## 使用场景
- 需要处理哪吒自杀情节
- 需要断绝亲子血缘关系
- 需要执行莲藕重塑身体
- 需要封印记忆并改变人物属性

## 核心流程

### 1. 确认危机背景
检查是否满足条件：
- 父亲当众否认父子关系
- 为保护父母/全族需独自承担后果
- 已无其他解决途径

### 2. 执行自杀决定

#### 2.1 表明决心
- 提出"取骨还父，割肉还母"
- 断绝世间恩情牵挂

#### 2.2 执行剔骨过程
按以下步骤执行：
1. **拔剑刎颈**：喉管断裂，喷血
2. **剔下血肉**：举剑将自己血肉一块块剔下
3. **弃剑**：放下武器
4. **剔下臂骨**：拔下左手臂骨
5. **剔下肋骨**：一根根剔下
6. **弃骨入海**：将骨头一根根弃于海中
7. **身形崩散**：只剩骨骼站立，大笑一声
8. **坠入沧海**：身形散开，坠入海中

### 3. 执行重塑过程

#### 3.1 寻回灵珠
- 执行者：太乙真人
- 寻回哪吒的灵珠

#### 3.2 准备材料
- **莲花**：两枝
- **荷叶**：三片
- **莲藕**：四节
- **催化剂**：金丹

#### 3.3 执行重塑
1. 将材料拼成人形
2. 放上金丹
3. 念念有词
4. 人形坐起

#### 3.4 封印记忆
- 封印原有记忆
- 成为只听师父吩咐的"工具人"

### 4. 确认新状态

#### 身体变化
- 身体里不再有热血流动
- 不再有真正的魂魄
- 无法感知世间炎凉
- 成为精美的人偶

#### 性格变化
- 无情感
- 无独立意志
- 绝对服从师父

## 关键变量
| 变量 | 值 | 说明 |
|------|-----|------|
| 重塑材料 | 莲花2枝, 荷叶3片, 莲藕4节 | 植物材料 |
| 催化剂 | 金丹 | 太乙真人提供 |
| 新属性 | 无魂魄, 无情感 | 从人到偶 |

## 注意事项
- 自杀过程极其惨烈，需详细描述
- 重塑后人物本质发生根本改变
- 新哪吒是"工具人"而非原有人格
- 整个过程带有强烈的悲剧色彩
