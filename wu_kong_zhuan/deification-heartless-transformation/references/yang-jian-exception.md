# 杨戬特殊案例分析

## 背景信息
杨戬是封神体系中的特殊个体，他拒绝上天受封，保留了完整的人性和情感。

## 保留的特征
- **心窍存在**：保留了"心"，能感受痛苦
- **情感完整**：能分辨善恶，有同理心
- **记忆保留**：能记着杨婵等重要羁绊
- **道德判断**：无法像其他神那样心安理得地作恶

## 杨戬的担忧
> "若是我也没了心窍，如何还能记着杨婵？如何还能记着我自己？"

这句话揭示了封神异化的核心代价：失去心窍意味着失去记忆和自我认同。

## 与标准神族的对比

| 特征 | 标准神族 | 杨戬 |
|------|----------|------|
| 心窍 | 无 | 有 |
| 情感 | 无 | 有 |
| 痛苦感 | 无 | 有 |
| 善恶判断 | 无 | 有 |
| 道德负罪感 | 无 | 有 |
| 记忆保留 | 风险 | 完整 |

## 设定意义
杨戬的存在证明了封神异化是可逆的或可选择的，同时也突显了"无心"状态对个体本质的根本性改变。
