# 封神异化机制分析

## 使用场景
当需要：
- 分析神仙或天庭众神的生理特征和行为模式
- 判断角色是否已接受封神或进入天庭编制
- 理解神族为何能心安理得地作恶
- 分析封神对记忆和身份的影响
- 处理涉及杨戬等特殊案例的设定

## 核心识别特征

### 生理特征
- **心窍缺失**：被封神者在物理或形而上层面没有"心"
- **视觉表现**：榜上诸神看起来都没了心窍
- **谎言隐匿**：说谎时无心跳闪烁，凡人无法察觉

### 心理特征
- **情感缺失**：看不出善恶悲喜，丧失同理心
- **罪恶感知度为零**：无论作恶多少都无负罪感
- **道德豁免**：按"天数"（剧本）行事即无罪

## 执行流程

### 1. 识别封神状态
检查角色是否符合以下条件：
- 已通过封神仪式
- 位列仙班
- 进入天庭编制

### 2. 评估异化程度

**标准神族（完全异化）**：
- 心窍存在性 = False
- 罪恶感知度 = 0
- 情感/人性 = 丧失
- 记忆保留 = 风险（可能遗忘重要羁绊）

**特殊个体（部分异化）**：
- 杨戬：未上天受封，保留心窍、情感和痛苦
- 能分辨善恶，无法心安理得作恶

### 3. 分析行为逻辑

**无心神族的行为模式**：
- 无情感驱动，仅按"天数"行事
- 无道德约束，杀戮无负罪感
- 说谎无生理反应，无法被看穿

### 4. 评估代价

**核心风险**：
- 一旦失去心窍（情感/人性），会忘记过去的重要羁绊
- 丧失自我记忆和身份认同

## 关键判断规则

**IF** (凡人或妖怪接受封神/进入天庭编制)
**THEN** (生理改造：失去心/情感)

**例外判断**：
- 杨戬等特殊个体保留人心和痛苦感
- 需单独分析其行为动机和道德判断

## 输出结果
转化为标准的、无情的、无法被看穿谎言的神族，代价是丧失自我记忆和人性情感。
