# 创伤背景参考

## 孙悟空创伤背景

### 五百年山下监禁
- 孙悟空被如来佛祖压在五行山下五百年
- 期间无法动弹，承受孤独与饥饿
- 此经历形成深层心理创伤

### 紧箍咒痕迹
- 观音菩萨为唐僧传授紧箍咒
- 紧箍咒勒紧时造成剧烈头痛
- 留下身体和心理双重阴影

## 队友关系动态

### 猪八戒和沙僧的敌对反应原因
- 对孙悟空过去经历的复杂性感到不安
- "想当年"等词汇可能唤起团队的不和谐回忆
- 倾向于通过暴力行为终止相关话题

## 触发词汇敏感性排序

1. **高敏感度**："五百年前" - 直接关联监禁经历
2. **中敏感度**："想当年" - 暗示过往荣耀或痛苦
3. **中敏感度**："压在山底" - 具体场景回忆
4. **低敏感度**："花果山" - 家乡记忆（可能触发复杂情感）
