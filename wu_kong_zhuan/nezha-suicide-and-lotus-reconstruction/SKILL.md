# 哪吒剔骨还父与莲藕重塑

## 使用场景
- 处理哪吒为不连累父母而自杀的场景
- 执行"取骨还父，割肉还母"仪式
- 使用莲藕材料重塑肉身的过程
- 分析重塑后"工具人"属性的转变

## 执行步骤

### 1. 确认触发条件
- 父亲公开否认父子关系（称其"无父无母的妖孽"）
- 外部威胁危及全族（东海龙王水淹陈塘关）
- 主角心死，决定独自承担后果

### 2. 执行剔骨还父仪式

**第一步：刎颈**
- 拔剑刎颈
- 喉管断裂，喷血

**第二步：剔肉**
- 举剑将血肉一块块剔下

**第三步：剔骨**
- 弃剑，拔下左手臂骨
- 剔下肋骨
- 一根根弃于海中

**第四步：崩散**
- 只剩骨骼站立
- 大笑一声
- 身形崩散，坠入沧海

### 3. 执行莲藕重塑

**准备工作：**
- 寻回灵珠

**材料清单：**
- 莲花：2枝
- 荷叶：3片
- 莲藕：4节
- 催化剂：金丹

**重塑方法：**
1. 将材料拼成人形
2. 放上金丹
3. 念念有词施法
4. 人形坐起，重塑完成

### 4. 确认新状态
- 记忆被封印
- 成为只听师父吩咐的"工具人"
- 身体内不再有热血流动
- 没有真正的魂魄
- 无法感知世间炎凉
- 成为精美的人偶

## 关键变化
| 属性 | 旧哪吒 | 新哪吒 |
|------|--------|--------|
| 构成 | 血肉之躯 | 莲藕化身 |
| 魂魄 | 有 | 无 |
| 情感 | 有 | 无 |
| 性质 | 人 | 偶 |
| 血液 | 热血 | 无 |

## 注意事项
- 此过程必须彻底切断与父母的血缘联系
- 重塑后的哪吒不再具备自主情感
- 记忆封印确保其成为完全的工具
- 象征意义：从人向偶的堕落
