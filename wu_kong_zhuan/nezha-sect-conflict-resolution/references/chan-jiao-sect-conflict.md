# 阐截教派冲突详细背景

## 教派对立关系

### 阐教（Chan Jiao）
- **教主**：元始天尊
- **代表人物**：太乙真人、文殊广法天尊、普贤真人
- **特点**：正统、精英主义、与佛家关系密切

### 截教（Jiao Jiao）
- **教主**：通天教主
- **代表人物**：石矶娘娘、多宝道人
- **特点**：收徒广泛、包容性强、被阐教视为旁门左道

## 冲突升级时间线

```
哪吒射箭 → 击中石矶徒弟 → 石矶追查 → 抓捕李靖 →
李靖供出哪吒 → 哪吒谢罪 → 交手败逃 → 石矶追至乾元山 →
太乙真人出面 → 拒不认错 → 使用九龙神火罩 → 炼化石矶
```

## 九龙神火罩详解

**使用方法**：
1. 将目标罩住
2. 倒入汽油（助燃剂）
3. 点火焚烧
4. 乱剑刺入（确保彻底消灭）

**效果**：
- 物理毁灭
- 灵魂炼化
- 无法复活

## 冲突的深层原因

1. **历史积怨**：阐截两派长期对立
2. **教派利益**：维护本派声誉和地位
3. **权力斗争**：封神大劫的前奏
4. **意识形态**：精英主义 vs 包容主义

此事件揭示：
- 教派利益高于人命
- 长辈的过错由晚辈承担
- "天定"和"劫数"成为推卸责任的借口
