# 乾坤弓与震天箭详细规格

## 1. 法宝来源
- **历史背景**：轩辕黄帝战蚩尤时留下的镇关之宝。

## 2. 乾坤弓特性
- **材质**：神木所制，古朴粗重。
- **重量**：沉重如陨铁，常人无法拿动。
- **弓弦**：上古神兽的筋绷制。

## 3. 震天箭特性
- **数量**：三支。
- **材质**：
  - 箭翎：如火般赤红。
  - 箭头：铁铸，刻成恶兽头状。
  - 箭骨：用上古恶怪的骨头刻成。
- **声效**：射出时发出震天呼啸，破空而去，如魔灵直入天际。

## 4. 追溯微雕细节
- **雕刻内容**：李靖在箭上刻有极其微小的文字信息。
- **信息字段**：包含使用者的完整姓名、详细地址、官职、精确身高体重等。
- **技术难度**：微雕精度极高，需仔细辨认才能读取，但一旦被有心人获取，可迅速定位失主。
