# 创伤触发详细参考

## 变量说明
- **trigger_type**: 触发类型（Head_Touch, Memory_Triggers, Visual_Trauma）
- **memory_fragment**: 导致创伤的具体记忆片段（如五行山、花果山）
- **成佛**: 获取无上力量的途径，但最终变成了维护秩序的界限
- **对力量的恐惧**: 对自己力量所代表的破坏性或失控的惧怕

## 团队反应模式

### 猪八戒和沙僧的敌对反应
- 对提及孙悟空过去的特定词汇有敌对反应
- 立即发起物理攻击
- 这表明团队对孙悟空的过去有共同的心理阴影

## 心理状态演变

### 正常状态
- 能够正常战斗和互动

### 触发状态
- 头部接触：立即攻击反应
- 记忆触发：挑衅或陷入痛苦
- 场景联想：身体崩溃、幻觉

### 恢复状态
- 苍老虚弱
- 仿佛耗尽生命

## 战斗心理分析

### 失败原因
- 不是力量不足
- 是害怕自己的力量
- 无法全力施为

### 内在冲突
- 想要打破界限
- 最终变成界限本身
- 害怕力量的破坏性
