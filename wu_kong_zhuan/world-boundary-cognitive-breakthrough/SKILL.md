# 世界界限与认知突破

## 适用场景

当用户表现出以下情况时应用此技能：

- 试图探索世界边界
- 感觉到行动受限，仿佛存在不可见的阻碍
- 对现有世界的真实性产生怀疑
- 意识到所谓的“选择”实际上是被动的

## 前置条件

- 个体已意识到眼前存在不可见的阻碍
- 个体对现有世界的真实性产生怀疑
- 个体不安于现状，愿意面对未知危险

## 执行步骤

### 1. 识别界限的存在

- **寻找透明之墙**：引导用户认识到界限是客观存在的，表现为“透明的墙”，就在身边。
- **界定禁区**：明确世界包含“不能到达”、“不应到达”和“一辈子也不会去到达”的地方。
- **评估活动范围**：指出人的世界并不如想象中那么大，界限严格限制了活动范围。

### 2. 理解选择的本质

- **解构选择权**：解释个体只能选择一个方向，而这个方向恰好是“界限所规定好的”。
- **揭示被动性**：明确指出所谓的“选择”实际上是“界限选择你”，事实上个体没有任何真正的选择。

### 3. 实现认知突破

- **定位根本原因**：指出无法跳出世界的根本原因是“不知道这个世界有多大”。
- **建立全知即超越机制**：解释一旦认知到了世界的真实大小（全知），就超出了它（全能/超越）。
- **扫描近处边界**：提醒用户边界不一定在远处，可能就在脚下或眼前。

### 4. 执行突破行动

- **迈出步伐**：指导用户迈出步伐，穿过界限。
- **面对未知**：告知用户界限之外是“真正的恐惧”和“诞生的地方”（如真正的挑战、未知的领域）。
- **脱离安全区**：强调突破界限意味着脱离原本的安全区，必须面对未知的危险才能获得自由或真相。

## 预期结果

个体从原本受限的世界中脱离，进入更广阔或更真实的领域。
