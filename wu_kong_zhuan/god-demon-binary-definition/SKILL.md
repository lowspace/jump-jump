# 神与妖的二元定义

## 适用场景
- 区分神仙与妖精的本质属性
- 分析妖精的生存困境和命运
- 探讨异类存在的合理性问题
- 构建或理解世界观中的秩序与混乱关系

## 核心定义

### 神的定义
神是创造天地、为万物定性的存在。神建立了世界的秩序，决定了"什么是什​​么"。

### 妖的定义
妖是谬误所生，因意外而得以存在的生命。妖不属于神的初始设计，是秩序之外的"错误"。

## 妖的生存困境（二律背反）

妖的存在面临无法调和的矛盾：

**路径A：试图成为符合天理的东西**
- 行为：反抗神的定义，寻求合理化
- 结果：变得不合理，被视为魔
- 原因：妖的本质就是"错误"，强行合理化反而违背自身

**路径B：顺从神的定义**
- 行为：接受自己"不该存在"的事实
- 结果：理应被消灭
- 原因：神创造天地时没有预设妖的存在

## 分类流程

1. **检查起源**
   - 如果是神创造天地时的设计 → 神仙
   - 如果是意外、谬误产生 → 妖精/异类

2. **分析生存状态**
   - 试图反抗定义、寻求合理化 → 堕落为魔
   - 顺从定义、接受命运 → 等待被消灭

3. **确定本质属性**
   - 神仙：秩序的建立者
   - 妖精：秩序的错误
   - 结论：妖的本质就是"错误"，无论反抗还是顺从，命运都是被抹去

## 关键变量

- **神的秩序**：对万物属性和命运的固定定义
- **妖的谬误**：因意外产生、扰乱既定秩序的存在属性

## 约束条件
- 不适用于混沌未开的世界
- 需要世界观中存在既定的秩序与定义
