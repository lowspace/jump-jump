# 神族封神转化分析

## 使用场景
当需要分析或描写以下情况时使用此技能：
- 凡人或妖怪接受封神、位列仙班
- 角色进入天庭编制后的行为与心理变化
- 讨论"无心"神族的特征与能力
- 评估封神的代价与后果
- 分析神说谎的隐匿能力

## 核心转化规则

### 触发条件
IF (凡人或妖怪接受封神/进入天庭编制) THEN (执行转化：失去心/情感)

### 转化流程

#### 1. 生理结构改造
- **心窍移除**：在物理或形而上层面移除"心"
- **视觉特征**：被封神者（榜上诸神）失去心窍，外观表现为无心状态
- **检测失效**：因无心跳，无法通过心跳判断是否说谎

#### 2. 行为与心理改变
- **情感缺失**：丧失善恶悲喜之分，完全丧失同理心
- **谎言隐匿**：说谎时无生理反应，凡人无法察觉（对比凡人说谎时心会闪烁）
- **道德豁免**：只要按"天数"（剧本）行事，所作恶行皆无罪且可获封赏

#### 3. 代价与风险
- **记忆剥离**：失去心后，逐渐遗忘过去的重要羁绊
- **身份丧失**：无法记住自己曾经的身份与关系
- **人性丧失**：完全变成标准神族，失去作为"人"的特质

#### 4. 例外情况识别
- 检查是否存在特殊个体（如杨戬）
- 验证是否正式接受天庭编制
- 评估是否保留了情感和痛苦感知能力

## 分析要点

### 转化完成度评估
检查以下指标以确认转化状态：
- [ ] 心窍存在性：False = 标准神族；True = 未完全转化
- [ ] 罪恶感知度：Level 0 = 完全豁免；Level > 0 = 保留良知
- [ ] 情感反应能力：无 = 成功转化；有 = 转化失败或例外

### 行为特征观察
- 是否表现出明显的善恶判断
- 对过往提及的反应是否冷漠
- 说谎时是否有生理特征可察
- 对残酷行为是否表现出心理负担

## 变量参数

| 变量名 | 类型 | 描述 |
|--------|------|------|
| 心窍存在性 | Boolean | True=保留人性/记忆；False=成为标准神族/无情 |
| 罪恶感知度 | Level | 无心神族对自身罪恶的感知度为零 |

## 转化结果

**标准结果**：转化为标准的、无情的、无法被看穿谎言的神族

**代价**：丧失自我记忆和人性情感

**获得能力**：道德豁免（按天数行事无需承担道德责任）、谎言隐匿
