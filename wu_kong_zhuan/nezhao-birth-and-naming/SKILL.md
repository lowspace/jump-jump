# 哪吒出生与命名处理

## 使用场景
- 婴儿出生为肉球而非正常人类
- 太乙真人要求赐名
- 需要解释为何哪吒不按五行规律命名
- 分析太乙真人拒绝"水吒"的真实原因

## 执行步骤

### 1. 确认出生异常
- 检查母亲怀孕时长（正常应为三年零六个月）
- 确认出生形态为鲜红肉球
- 记录肉球被劈开后的婴儿状态（额上留有伤痕）

### 2. 确定师承关系
- 确认太乙真人前来收徒
- 明确哪吒为太乙真人弟子

### 3. 执行命名逻辑推演

**常规五行规律：**
- 长子：金吒（金），拜入文殊门下
- 次子：木吒（木），拜入普贤门下
- 按五行排序，三子应为：水吒（水）

**太乙真人的拒绝理由：**
1. 作为道士不愿随佛家起梵语名字
2. 不愿按五行规矩
3. 决定"乱起一气"

### 4. 最终命名
- 定名为：哪吒
- 对外解释："此乃天机，不可泄露"

## 关键变量
| 变量 | 值 |
|------|-----|
| 长子名 | 金吒 |
| 次子名 | 木吒 |
| 五行规律 | 金木水火土 |
| 三子名 | 哪吒 |

## 输出结果
获得名字：哪吒
