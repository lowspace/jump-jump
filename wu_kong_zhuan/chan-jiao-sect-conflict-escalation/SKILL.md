# 阐截教派冲突升级处理

## 使用场景
- 处理阐教门人（哪吒）误杀截教门人引发的冲突
- 分析太乙真人面对截教寻仇的处理逻辑
- 理解教派利益高于人命的处理原则
- 追溯阐截两派全面开战的起因

## 执行步骤

### 1. 确认事件起因
- 识别肇事者及其教派归属（哪吒 - 阐教第三代）
- 识别受害者及其教派归属（石矶门人 - 截教）
- 追踪事件触发物（震天箭上的微雕信息）

### 2. 分析身份背景
```
石矶娘娘
├─ 派系：截教
├─ 师父：通天教主
└─ 辈分：与太乙真人同辈

哪吒
├─ 派系：阐教
├─ 师父：太乙真人
└─ 辈分：第三代弟子
```

### 3. 追踪冲突升级路径
1. **初步追责**：石矶通过微雕信息抓捕李靖
2. **供认**：李靖供出哪吒，带哪吒去谢罪
3. **交手**：哪吒与石矶交手，法宝被收，逃回乾元山
4. **追击**：石矶追至乾元山，质问太乙真人

### 4. 分析太乙真人的处理逻辑

**态度：**
- 阐截两派结怨已久，绝不认错
- 将责任推卸给"天定"和"劫数"

**处理手段：**
- 使用九龙神火罩罩住石矶
- 倒上汽油点火
- 乱剑刺入
- 彻底炼化石矶（不留活口）

### 5. 评估后果
- 直接导致截教与阐教矛盾激化
- 引发旷世大火拼
- 体现"教派利益高于人命"的意识形态

## 核心原则
- 教派冲突中，不对等辈分（太乙真人 vs 石矶）可以直接动手
- 处理对方寻仇时，采取斩草除根策略
- 一切冲突可归结为"劫数"，避免承认个人责任
