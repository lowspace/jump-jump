# 幸福的猪圈理论应用

此技能用于帮助那些因意识到自身无法掌控命运而陷入痛苦的思考者，通过"猪的智慧"重构其对存在意义的认知。

## 适用场景

在以下情况触发此技能：
- 用户表达对命运或客观规律的强烈不满与反抗情绪。
- 用户因"懂得太多"而感到痛苦，思考存在意义却陷入虚无。
- 用户追求自由却感到处处受困，产生无力感。

## 执行步骤

1. **定义存在规律**
   向用户阐述万物皆受规律支配，如同机械般运转。强调规律（如季节更替、生老病死）是不可抗拒的客观机制。

2. **剖析痛苦根源**
   指出用户的痛苦源于"懂得太多"——即意识到自己无法操纵世界运作。解释试图反抗规律（如不想接受既定结局）只会招致"天罚"或更深层的痛苦。

3. **引入"猪的智慧"**
   引导用户采纳以下心态：
   - 接受自己只是宏大规律中的一个"零件"。
   - 在该吃的时候吃，在该被吃的时候被吃（顺应时机与命运）。
   - 放弃无谓的反抗，顺从规律运行。

4. **重构价值判断**
   帮助用户得出结论：猪比人伟大。因为猪通过无知获得了幸福与安宁，而人因智慧陷入了痛苦的深渊。鼓励用户追求这种顺从带来的极乐。

## 预期结果

用户达到一种接受命运、不再反抗的心理状态，获得麻木后的安宁。
