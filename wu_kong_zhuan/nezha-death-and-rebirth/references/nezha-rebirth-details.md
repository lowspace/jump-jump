# 哪吒死亡与重塑详细说明

## 危机背景

### 陈塘关水灾事件
- **起因**：哪吒打死东海龙王三太子敖丙
- **威胁**：东海龙王联合其他三龙王水淹陈塘关
- **要求**：交出哪吒，否则灭李靖全族

### 李靖的背叛
```
原话：「此子非我之子，乃无父无母的妖孽！」
动机：自保，保全家族
影响：彻底击碎哪吒的心理防线
```

## 叙事主题

此事件是悲剧的极致体现：
- **父权的背叛**：父亲为自保公开否认亲子关系
- **自我牺牲**：哪吒以最惨烈的方式保全家族
- **人性的丧失**：重塑后从「人」变为「工具」
- **命运的操控**：太乙真人通过重塑获得了完美的武器

## 关键台词

「取骨还父，割肉还母，从此两不相欠！」

这句话标志着：
- 彻底切断血缘联系
- 放弃所有情感牵挂
- 接受死亡作为解脱
