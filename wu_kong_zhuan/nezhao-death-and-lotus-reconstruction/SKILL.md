# 哪吒死亡与莲藕重塑

## 使用场景
- 父亲否认父子关系
- 需要断绝与父母的血缘联系
- 处理哪吒自杀事件
- 执行莲藕化身重塑
- 分析从人到偶的转变

## 执行步骤

### 1. 确认危机背景
- 确认东海龙王水淹陈塘关
- 确认龙王要灭李靖全族
- 确认李靖当众否认哪吒为其子
- 确认李靖称哪吒为"无父无母的妖孽"

### 2. 执行自杀决定
**动机：**
- 心死，独自承担后果
- 提出"取骨还父，割肉还母"
- 断绝世间恩情牵挂

**自杀过程：**
1. 拔剑刎颈，喉管断裂，喷血
2. 举剑将自己血肉一块块剔下
3. 弃剑，拔下左手臂骨，剔下肋骨
4. 将骨头一根根弃于海中
5. 只剩骨骼站立，大笑一声
6. 身形崩散，坠入沧海

### 3. 执行重塑过程（莲藕化身）

**执行者：** 太乙真人

**材料准备：**
- 莲花：2枝
- 荷叶：3片
- 莲藕：4节
- 金丹：1颗（催化剂）

**重塑方法：**
1. 太乙真人寻回灵珠
2. 将莲花、荷叶、莲藕拼成人形
3. 放上金丹
4. 念念有词

### 4. 确认新状态
- 人形坐起
- 记忆被封印
- 成为只听师父吩咐的"工具人"
- 身体里不再有热血流动
- 不再有真正的魂魄
- 无法感知世间炎凉
- 成为精美的人偶

## 关键变量
| 变量 | 值 |
|------|-----|
| 重塑材料 | 莲花2枝, 荷叶3片, 莲藕4节 |
| 催化剂 | 金丹 |
| 新属性 | 无魂魄, 无情感 |

## 输出结果
旧哪吒死亡，新哪吒（莲藕化身）诞生
