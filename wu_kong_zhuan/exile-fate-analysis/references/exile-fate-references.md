# 流放者命运分析 - 参考资料与详细说明

## 核心变量定义

### 变量 1: 来时的路
- **类型**: Path
- **描述**: 通往过去家园或原始状态的路径
- **意义**: 对流放者而言，这是物理与精神层面的双重阻断。即使物理路径存在，心理路径也已断裂。

### 变量 2: 过去的家园
- **类型**: Location
- **描述**: 个体记忆中归属的物理或精神空间
- **意义**: 流放者执着的目标，但该对象在现实中已发生不可逆的改变或消亡。

## 典型案例分析

### 案例背景：白晶晶
- **角色定位**: 妖精/被边缘化的群体
- **行为表现**: 等待与寻找
- **结局**: 在等待中妖精化，最终在孤独中消亡
- **符合逻辑**: 符合“会死在某一个角落”的流放者宿命

### 对比案例：唐僧
- **心态**: “任何一个地方都是家” 或 “一无所有（无牵挂）”
- **区别**: 
  - 唐僧不执着于物理空间上的“家”
  - 接受无常，不尝试找回“永远失去”的东西
  - 因此不属于流放者，不受流放者宿命束缚

## 哲学背景

### 存在主义视角
流放者体现了存在主义中关于“归属感缺失”与“意义构建失败”的困境。他们的悲剧在于试图在一个变化的世界中寻找永恒不变的锚点（过去的家园）。

### 宿命论视角
流放者的结局具有必然性：
1. 拒绝接受失去 -> 2. 试图回归 -> 3. 路径与家园的双重消亡 -> 4. 漫流浪直至死亡

## 排除标准

以下情况**不适用**本技能：
- 主动选择流浪的游牧者
- 具有高度适应性、能迅速建立新归属感的个体
- 完全抹杀过去记忆的人（流放者的特征是“记得并执着”）
