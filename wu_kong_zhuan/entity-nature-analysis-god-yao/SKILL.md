# 实体本质分析：神与妖的二元定义

## 适用场景
当遇到以下情况时，应用此技能：
- 需要明确角色属于“神仙”、“妖精”或“异类”的根本属性
- 探讨“妖”为何生存艰难或其存在的哲学矛盾
- 分析角色在既定天理秩序下的必然结局
- 构建或解析存在“既定秩序”的世界观背景

## 分析步骤

### 1. 确认实体起源
根据对象在世界观中的诞生方式，判断其本质：

- **神（秩序创造者）**：创造天地，为万物定义“它们是什么”，建立并维护既定秩序。
- **妖（谬误产物）**：因意外而得以存在，不属于神的初始设计，是秩序之外的东西。

### 2. 定义核心变量
- **神的秩序**：系统对万物属性和命运的固定定义。
- **妖的谬误**：对象因意外产生、扰乱既定秩序的存在属性。

### 3. 推演生存困境（二律背反）
对于被认定为“妖”的实体，分析其面对“神的秩序”时的两种必然路径及结果：

- **路径A：反抗神的定义**
  - **行为**：试图通过修炼或抗争，让自己成为符合“天理”的东西。
  - **结果**：因其本质是“错误”，强行合理化会导致逻辑自洽性崩塌，变得不合理，最终被定义为“魔”。

- **路径B：顺从神的定义**
  - **行为**：承认自身属性，接受既定的天理秩序。
  - **结果**：因神创造天地时未包含妖，按照神的定义，妖理应被消灭。

### 4. 输出结论
基于上述分析，得出以下结果：
- **本质属性**：确认对象是秩序的制定者还是破坏者。
- **命运判定**：识别对象必然的悲剧命运——妖的本质即是“错误”，无论反抗还是顺从，最终结局都是被抹去。

## 约束条件
- 此定义仅适用于存在既定秩序与定义的世界观。
- 不适用于混沌未开或完全无序的世界设定。
