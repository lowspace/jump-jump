# 封神转化与无心特性分析

## 使用时机

当遇到以下情况时使用本技能：

- 角色接受封神/位列仙班/进入天庭编制
- 需要解释天庭众神为何无情感、无善恶判断
- 分析封神对角色记忆和人性的影响
- 创作涉及封神抉择或拒绝封神的剧情
- 区分标准神族与保留人性的特殊个体（如杨戬）
- 解释神族说谎时为何无法被看穿

## 转化判定流程

### 步骤1：确认转化条件

检查角色是否满足以下条件：

```
IF (凡人或妖怪 AND 接受封神仪式 OR 进入天庭编制) THEN (
    触发生理与心理改造
)
```

**例外检查**：杨戬等特殊个体未接受封神，保留人心和痛苦感，不执行转化。

### 步骤2：执行生理改造

对通过封神的角色应用以下规则：

- **移除心窍**：在物理或形而上层面失去"心"
- **视觉特征**：被封神者（榜上诸神）呈现没有心窍的状态
- **物理变化**：失去心跳闪烁特征，导致说谎无法被凡人察觉

### 步骤3：应用心理与行为规则

设置以下行为模式：

- **情感维度**：看不出善恶悲喜，丧失同理心和情感反应
- **沟通特性**：因无心跳物理特征，说谎时无法被察觉（对比：人说谎时心会闪烁）
- **道德豁免**：只要按"天数"（剧本）行事，无论作恶多少、杀戮多少，都无罪且可获封赏

### 步骤4：评估转化代价

计算记忆与身份风险：

```
IF (心窍存在性 = False) THEN (
    逐渐遗忘过去的重要羁绊
    可能丧失自我身份认知
)
```

**表达示例**："若是我也没了心窍，如何还能记着杨婵？如何还能记着我自己？"

### 步骤5：处理保留人性个体

对于拒绝封神或特殊保留人性的角色：

- **保留能力**：情感感知、痛苦感、善恶分辨
- **承担代价**：无法像标准神族那样心安理得作恶或冷漠执行天命
- **典型角色**：杨戬

## 关键变量控制

| 变量名 | 类型 | 取值 | 说明 |
|--------|------|------|------|
| 心窍存在性 | Boolean | True/False | True=保留人性与记忆；False=成为标准神族/无情 |
| 罪恶感知度 | Level | 0 (无)/1-10 | 无心神族对自身罪恶的感知度固定为0 |

## 结果输出

转化完成的角色呈现为：

- **形态**：标准神族，无心窍
- **心理**：无情无感，无善恶判断
- **行为**：按天数行事，道德豁免，说谎隐匿
- **代价**：丧失自我记忆和人性情感

## 应用检查清单

- [ ] 确认角色是否接受封神/进入天庭
- [ ] 排除杨戬等特殊例外个体
- [ ] 应用无心状态导致的情感缺失
- [ ] 确保说谎时无心跳闪烁特征
- [ ] 评估对重要记忆和羁绊的影响
- [ ] 明确标准神族与保留人性个体的区别
