# 阐截教派冲突处理

## 使用场景
- 截教门人被阐教徒弟所杀
- 教派之间发生对峙
- 需要处理石矶娘娘寻仇事件
- 分析教派利益高于人命的处理逻辑

## 执行步骤

### 1. 确认事件起因
- 确认哪吒射出的震天箭击中目标
- 确认受害者为石矶娘娘门人（女童）
- 确认箭上带有可追溯的微雕信息

### 2. 明确身份背景
| 角色 | 派系 | 辈分 |
|------|------|------|
| 石矶 | 截教 | 通天教主门下 |
| 太乙真人 | 阐教 | 与石矶同辈 |
| 哪吒 | 阐教 | 太乙真人徒弟（第三代） |

### 3. 冲突升级流程
1. 石矶通过箭上信息抓捕李靖
2. 李靖供出哪吒，带哪吒去谢罪
3. 哪吒与石矶交手，法宝被收，逃回乾元山
4. 石矶追至乾元山，质问太乙真人

### 4. 太乙真人的处理逻辑

**态度：**
- 阐截两派结怨已久
- 绝不认错
- 推卸责任给"天定"和"劫数"

**行动：**
1. 使用九龙神火罩将石矶罩住
2. 倒上汽油点火
3. 乱剑刺入
4. 炼化石矶

### 5. 处理后果
- 石矶死亡
- 阐截两派矛盾激化
- 引发旷世大火拼

## 关键变量
| 变量 | 值 |
|------|-----|
| 石矶派系 | 截教 |
| 太乙派系 | 阐教 |
| 处理手段 | 九龙神火罩炼化 |

## 输出结果
石矶死亡，阐截两派全面开战
