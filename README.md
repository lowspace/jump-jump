# Jump Jump · 悟空传

> *"悟空是极少数，凡人才是世界的主角。"*

一个基于《悟空传》的 LLM 驱动文字博弈游戏。玩家在西游世界中扮演不同的凡人/小人物，在有限行动内通过对话、谈判、抉择来求生存、争利益。场景间通过暗线（因果链）相连，经验可"复利"。

这不是一个关于英雄的游戏，这是一个关于**被忽视者**的游戏。

---

## 核心理念

### 被忽视者的主场 (The Overlooked Take Center Stage)

玩家扮演的不是"没有法力的凡人"，而是西游叙事中**被忽视的普通角色**。游戏的核心视角翻转是：这些被忽视的群体才是世界的真正主体。

- 你绝不会成为"关键先生"或"天选之人"
- 你能感知到宏大事件正在发生，但只能从边缘介入
- 你的身份本身就是约束——地位决定了你能接触什么、能做什么

### 多元生存博弈

每个场景围绕不同维度的"生存"展开：

| 场景 | 生存维度 | 核心矛盾 |
|------|---------|---------|
| 五指山·尘埃 | **意义的生存** | 遗忘/接受 vs 铭记/执念 |
| 陈塘关·剔骨 | **道义的生存** | 亲情的保全 vs 责任的承担 |
| 天河·坠落之前 | **职场的生存** | 记忆的保存 vs 安全的前程 |
| 花果山·最后的桃 | **理想的存活** | 反抗的坚持 vs 族群的延续 |
| 灵台·空经 | **信仰的生存** | 真相的认知 vs 意义的建构 |

### 道德重量

关键抉择必须让玩家**在屏幕前真正纠结**。选择设计不是"好 vs 坏"，而是"好 vs 好"或"坏 vs 更坏"。每个选项都有令人心痛的代价，不存在道德高地。

> "如果我是另一个角色，我可能也会这样做。"

### 缝隙参与

玩家的价值不是"重要"，而是**"刚好在这里"**——因为你不引人注意、因为你碰巧听到了什么、因为你无足轻重到不会被怀疑。NPC 社会运转正常时，你无法介入；你的窗口是 NPC 社会出现"裂缝"的时候。

## 五章叙事

### 序章：五指山·尘埃

**玩家**：少年樵夫（十四岁，五指山脚下砍柴为生）

**故事**：一切结束后的回忆视角。祖母讲述四个扭曲的故事——首次游玩时是谜，通关后是答案。你在山上种下一颗桃核、刻下自己的名字、或对着山说一句话。你不知道山下压着谁，不知道这些故事属于谁。

**魂魄碎片**：汇聚——义、智、勇、信四种碎片的微弱回响。

> "今天只是一个普通的黄昏。一个少年在山上砍了一天柴。仅此而已。"
> "真的仅此而已吗？"

### 第一章：陈塘关·剔骨

**玩家**：周师傅（哪吒的武术教习）

**故事**：龙王逼债，李靖面临交出哪吒的选择。你不是决策者，你只是一个教过哪吒几套拳法的师傅。你能做什么？说服李靖？放走哪吒？还是在他剔骨时站在旁边？

**核心抉择**：那把刀——是李靖赐的"父刀"，还是你教的"师刀"？

> "哪吒拔出武师教的短刀，刀柄磨得发亮。'

### 第二章：天河·坠落之前

**玩家**：陆执（天庭灵蕴核算吏）

**故事**：你发现账目异常——大量灵蕴深夜流向灵山。同时，天蓬元帅因爱上月亮即将被贬。你可以选择揭发、沉默、或警告天蓬。但无论你怎么选，天蓬都会坠落。

**核心矛盾**：知道了真相，你还能装作不知道吗？

> "他选择爱情不是因为他高尚，而是因为他就是这么想的。"

### 第三章：花果山·最后的桃

**玩家**：石卵（水帘洞的普通杂役猴子）

**故事**：悟空被压五指山后，花果山群龙无首。老猴主张躲避求生，铁头主张继续反抗，天兵随时可能再次围剿。你只是一只没有法力的普通猴子，但你的选择会影响猴群是否记得齐天大圣。

**核心问题**："他不在了，我们还要记得他吗？"

### 第四章：灵台·空经

**玩家**：法明（灵山末等抄经僧）

**故事**：你发现真正的佛经上什么都没有写。唐僧（取经出发前）告诉你：经文本身不重要，但行走本身有意义。你可以选择继续抄经、离开灵山、或当众质问。

**核心领悟**：如果经是空的，走这条路还有意义吗？

## 系统设计

### LLM Agent 架构

**核心理念：Agent 也是玩家**

NPC 不是响应器，而是 LLM 驱动的独立玩家，和人类在同一个博弈场中。

```
Player Action
  ├─ @NPC 对话 → 直接影响目标 NPC → 级联传播
  └─ 直接行为 → GM 判定影响范围 → 受影响 NPC 各自反应
    ↓
[NPC 级联传播]（最大 K 轮上限）
  - Agent 自由意志传播（基于各自利益判断）
  - 传播有「隔墙有耳」风险 + 信息损耗/失真
    ↓
[GM 全局评估]
  - 汇总状态变化
  - 判定蝴蝶效应
  - 更新世界状态
```

### 双层信息过滤

- **Layer 1 — Agent 自主**：基于动机/利益决定「想说什么」（可能隐瞒、欺骗、选择性透露）
- **Layer 2 — GM 约束**：基于世界观判定「能说什么」（凡人不可能知道天庭机密）

### 洞察值系统（简化版）

- 每场景固定分配：2 次「真实目的」+ 2 次「幕后对话」
- **「真实目的」**：揭示 NPC 回复的 Hidden Intent（真实意图+推理+信息策略）
- **「幕后对话」**：揭示触发的 NPC 间幕后交互完整过程
- Hidden intent **绝不暴露给其他 NPC**

### 涟漪而非巨浪

玩家的行为可以改变西游历史的**程度**，但不能改变**主线走向**。核心叙事（取经、大闹天宫、五指山）是既定的。

> 你能做到的最好结果，可能只是让被压在五指山下的孙悟空多了一棵桃树。但这棵桃树是真实的，它证明了你存在过。

### 核心类

**LLMNPCAgent** (`llm_npc_agent.py`)
- 真正的 LLM 驱动 NPC
- 每个 NPC 有独立 personality、background、goals、secrets
- 信任度系统控制信息共享程度
- JSON 输出：observable_response + hidden_intent + trust_change

**GameFlowManager** (`game_flow.py`)
- 场景管理（5 个完整场景）
- 目标追踪系统
- 决策点触发
- 场景切换

**JumpJumpGame** (`client_v5.py`)
- CLI 主循环
- 场景 NPC 动态加载
- 回合制交互

## 设计哲学

### 8 个核心体验原则

| 原则 | 定义 |
|------|------|
| **P1** 被忽视者的主场 | 玩家是西游叙事中被忽视的普通角色 |
| **P2** 多元生存博弈 | 每个场景有不同维度的生存侧重 |
| **P3** 道德重量 | 选择让玩家真正纠结，没有明显正确答案 |
| **P4** 理想与枷锁 | 抉择发生在理性与感性之间 |
| **P5** 暗线隐晦 | 因果暗线隐晦，闭合发生在心性层面 |
| **P6** 涟漪而非巨浪 | 改变程度而非主线，留下痕迹而非拯救世界 |
| **P7** 发现感 | 探索被奖励，好奇心有回报 |
| **P8** 无力感与微光 | 在绝望中总有一丝可以抓住的希望 |

### 宇宙法则（Root Rules）

- **R1 秩序法则**：天庭是后来建立的治世机构
- **R2 存在法则**：秩序外的存在是"错误"，等待被修正
- **R3 能量法则**：灵蕴由凡人供奉转化，是神的燃料
- **R4 天数法则**：既定剧本只覆盖宏观事件，凡人选择在缝隙中
- **R5 边界法则**：认知边界内的存在以为自己在自由选择
- **R6 不可逆法则**：宇宙级事件不可逆，凡人层面有韧性
- **R7 凡神反比法则**：凡人物质状态与博弈结果状态成反比
- **R8 信念侵蚀法则**：信息越多，盲目信念越弱，真实信念越强

## 开发历程

这个项目源于一个简单的问题：**如果悟空传的世界里有普通人，他们会怎么活？**

从最初的技术验证到完整的 5 场景实现，经历了多轮架构迭代：

1. **Round 1**：Agent 身份与边界定义
2. **Round 2**：NPC as Tool + GM 4 模块拆分
3. **Round 3**：NPC 社会 + 弹性 NPC + 双层输出 + 自然交互范式

核心洞察：**"缝隙参与"**——玩家的价值恰恰来自被忽视。
