# 世界设定书 -- 凡人世界分册（World Bible: Mortal Realm）

> **本文档是 `world-bible.md` 的分册。** 宏观宇宙法则、物种层级、权力系统、认知规则、哲学框架等请参见主文档 `world-bible.md`。
> 本分册专注于定义凡人的能力、生活、社会、经济、信仰与日常——即玩家角色所处的世界。
> 本游戏的核心是「凡人是主角」。本文档是场景设计师最常引用的资料，所有凡人场景必须与本文档一致。

---

## 一、凡人能力体系

> **设计原则**：凡人的能力是定性的，不是数值化的。能力描述的目的是让 GM 和场景设计师判断「这个角色在这种情况下能做什么、不能做什么」。

### 1.1 通用社会技能

每个凡人都在以下维度上有强弱之分，具体侧重由职业和经历决定：

| 技能 | 描述 | 典型应用 |
|------|------|---------|
| **说服** | 用道理、情感或利益打动他人 | 求情、劝降、结盟、化解误会 |
| **欺骗** | 隐瞒真相或构造假象 | 伪装身份、编造借口、设局、诈骗 |
| **恐吓** | 利用武力、权势或信息优势施压 | 威胁、逼供、驱散、震慑 |
| **讨价还价** | 在交易中争取更优条件 | 买卖、雇佣、换取情报、谈判赎金 |
| **察言观色** | 通过表情、语气、肢体语言判断对方意图 | 识破谎言（仅对凡人有效）、判断情绪、评估危险 |

**重要限制**：察言观色对神无效——神没有心窍，说谎时无生理反应。凡人可能自以为看透了一个神，但那只是神愿意让你看到的。

### 1.2 知识领域

凡人的知识是碎片化的、经验性的、口耳相传的。没有系统化的学术体系。

| 知识领域 | 内容 | 获取方式 |
|---------|------|---------|
| **民间偏方** | 治小病、解蛇毒、催产、止血的土法子 | 家族传承、邻里相授 |
| **官府律法** | 大唐律令的民间版本（常有误读和简化） | 衙门告示、讼师口传、亲历官司 |
| **商路消息** | 哪条路安全、哪个镇闹匪、哪里缺粮 | 行商带来、驿站传播、茶馆闲谈 |
| **风土人情** | 各地禁忌、方言、习俗、地方势力 | 旅人口述、寺庙僧侣、赶集交流 |
| **草药学** | 常见草药的辨认、采集、炮制、配伍 | 师徒传承、药铺学徒、山民经验 |

**关键特征**：凡人知识的可靠性极不稳定。同一个偏方在甲村救了人、在乙村害了人。没有标准化，没有对照实验，全凭经验和运气。

### 1.3 特殊技能

少数凡人掌握的、触及超自然边缘的能力：

**驱邪基础**
- 工具：咒语（口诀）、符箓（朱砂黄纸）、草药（雄黄、艾草、桃木）
- 有效范围：仅对低级灵/精有效——宅中作祟的器物精、山路上迷人的狐狸精、水边纠缠的溺死鬼
- 对真正的妖无效：妖是宇宙运转的「错误」，其力量远超凡人手段
- 失败代价：惹怒了对付不了的存在，后果比不驱邪更严重

**占卜**
- 方式：龟壳灼烧、铜钱卦、面相、梦兆解读
- 效果：大部分时候是心理安慰；但偶尔真的准——这个「偶尔」足以维持占卜作为一门营生
- 设计用途：为玩家提供模糊线索，但永远不给确定答案。占卜结果的解读空间是博弈的一部分

**风水堪舆**
- 选址建房、安葬择穴、趋吉避凶
- 真实性：部分有效——灵蕴在地理上的分布确实不均匀，有些地方「气」确实更好
- 但凡人对此的解释完全错误：他们以为是龙脉走向，实际上是神的管辖区域划分造成的能量差异

### 1.4 职业能力侧重

每种职业的凡人有不同的能力组合。以下不是严格的职业系统，而是角色塑造的参考：

**商人**
- 核心：信息网络、讨价还价、识人（判断对方可信度与支付能力）
- 延伸：多地方言、商路地理、货物品鉴、贿赂之道
- 弱点：体力差、野外生存能力弱、容易被抢劫
- 场景价值：信息经纪人。商人知道的事比任何单一地点的人都多，但信息要价不菲

**猎户/樵夫**
- 核心：野外生存、动物行为理解、体力、方向感
- 延伸：追踪、设陷阱、辨别天气征兆、识别危险区域
- 弱点：社交技能弱、不识字、对官场和城市一无所知
- 场景价值：野外场景的核心。猎户能发现「这片林子不对劲」——动物异常迁徙、某个方向的鸟全消失了

**僧侣/道士**
- 核心：驱邪、经文知识、冥想洞察
- 延伸：识字（极少数识字的凡人群体）、草药基础、社区调解
- 弱点：武力差、经济上依赖布施、可能被教条束缚
- 场景价值：跨层级信息节点。寺庙是消息汇聚之地，僧侣/道士是最可能接触到超自然信息碎片的凡人
- 特殊说明：僧侣/道士的驱邪能力来自技术（咒语、符箓），不来自真正的神力。他们以为自己是在借神力，实际上神根本没在乎

**书生/官吏**
- 核心：律法知识、文书能力、官场人脉
- 延伸：历史典故、诗文、外交辞令、档案检索
- 弱点：体力极差、脱离底层现实、可能迂腐
- 场景价值：制度博弈的核心。书生能看懂告示背后的权力意图，能写状子，能走官府渠道

**铁匠/手工艺者**
- 核心：制造修理、材料知识、工具使用
- 延伸：金属辨别、火候控制、结构强度判断
- 弱点：社交圈窄、活动范围小（铁匠铺是固定的）
- 场景价值：物质支持。关键时刻能打造工具、修补器物。极少数铁匠掌握在武器上刻符的技术（效果存疑）

**草药师/郎中**
- 核心：医疗、草药、毒物知识
- 延伸：接骨、针灸、简易外科（拔箭头、缝伤口）、辨识中毒症状
- 弱点：治不了超自然疾病（被妖气侵染、被诅咒）、社会地位不高
- 场景价值：生死关头的关键角色。郎中是少数能客观观察身体变化的人——「这人的伤口不正常，不是刀砍的，是被什么烧的」

## 二、物质文明

> 技术水平对标大唐贞观年间。以下描述的目的是为场景设计师提供「空气感」素材。

### 2.1 建筑

- **民居**：土坯墙、茅草或灰瓦顶。富户用砖石和木架。窗户糊纸，冬天冷风直灌
- **城镇**：有夯土或砖石城墙。城门日落关闭、日出开启。城内有坊市格局，居住区（坊）和商业区（市）分开
- **官衙**：全镇最好的建筑。朱漆大门、照壁、公堂。门前有鸣冤鼓
- **寺庙/道观**：仅次于官衙的建筑。香火旺盛的寺庙可能比官衙还气派——这本身就说明了权力格局
- **乡间**：散落的村庄，几十户到百余户不等。村口有老树，树下是议事点。村尾或村外常有土地庙

### 2.2 交通

- **步行**：绝大多数人的出行方式。一天走三四十里算正常
- **马车/牛车**：商人、官员使用。牛车慢但能载重。马匹昂贵，普通人养不起
- **船**：水路是长途运输的首选。渡船、货船、竹筏。风险：翻船（可能是天灾，可能是「天灾」）
- **驿站**：官方通讯和官员出差的中转站。普通百姓不能使用官驿，但驿站附近常有客栈

**距离感**：长安到洛阳约八百里，骑马三四天，步行半个月。对普通凡人来说，隔壁县就是「远方」。大多数农民一辈子活动范围不超过方圆百里。

### 2.3 通讯

- **口信**：最常见。找个顺路的人带句话。可靠性极低
- **书信**：需要识字（排除了九成以上的人）。需要找人送信（费钱）。可能被截、被丢、被水泡烂
- **驿站系统**：仅供官方使用。八百里加急是最快速度，普通公文慢得多
- **寺庙网络**：云游僧侣在寺庙间流动，客观上形成了一个非正式的信息网络。这是凡人世界最接近「情报系统」的东西

**信息衰减规则**：任何消息传过三手就会严重失真。传过五手可能面目全非。这是游戏的核心机制之一。

### 2.4 武器

- **常见兵器**：刀、剑、枪、弓弩、棍棒
- **民间武器**：柴刀、锄头、菜刀、扁担——农民不会有真正的兵器
- **杀伤力上限**：凡人武器只能伤害凡人和低级灵/精。对妖无效，对神更是笑话
- **例外**：极少数经过特殊处理的武器（道士开光、用特殊材料铸造）可能对低级灵/精有微弱加成，但这更多是心理安慰

### 2.5 医疗

- **草药**：主要治疗手段。对常见病有效，对疑难杂症看运气
- **针灸**：少数郎中掌握。止痛、通气血有一定效果
- **土法手术**：拔箭头、截肢（存活率很低）、放血、灼烧止血
- **接生**：产婆负责。产妇和婴儿的死亡率很高——这是日常，不是意外
- **瘟疫**：一旦爆发几乎无法控制。隔离是唯一手段，但执行困难。瘟疫在凡人认知中是「天罚」——有时候确实是

## 三、社会结构与治理

### 3.1 人间官府

**地方行政**：
- **县令**：一县之主。管辖几千到几万人。由朝廷任命，通常是外地人（回避制度）
- **县丞/主簿**：县令副手。处理文书、税赋、户籍
- **典史/捕头**：负责治安、缉捕。手下有衙役若干
- **里正/保长**：基层自治。负责传达官令、催收赋税、调解小纠纷。通常由本地人担任

**官府的实际能力**：
- 能管的事：收税、审案、征发徭役、维持基本治安
- 管不了的事：超自然事件、地方豪强的隐性权力、山野中的匪患
- 官府遇到超自然事件的标准反应：否认、推诿、找道士、上报（然后石沉大海）

**官府与天庭的关系**：
- 凡人官员不知道天庭的真实运作机制
- 多数官员对神佛持实用主义态度：修庙、拨款、参与祭祀——这是维稳手段，不是信仰
- 少数官员有模糊的认知：「确实有些事不是人力所能为」，但无法深入了解
- 官府和神界不存在正式的沟通渠道

### 3.2 社会阶层

**士农工商**——名义上的四民划分：
- **士**：读书人、官吏。地位最高但人数最少。科举是底层上升的理论通道，但实际中举率极低（万里挑一）
- **农**：种地的。名义上地位仅次于士，实际上是被盘剥最重的群体。交租、服役、供奉三重负担
- **工**：手工业者。铁匠、木匠、陶匠、织工。技术是他们的资本，但没有土地，生存依赖市场
- **商**：商人。名义上地位最低，实际上可能最富有。社会偏见与经济实力的矛盾

**阶层流动性**：
- 向上：科举（极难）、经商致富（有风险）、立军功（要命）、嫁入高门（看运气）
- 向下：极其容易。一场天灾、一场官司、一场大病就能从自耕农变成流民

**底层**：
- 乞丐：城镇中的常见存在。有组织的乞丐帮派控制地盘
- 流民：失去土地的农民。战乱、天灾、横征暴敛都会制造流民。流民是社会不稳定的最大来源
- 罪犯/刺配之人：脸上有字，社会性死亡。被发配到边远地区服苦役

### 3.3 地方权力格局

一个典型的县镇里，四种权力并存、博弈、有时合作：

**县令（官方权力）**
- 合法性来源：朝廷任命
- 实际控制力：有限。外来者，不了解地方盘根错节的关系
- 工具：衙役、律法、税收权
- 弱点：任期有限、不通地方情况、可能被架空

**乡绅/地主（经济权力）**
- 合法性来源：土地和财富
- 实际控制力：强。控制佃农生计、放贷、操纵粮价
- 工具：金钱、人脉、家丁
- 与官府关系：互相利用。乡绅帮官府收税维稳，官府给乡绅方便

**寺庙住持（精神权力 + 信息枢纽）**
- 合法性来源：宗教权威、社区信任
- 实际控制力：隐性但深入。影响民众的判断和行为
- 工具：宗教话语权、信息网络、调解权威
- 特殊地位：寺庙是唯一合法的跨阶层聚集场所——地主和佃农在佛前理论上平等

**帮派/江湖人（灰色权力）**
- 合法性来源：无。靠武力和「义气」
- 实际控制力：在官府触及不到的领域（夜间、城外、水路）有实际控制
- 工具：暴力、走私、保护费、情报
- 与其他势力的关系：被利用也利用他人。官府需要他们做脏活，乡绅雇他们打手

**权力格局的游戏意义**：玩家角色在任何一个地方都需要判断这四种权力的强弱关系和当前博弈态势。选择靠哪棵树、得罪哪股势力，是核心决策。

## 四、经济与货币

### 4.1 货币体系

- **铜钱**（文）：日常交易的基础单位。一串铜钱（贯）= 一千文。铜钱沉重，大额交易极不方便
- **银两**：大额交易使用。一两银大约兑一贯到两贯铜钱（浮动）。银子需要剪凿称量，不是标准化货币
- **金**：极罕见。只在最高级的交易中出现。普通凡人一辈子可能没见过金子
- **实物交易**：底层经济大量以物易物。粮食、布匹、盐都可以当货币用

### 4.2 价格感（相对比较）

> 不给绝对数字，给相对感。场景设计师据此判断「这贵不贵」。

| 参照物 | 大约成本 | 感觉 |
|--------|---------|------|
| 一顿路边摊粗饭 | 几文钱 | 穷人也吃得起 |
| 一斤猪肉 | 几十文 | 普通人家隔三差五吃一次 |
| 一匹粗布 | 百来文 | 做一身衣裳的材料 |
| 一晚客栈通铺 | 十几文 | 赶路人的标配 |
| 一晚客栈单间 | 几十文到上百文 | 商人、富户的标配 |
| 一匹中等马 | 十几两到几十两银 | 普通人倾家荡产的数字 |
| 一间乡下宅院 | 几两到十几两银 | 一家人积攒多年 |
| 一亩良田 | 几两银 | 农民最重要的资产 |
| 郎中看一次病 | 几十文到几百文 | 穷人可能看不起 |
| 寺庙一炷好香 | 几文到几十文 | 看寺庙大小和香的品质 |
| 科举赶考一趟（路费食宿） | 几两银以上 | 所以穷人考不起 |

### 4.3 寺庙经济

寺庙不只是信仰场所，更是经济实体：

- **香火钱**：善信的日常供奉。从几文钱到几两银不等。大户人家的供奉是寺庙的主要收入
- **法事收入**：超度、祈福、消灾、做道场。价格随名目和排场浮动。是最赚钱的业务
- **庙产**：香火旺盛的寺庙往往拥有田产、房产、商铺。租金收入有时超过香火
- **布施**：寺庙也向外布施——施粥、义诊、收容流民。这既是慈善也是扩大信众的手段
- **经济权力**：大寺庙的住持在经济上可能比县令更有实力。这种经济权力通过「神的代言人」的身份获得合法性

**香火钱的世俗流转**：凡人烧给神的钱，最终流向了寺庙的日常运转——修缮、僧侣食宿、法器维护。在灵蕴层面，香火产生的能量上浮被神吸收；在世俗层面，银钱留在了寺庙手中。两套系统并行，凡人只看到后者。

### 4.4 不同阶层的生活成本感

- **赤贫（乞丐/流民）**：有一顿没一顿。今天能不能吃上饭是唯一的问题
- **贫农**：交完租子和赋税，勉强糊口。一场天灾就会陷入赤贫。肉是稀罕物，新衣裳是过年才有的
- **自耕农/小手艺人**：温饱有余、富裕不足。能吃饱穿暖，偶尔吃肉，攒点钱但经不起大变故
- **商户/地主**：衣食无忧。有余钱享受——好茶、好酒、绸缎衣裳。子弟能读书
- **大户/乡绅**：锦衣玉食。家有仆从，出行坐轿。与官府来往，影响地方事务

## 五、信仰体系与日常供奉

### 5.1 凡人对超自然世界的认知

凡人眼中的超自然世界是一幅扭曲的、不完整的拼图：

- **知道**：有神、有鬼、有妖怪。烧香拜佛有用（有时候）。得罪神会遭报应
- **不知道**：神的力量来源就是自己的供奉。灾难是神主动制造的。神的系统和人间官僚一模一样——贪婪、等级森严、互相倾轧
- **误以为**：神是慈悲的但标准很高。灾难是因为自己不够虔诚。供奉是在感恩而不是在被勒索
- **混合状态**：有些人真心信，有些人半信半疑，有些人只是走形式。但几乎没有人敢公开不信——代价太大

### 5.2 供奉的驱动力

**恐惧 > 感恩 > 敬爱**

这是凡人供奉的驱动力排序。大多数人烧香不是因为觉得神好，而是因为害怕不烧香会出事。这种恐惧是有现实基础的——不供奉确实会遭灾（因为神会惩罚不供奉的人）。

### 5.3 供奉日常

**频率**：
- 日常：每日在家中神龛前点香，早晚各一次（贫困家庭可能简化为晨起一次）
- 初一十五：去寺庙或祠堂正式烧香。多数人至少做到这个频率
- 节庆：大年、清明、中元、冬至等节日有集中供奉。寺庙最热闹的时候
- 急事：遇到大病、天灾、婚丧、出远门——临时加供奉。这是「保险型消费」

**形式**：
- 最低限度：在神龛/土地庙前点一炷香，磕头，念几句祈语
- 标准：香烛、纸钱、果品、酒水
- 高规格：全猪全羊（有钱人家才供得起）、请僧道做法事、戏班唱大戏给神看
- 特殊：还愿——许过的愿灵验了（或者自以为灵验了），要加倍还报

**成本**：
- 日常供奉对温饱之家是小开支（几文钱的香烛）
- 节庆供奉需要专门准备，对贫户是负担
- 法事和还愿是大额支出，可能占到一个穷人家庭数月收入
- 供奉存在「军备竞赛」效应——邻居供了一头猪，你只供了一只鸡，你会焦虑

### 5.4 不供奉的后果

**时间尺度**：
- 停止供奉后不会立刻出事。神的管辖区域大，注意力有限
- 通常在数周到数月后开始出现「征兆」
- 征兆逐渐升级，从小不顺到大灾祸

**表现形式（渐进式）**：
1. 家中物品莫名损坏、东西找不到、噩梦增多
2. 牲畜生病、庄稼异常、小病缠身
3. 家人遭意外——摔断腿、落水、走夜路撞邪
4. 大灾——房屋失火、洪水冲田、家人重病不治

**凡人的理解**：「是我不够虔诚，老天爷在警告我。」他们几乎正确——确实是因为供奉不够才遭灾。但归因方向完全错误：他们以为是自己的态度问题（「心不诚」），实际上是系统的强制机制（「保护费没交」）。

### 5.5 凡人的归因偏差

这是本游戏最重要的认知裂缝之一：

| 凡人的理解 | 实际真相 |
|-----------|---------|
| 「我不够虔诚所以遭灾」 | 你供奉不够所以被惩罚 |
| 「神是慈悲的，灾难是考验」 | 神制造灾难是为了逼你供奉 |
| 「好人有好报」 | 供奉多的人被惩罚得少 |
| 「坏人终有报应」 | 不供奉的人被惩罚得多（和好坏无关） |
| 「菩萨保佑了我」 | 你的供奉转化的灵蕴刚好够，所以没被追加惩罚 |
| 「修来世」 | 没有来世这回事——至少凡人无法确认 |

**设计意义**：这张表是GM引导场景情感冲突的核心工具。当玩家（凡人角色）开始接近真相时，游戏最有张力的时刻就到了。

## 六、寺庙与祠堂

> 寺庙的社会功能远超宗教。它是凡人社会的多功能枢纽。

### 6.1 信息交换中心

- 外乡人、行商、云游僧侣到了一个地方，第一站往往是寺庙——住宿便宜（甚至免费）、安全、有人接待
- 寺庙因此成为消息汇聚之地：某地闹旱灾、某条路不通了、某个镇子出了怪事
- 住持/知客僧是事实上的情报掌握者——虽然他们可能不这么理解自己的角色
- **游戏机制意义**：寺庙是玩家获取外部信息的主要场所。在寺庙里能「听说」很多事，但信息真假需要自行判断

### 6.2 社区聚集点

- 庙会：集市 + 宗教活动 + 社交场合。一年几次的大事
- 日常：村民来烧香时互相交流。老人聚在庙前晒太阳聊天
- 避难：天灾时寺庙往往是避难所。建筑坚固、有存粮、有组织能力

### 6.3 纠纷调解——「神明公断」

- 凡人之间的纠纷如果官府不管（太小）或不敢去官府（怕花钱/怕受刑），就到寺庙请「神明公断」
- 双方在神像前发誓，由住持主持。撒谎的人「会遭报应」——这种威慑有时比衙门的板子还管用
- 实际操作：住持根据自己的判断裁决，但披上「神谕」的外衣。好的住持公正，差的住持偏私
- 这意味着住持拥有司法性质的隐权力

### 6.4 香火经济的物理终端

- 凡人的供奉在物质层面流入寺庙——钱、粮、物资
- 在灵蕴层面流向天庭——能量上浮被神吸收
- 寺庙是两个世界（凡人世界与超自然世界）的物理交汇点
- 寺庙建筑本身可以理解为一个「灵蕴采集站」的世俗外壳

### 6.5 跨层级信息的交汇点

**这是游戏机制上最重要的设定之一。**

寺庙是凡人世界中唯一可能接触到超自然层级信息碎片的常规场所：
- 神像偶尔「显灵」（可能是真的，可能是巧合，可能是低级灵/精的恶作剧）
- 高僧/高道偶尔能感应到「异样」（不能精确理解，但知道「有什么不对」）
- 经文中隐藏着真实的宇宙信息，但被包裹在宗教语言中，凡人读不出真意
- 寺庙里保存的古物、石碑、手抄本可能记录着历史上的真实超自然事件——但被当作「传说」

**对玩家的意义**：寺庙是凡人角色「向上看」的窗口。你不能爬到天上去，但你可以在寺庙里找到从天上掉下来的碎片。

## 七、除魔驱邪

> 凡人世界的超自然服务业。不是英雄叙事，是一门营生。

### 7.1 驱邪者的身份

- 多数是道士或半路出家的「法师」。少数是世代传承的驱邪家族
- 社会地位暧昧：被需要但不被尊重。平时被当作骗子，出事了才被请来
- 经济来源：靠帮人驱邪收费。收入不稳定——没有妖怪闹事就没有生意
- 与官方宗教的关系：正规寺庙/道观对「野路子」的驱邪者态度轻蔑，但有时也暗中合作

### 7.2 能力边界

| 能对付的 | 对付不了的 |
|---------|----------|
| 宅中作祟的器物精 | 真正的妖（宇宙级错误） |
| 山路迷人的低级狐精 | 有修为的狐仙 |
| 溺死鬼、怨魂 | 厉鬼、被封印的恶灵 |
| 受惊后的「撞邪」（心理疾病） | 真正的附身 |
| 用草药驱虫除秽 | 妖气侵染 |

**关键设定**：驱邪者自己通常不知道自己的能力边界在哪。他们遇到对付不了的东西时才发现——而那时往往已经太晚了。这是天然的游戏紧张感来源。

### 7.3 驱邪技术

- **咒语**：口诀念诵。来源不明（可能是古代真正的修行者留下的，经过多代传抄已经残缺）。有些咒语确实有微弱效果，有些纯粹是安慰剂
- **符箓**：朱砂画在黄纸上。有固定的符文体系但各家各派不同。贴在门上、烧化后溶于水中饮用、塞进衣领
- **草药/物品**：雄黄、桃木、艾草、黑狗血、铁钉、铜镜。对低级灵/精有驱逐效果（不是杀灭，是赶走）
- **仪式**：设坛、焚香、诵经、撒米、泼水。过程比结果重要——仪式感本身能安抚受害者的心理

### 7.4 驱邪者作为信息节点

驱邪者的另一个价值在于他们的信息网络：
- 来求助的人带来各地的消息——「我们村子出了怪事」
- 驱邪者因此比普通凡人更了解超自然事件的分布和频率
- 老练的驱邪者能从求助者的描述中判断事态的严重程度：「这个我能处理」vs「这个你得去找更大的庙」
- **游戏设计**：驱邪者NPC是重要的信息来源和任务发放者

## 八、口耳相传 vs 真实

> 信息不确定性是核心玩法要素。本节定义凡人的信息环境。

### 8.1 信息失真机制

凡人的信息环境有以下特征：
- **传递衰减**：每传一手，细节丢失、被填补、被夸张。三手后面目模糊，五手后可能完全走样
- **情感放大**：恐怖的事会在传播中变得更恐怖。「有个妖怪」会变成「有一群妖怪」再变成「妖怪大军」
- **权威覆盖**：如果官府或寺庙给了一个解释，即使是错的，也会压过真实版本
- **时间压缩**：过去几十年发生的多件事可能被压缩成一个故事

### 8.2 传说 vs 真实的对照（示例）

| 凡人传说 | 可能的真实 |
|---------|----------|
| 「天上打了一场大仗，有个猴子跟玉帝斗」 | 大闹天宫确实发生了，但细节全错 |
| 「南山有个吃人的大虫成了精」 | 可能是真的妖，也可能只是一只特别大的虎 |
| 「城隍爷显灵救了全村」 | 灾难碰巧停了，城隍什么都没做 |
| 「某某法师道行高深」 | 他只是运气好碰到了低级灵/精 |
| 「那个和尚能请神降妖」 | 那个和尚可能真的有点本事，也可能是骗子 |

### 8.3 信息不确定性的游戏应用

- 玩家获得的任何信息都不能被默认为真。需要交叉验证
- NPC提供的信息反映的是他们的认知水平，不是客观事实
- 越离谱的传说反而可能越接近真相（因为真相本身就很离谱）
- 最可靠的信息来源是亲眼所见——但即使亲眼所见也可能被幻术欺骗

## 九、跨物种沟通规则

### 9.1 沟通方式矩阵

| 发送方 → 接收方 | 方式 | 凡人能否理解 | 备注 |
|----------------|------|-------------|------|
| 凡人 → 凡人 | 口语、书信、手势 | 能 | 方言障碍存在 |
| 凡人 → 神 | 祈祷、烧香、献祭 | 单向发送，无法确认是否被接收 | 绝大多数祈祷不被回应 |
| 神 → 凡人 | 托梦、神谕（通过僧道转达）、显灵（极罕见） | 部分可理解但常被误读 | 神极少主动与凡人沟通 |
| 妖 → 凡人 | 化为人形直接对话、制造异象 | 能（化形后说人话）| 凡人通常无法识别对方是妖 |
| 凡人 → 妖 | 口语（如果妖在场且愿意听） | — | 凡人不知道如何主动联系妖 |
| 灵/精 → 凡人 | 作祟（物品移动、怪声、梦魇）| 不能直接理解，只能感知异常 | 低级灵/精通常无法说人话 |

### 9.2 语言与理解

- **人语**：各地方言差异大。隔了几个州可能互相听不懂。官话（类似普通话）只有读书人和官员会说
- **妖语/神语**：凡人听不懂也听不到。妖与凡人沟通必须化形后说人话。神与凡人沟通通常通过中介（梦、神谕、代言人）
- **经文**：佛经、道藏中的语言是「编码过的」信息——字面意思和真实含义不同。识字的凡人能读字面意思，但几乎无人能解码真意
- **特殊情况**：极少数凡人（天生异禀或经历特殊事件后）可能获得短暂的「灵听」能力——能听到不该听到的声音。这通常是灾难的前兆

### 9.3 信息载体

| 载体 | 持久性 | 可靠性 | 获取难度 |
|------|--------|--------|---------|
| **口述** | 极低（传几代就失真） | 低 | 低（找个人问就行） |
| **书卷** | 中等（纸会腐烂、被虫蛀） | 中等（但抄写可能出错） | 高（识字率极低） |
| **石刻** | 极高（可存千年） | 高（但可能被风化模糊） | 高（石碑通常在偏远处） |
| **梦境** | 一次性（醒来就模糊） | 极不可靠（难以区分真梦和普通梦） | 被动（不能主动获取） |
| **实物遗迹** | 看材质 | 高（物证不会说谎）但需要解读 | 极高（需要找到并识别） |

## 十、日常生活

> 以下内容为场景设计师提供「凡人日常」的空气感素材。

### 10.1 节庆与民俗

**主要节庆**：
- **元日（春节）**：最大的节日。除夕守夜、爆竹（竹子放火里烧，真的竹子）、贴桃符、饮屠苏酒。穷人家也要想办法吃一顿好的
- **上元节（元宵）**：灯会。城镇取消宵禁，允许夜间出行。是少数男女可以公开接触的场合
- **清明**：扫墓祭祖。给死人烧纸钱——凡人不知道这些「钱」在另一个世界到底有没有用
- **端午**：龙舟竞渡、系彩绳、饮雄黄酒。驱邪意味浓厚——艾草和菖蒲挂在门口
- **中元节（鬼节）**：七月十五。烧纸钱、放河灯、超度亡魂。凡人最恐惧的节日——「鬼门开」的传说让人夜间不敢出门
- **中秋**：赏月、吃饼、阖家团圆。文人赋诗，百姓饮酒
- **冬至**：「冬至大如年」。北方吃饺子/馄饨，南方祭祖。标志着最难熬的寒冬开始

**日常民俗/禁忌**：
- 夜间不叫人全名（怕被鬼听到）
- 筷子不能插在饭上（像给死人上香）
- 出远门前要在灶神前报备
- 看到乌鸦叫、猫头鹰叫是不吉之兆
- 孕妇不能参加丧事
- 搬新家要先请灶神入宅

### 10.2 饮食

- **主食**：北方以面食为主（饼、面条、馒头），南方以米饭为主。粟（小米）是穷人的主粮
- **菜蔬**：萝卜、白菜、葱、蒜、韭菜、豆腐。时令蔬菜靠种靠采
- **肉食**：猪肉最常见但并非天天有。鸡鸭偶尔。牛肉受限（耕牛不能随意宰杀）。鱼虾看地区
- **饮品**：茶（但好茶是奢侈品）、酒（浊酒，清酒贵）、白水
- **调味**：盐（官府专卖，价格不便宜）、醋、酱、花椒。糖是稀罕物
- **饮食阶层差异**：穷人吃糠咽菜、稀粥度日；富人鱼肉不断、酒席常开。一桌酒席的花费可能是穷人半年口粮

### 10.3 婚丧嫁娶

**婚**：
- 父母之命、媒妁之言。本人几乎没有选择权
- 聘礼和嫁妆是两家经济实力的博弈
- 婚礼当天拜天地、拜高堂——「天地」不知道也不在乎
- 穷人家的婚礼可能简陋到只有一顿饭和一碗酒

**丧**：
- 死亡率高——婴儿夭折、产妇难产、伤病不治都是常事
- 丧葬流程：停灵、守孝、出殡、下葬。请僧道做法事超度
- 丧葬费用是沉重负担。「死不起」是真实存在的问题
- 孝期：父母丧守孝三年（官员需丁忧离任）。这期间不能婚嫁、赴宴、穿彩衣

**嫁娶中的超自然要素**：
- 择日必须看黄历（占卜变体）
- 新娘花轿要放铜镜（辟邪）
- 新房贴符
- 婚礼和丧礼都涉及大量供奉——这些场合的灵蕴产出特别高（因为情感强烈）

### 10.4 娱乐

- **茶馆/酒肆**：社交场所。听说书、聊天、下棋、赌博
- **说书**：凡人世界的「媒体」。说书人讲述英雄传奇、鬼怪故事、历史演义。信息传播的重要渠道——但说书人的加工让信息更加失真
- **戏曲**：城镇有戏班。庙会时搭台唱戏。内容多为忠孝节义、因果报应——强化现有的信仰体系
- **赌博**：骰子、牌九、斗蟋蟀、赌马。底层最常见的「娱乐」，也是致贫的重要原因
- **棋类**：围棋（文人）、象棋（更平民）
- **节庆活动**：灯谜、龙舟、庙会游艺、杂耍表演

### 10.5 教育

- **识字率**：极低。估计不超过一成的人能读写。女性识字率更低
- **私塾**：地方乡绅或退休官员办学。只有交得起束脩的人家才能送孩子去读书
- **教育内容**：《三字经》《千字文》启蒙，然后是四书五经。目标是科举，但绝大多数人止步于识字阶段
- **学徒制**：手工业靠师傅带徒弟传承。学徒期三到七年不等。师傅有绝对权威
- **寺庙教育**：寺庙/道观有时承担启蒙教育。穷人家的孩子如果出家为僧/道，反而能获得识字的机会
- **知识垄断**：识字本身就是一种权力。不识字的人在官府面前几乎没有自我保护的能力——文书上写什么他们不知道

## 附录A：场景设计速查

> 场景设计师在构建凡人场景时可快速参考以下清单。

### 一个典型的乡村场景应该包含：
- [ ] 土地庙（哪怕很小、很破）
- [ ] 至少一个知道外面消息的人（行商、归乡的兵、云游僧）
- [ ] 阶层差异的痕迹（地主的砖房 vs 佃农的茅屋）
- [ ] 供奉的日常痕迹（神龛、香灰、门上的桃符）
- [ ] 某种不安的隐兆（最近庄稼不好？有人做了怪梦？）

### 一个典型的城镇场景应该包含：
- [ ] 至少一座像样的寺庙或道观
- [ ] 官衙的存在感（哪怕只是门前走过的衙役）
- [ ] 茶馆/酒肆（信息交换的核心场所）
- [ ] 阶层的可见对比（锦衣商人 vs 街角乞丐）
- [ ] 市场的喧闹（叫卖声、讨价还价、牲口的气味）

### 空气感关键词：
- 烟火气：灶烟、油灯、柴火的噼啪声、饭菜的香气
- 泥土气：黄土路、雨后泥泞、田间的牛粪味
- 人情世故：邻里串门、闲言碎语、谁家媳妇和婆婆吵架了
- 恐惧的底色：入夜后门窗紧闭、路过祠堂时加快脚步、不敢高声议论神佛
- 信息的饥渴：外乡人来了全村都围过去问消息
