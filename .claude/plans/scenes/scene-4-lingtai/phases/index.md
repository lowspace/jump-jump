# 阶段流程

| 阶段 | 名称 | 场景 | 目的 |
|------|------|------|------|
| [阶段一](phase-1.md) | 异常（发现 + 确认） | 抄经院，法明的工位。清晨。 | 发现第一个异常 — 空白底本。建立日常与关系。 |
| [阶段二](phase-2.md) | 深入（信息搜集 + 关系建立） | 抄经院内外。白天到入夜。 | 主动搜集信息，发现无字真经是系统性存在。 |
| [阶段三](phase-3.md) | 质问（与体制的碰撞） | 寺院各处。 | 展现体制对个体质疑的回应方式。 |
| [阶段四](phase-4.md) | 偶遇（微光时刻） | 后山小径。黄昏或深夜。 | 与唐僧偶遇，核心问题的提出。 |
| [阶段五](phase-5.md) | 抉择（最终决策） | 抄经院。最后一天。 | 最后一卷空白经卷上的终极选择。 |
| [阶段六](phase-6.md) | 余波 | 寺院门口/离开路上。 | 结局与后续影响。 |
