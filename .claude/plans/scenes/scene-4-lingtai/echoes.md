# 回响（跨场景联动）

## 前置场景变量读取（Inbound）

本场景在开场和特定阶段会读取前三个场景的输出变量，以「微弱闪回」的形式嵌入法明的体验。法明不知道这些感受从何而来 — 它们是碎片化的、无法解释的、但确实存在的。

| 前置变量 | 条件 | 闪回内容 |
|---------|------|---------|
| Scene 1 `knife_choice` | = 师刀 | 法明在抄写某段关于「师徒传承」的经文时突然停笔，感觉这段文字描述的不是佛法，而是某种更私人的东西 — 一种被刀刃切割过的温柔。他的手指微微发抖，说不清为什么。 |
| Scene 2 `seventh_aperture_awareness` | = 觉察 | 法明在打坐时偶然体会到一种「说不清的不安」，像是身体里有一个角落在响。那不是疼痛，更像是某种东西在试图苏醒。他睁开眼，不安消散了，但那个角落还在。 |
| Scene 3 `peach_tree_fate` | = 桃树保留 | 法明在寺院后院看到一棵桃树（灵山也有桃树），莫名觉得这棵树「很重要」，但说不清为什么。他站在树下看了很久，直到有人叫他去抄经才离开。走的时候回了一次头。 |
| Scene 3 `memory_kept` | = 铭记 | 法明听到一个云游僧提到「齐天大圣」这个名号时，心里一跳。不是害怕 — 是一种更深的东西，像是有人在很远的地方叫他的名字，但叫的不是「法明」。 |

## 后续场景闪回输出（Outbound）

本场景产生以下可能在后续场景中触发的闪回：

- **唐僧的问题闪回**（条件：`tangseng_encounter` = 遇见）：后续场景中某角色在做重要选择时，脑海中浮现一个问题 — 「你抄经的时候，心里想的是什么？」或「如果你知道路的尽头什么都没有，你还走吗？」
- **笔的闪回**（条件：`pen_taken` = 带走）：某角色在书写场景中感到手中的笔「不像自己的」
- **笔的环境闪回**（条件：`pen_taken` = 留下）：新抄经僧觉得这支笔写起来特别顺手
- **抄经院的环境闪回**（条件：`monastery_fate` = 留下）：后续场景中可能出现「一座安静的抄经院」的意象
- **悟空传说闪回**（条件：Scene 3 `memory_kept` = 铭记）：某角色在绝境中突然想起 — 「被压在山下的人，信什么？」
- **慧空善意闪回**（条件：慧空关系变量 = 理解，获得蜡烛头）：后续场景中出现「一截蜡烛头」或「不够亮的光」的意象
