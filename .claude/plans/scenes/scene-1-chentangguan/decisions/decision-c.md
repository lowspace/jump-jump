# 决策点 C：离开前

> 所属阶段：[阶段五·余波](../phases/phase-5.md)

你在收拾行李时，在练武场的角落找到了哪吒的练武护腕。他用力太大，护腕总是断，你帮他缝过很多次。

## C — 你带不带走这个护腕？

| 选择 | 后续影响 |
|------|---------|
| **带走** | 这个物件成为闪回触发物。在后续场景（Scene 3 或 4）的某个关键时刻，玩家角色会在口袋/行囊里摸到一个「不属于自己的东西」，触发一瞬间的既视感。 |
| **不带** | 练武场荒废后，护腕被风沙掩埋。在 Scene 0 中，如果樵夫路过一处废墟，可能会看到沙土中露出一角布带。他不知道那是什么。 |
