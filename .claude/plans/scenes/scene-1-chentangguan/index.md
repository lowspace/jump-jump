# Scene 1：陈塘关·骨与莲

> 本文档是《Jump Jump》的第一个可玩场景设计。
> 时间线位置：封神时期，哪吒剔骨还父。
> 宏观规则见 `world-bible.md`，角色档案见 `world-bible-characters.md`。

---

## 场景概要

| 项目 | 内容 |
|------|------|
| **核心矛盾** | 血缘义务 vs 自我完整（「还清了债，人也没了」） |
| **生存维度** | 道义下不得已的责任 |
| **玩家角色** | 周师傅 — 李靖府上的武术教师，哪吒的武术启蒙人 |
| **核心 NPC** | 哪吒、李靖 |
| **次要 NPC** | 杨戬（隐身出现，条件触发） |
| **远景存在** | 玉帝（天条的间接在场）、龙王（施压者） |
| **基础行动回合** | 8-10 回合 + 最多 3 回合弹性延长 |
| **魂魄碎片** | 义 — 明知不可为而为之的冲动 |
