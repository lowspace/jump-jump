# 回响（Echoes）

## 入站回响

本场景无入站回响（Scene 1 为第一个可玩场景）。

## 出站回响

### → Scene 0（倒叙/五指山少年樵夫）

- **护腕闪回**（`armguard = 留下`）：樵夫路过一处废墟，可能会看到沙土中露出一角布带。他不知道那是什么。
- **涟漪变量密度**（`wushi_presence`）：影响 Scene 0 中与本场景相关的叙事细节浓度。
- **闪回内容色温**（`knife_choice`）：影响 Scene 0 中剔骨相关闪回的叙事基调。

### → Scene 2（封神·核算吏）

- **杨戬闪回**（`yangjian_triggered = 是`）：核算吏面对封神选择时，脑海中会浮现一句莫名的话 — 「有心窍的人活着更难」— 他不知道这句话从何而来。

### → Scene 3（花果山）

- **B3 闪回**（`wushi_presence = 低`）：在花果山的某个安静夜晚，渡客会听到风里有骨头碎裂的声音，说不上来为什么难受。
- **护腕闪回**（`armguard = 带走`）：在某个关键时刻，玩家角色会在口袋/行囊里摸到一个「不属于自己的东西」，触发一瞬间的既视感。

### → 影响力报告

- `nezha_trust`：哪吒莲藕重塑后对凡人的基础态度
- `knife_choice`：叙事色温
- `wushi_presence`：「有人在乎」的印记强度
- `lijing_hesitation`：叙事细节
- `crowd_attitude`：陈塘关的集体记忆
- `player_philosophy`：行为画像
