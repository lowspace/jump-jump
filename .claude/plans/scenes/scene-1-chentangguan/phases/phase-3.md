# 阶段三：否认（不可改变的历史时刻）

**场景**：陈塘关城楼。李靖面对龙王使者和全城百姓。

这一刻**不可改变** — 无论玩家之前做了什么，李靖都会当众否认哪吒。

> 「哪吒是我夫人怀胎三年零六月，从肉球中剖出之物。非人，非妖，非我李靖之子。他的孽，他自己担。」

## 程度弹性

这句话的**说法和节奏**受前置变量影响：

| 条件 | 李靖的表现 |
|------|----------|
| 玩家在 A2 中说服检定大成功 | 李靖说到「非我李靖之子」时有**明显的停顿**。他的手在发抖。百姓中有人注意到了。 |
| 玩家在 A2 中说服检定成功 | 停顿很短，只有武师能察觉。 |
| 玩家没去找李靖 / 检定失败 | 李靖说得干脆利落，面无表情。 |

## 哪吒的反应

| 条件 | 哪吒的表现 |
|------|----------|
| 玩家在 A1 中陪伴过哪吒 + 信任度 ≥ 2 | 哪吒站在人群中。听到李靖的话后，他的目光扫过人群，**在武师方向停留了一瞬**。然后他走向城楼。 |
| 玩家没去找哪吒 / 信任度 < 2 | 哪吒的目光只盯着李靖。他独自走向城楼。周围没有任何他在乎的人。 |
