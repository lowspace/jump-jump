# Scene 2：天河·坠落之前

> 本文档是《Jump Jump》的第二个可玩场景设计。
> 时间线位置：天蓬元帅被贬之前/之时。天庭，天河边。
> 宏观规则见 `world-bible.md`，角色档案见 `world-bible-characters.md`，Scene 1 见 `scene-1-chentangguan.md`。

---

## 场景概要

| 项目 | 内容 |
|------|------|
| **核心矛盾** | 记忆/真相 vs 安全/前程（「知道了真相，你还能装不知道吗？」） |
| **生存维度** | 职场的生存 — 一个小官吏在体制巨轮中的挣扎 |
| **玩家角色** | 陆执 — 天庭灵蕴核算吏（负责审计灵蕴/香火账目的小官吏） |
| **核心 NPC** | 天蓬元帅（即将因爱阿月触犯天条被贬）、卷帘大将（天庭安全系统的忠实执行者） |
| **次要 NPC** | 阿月/嫦娥（远景存在）、灵蕴部中层主管·宣明（陆执的直属上司） |
| **远景存在** | 玉帝（天条的来源）、如来（灵蕴交易的另一方） |
| **基础行动回合** | 7-9 回合 + 最多 2 回合弹性延长 |
| **魂魄碎片** | 智 — 在信息与权力面前保持清醒的意识 |
