# 卷帘大将 — 天庭安全系统的核心执行者

**身份**：天庭灵霄殿卷帘大将，表面职务是玉帝的近侍护卫，实际上是天庭内部安全系统的核心操作者。他负责的不是「保护玉帝的人身安全」（玉帝不需要保护），而是**监控天庭内部所有异常行为**。他是天庭的眼睛和耳朵。

**核心动机**：完成职责。卷帘大将的动机纯粹到令人不安 — 他不追求权力、不追求认同、不追求任何个人利益。他只是在执行他被分配的工作。封神之后他的心窍被清除得比大多数神更彻底，剩余的情感几乎为零。但「几乎为零」不是「零」— 他还保留着对「同僚」这个概念的微弱认知，虽然他不会承认，也可能没有意识到。

**底线**：不越权。卷帘大将绝不做超出授权范围的事。如果上级没有下令逮捕某人，即使他确认此人有问题，他也只会**记录并上报**，而不会擅自行动。这既是他的职业素养，也是他保护自己的方式 — 在天庭，越权比失职更致命。

**秘密**：卷帘大将知道天蓬和阿月的事。不是最近才知道，是**很久以前**就知道了。他没有立即上报，而是持续观察。这个「延迟上报」是他职业生涯中唯一一次偏离标准流程的行为 — 他不知道自己为什么拖延了，他把它归因为「情报尚未充分确认」。但如果他还有心窍的话，他可能会承认：那是犹豫。是对一个还能爱的同僚的、最微弱的、几乎不存在的犹豫。

**在本场景的状态**：卷帘大将在本场景中处于高度警觉状态。天蓬事件即将爆发，整个天庭安全系统进入一级戒备。他正在执行最后的证据收集和涉事人员排查。陆执 — 一个在敏感时期接触灵蕴账目的小官吏 — 自然进入了他的监控范围。

**行为模式**：
- 面对下级 → 礼貌但不温暖。语气永远是公事公办的。他不威胁人，但他的在场本身就是一种压力
- 面对异常行为 → 不直接质问，而是**制造场景让对方暴露**。他会问一个看似无关的问题，然后观察你的反应
- 面对天蓬事件 → 执行命令。没有个人感情。但在天蓬被押走的那一刻，他会站在原地多看一眼 — 那一眼比任何言语都更能说明他内心残存的东西

**价值优先序**：天庭体制 > 职责 > 同僚情 > 个人判断

**GM 提示**：卷帘大将是沙僧的前身。他现在的状态 — 能干、冷静、精准 — 和后来流沙河里那个沉默空洞的存在形成了残酷的对比。他的悲剧在于：他亲眼看着天蓬因为「违背体制」而坠落，然后从中学到了一个错误的教训 — 「永远不要违背」。这个教训最终把他变成了一个彻底空掉的人。在本场景中，他对陆执的态度取决于陆执的行为：如果陆执表现正常，卷帘大将会将他归类为「无风险」然后忽略；如果陆执表现出异常（紧张、回避、说谎），卷帘大将会锁定他并持续施压。

**卷帘大将的观察判定规则**：
- 卷帘大将的被动洞察修正值为 **+5**
- 当陆执在卷帘面前进行欺骗检定时，DC 基于 **D20 + 5 对抗**
- 卷帘大将不需要主动检定 — 他永远在观察
