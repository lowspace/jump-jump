# 阶段四：坠落（天蓬被贬 — 不可改变的历史时刻）

**场景**：傍晚。天河边。

号角再次响起 — 这一次不是集结令，是**审判令**。所有灵蕴核算司的人被要求到天河岸边列队。不只是核算司 — 天河沿岸所有部门、所有天兵、所有文职，全部被召集到天河两岸。

天河中央的凌云台上，光柱冲天。那是玉帝的天谕直降。

你站在人群中。你的位置很远，几乎在最后排。但天河的水清澈得像镜子，你能看到凌云台上的一切。

**天蓬元帅被押上凌云台。**

他穿着水军统帅的全套甲胄，但甲胄上的权印已经被拔除了。他的双手被天链锁着。但他的背是直的。他没有低头。

天谕降下。玉帝的声音从天穹传来 — 不是一个人的声音，是**制度**的声音：

> 「天蓬，身为天庭水军统帅，不思天恩，私通广寒宫宫娥阿月，违犯天条第七十三款。罪证确凿。即刻削去仙籍，贬入凡间，投猪胎转世。令即执行。」

### 程度弹性

天蓬被贬是**固定事件**。但陆执在这个过程中的体验受前置选择影响：

| 条件 | 陆执的位置和视角 |
|------|--------------|
| 玩家在 A4 中去过天河边 + 洞察成功 | 陆执站在靠近天河的位置（因为之前来过，知道哪个角度能看清楚）。他能看到天蓬的表情。 |
| 玩家在 A1-A3 中没有离开过办公间 | 陆执在人群最后排。看不清天蓬的脸，只能看到一个模糊的身影。 |
| `juanlian_suspicion` ≥ 3 | 卷帘大将的副官站在陆执附近，明显在监视他。陆执的行动受限。 |

### 天蓬的最后时刻

天蓬站在凌云台上。天链发出刺目的光，灵蕴开始从他体内被抽离。这是贬谪的执行过程 — 先抽去仙力，再强制投胎。

在仙力被抽去的那一刻，天蓬做了一件事。

他抬起头，看向广寒宫的方向。

> 「阿月。」

只有两个字。声音不大。但天河的水面震荡了一下 — 那是水军统帅最后一丝权限在起作用，让天河把他的声音传出去。

**D20 + 洞察检定 DC 11**：
- **成功**：你听到了。你看到了他的嘴型，或者你听到了天河水面传来的那两个字。你知道天蓬在最后一刻叫的不是任何辩驳或恳求 — 是一个名字。→ `tenpeng_last_words` = true。
- **大成功（超过 DC 5+）**：你不仅听到了那两个字，还看到了一个更细微的细节 — 卷帘大将站在凌云台侧面。在天蓬叫出那个名字的瞬间，卷帘大将的身体有一个极其微小的僵硬。然后恢复了。像什么都没发生过。→ `tenpeng_last_words` = true，且你获得了对卷帘大将内心的一个关键线索：他不是完全没有感觉。
- **失败**：你什么也没听到。人群太嘈杂，你站得太远。你只看到天蓬被光柱吞噬，然后消失了。→ `tenpeng_last_words` = false。

### 天蓬坠落之后

光柱消散。凌云台空了。天河的水恢复了平静。

> GM 描述：「人群开始散去。你身边的同僚们低着头，脚步匆匆。没有人讨论刚才发生的事 — 不是不想，是不敢。天条的余威像一层冰覆在所有人身上。你也在走。但你的脚步比别人慢。你在想 — 不，你不是在'想'，你不会'想' — 你只是觉得不安。那个不安比今天早晨看到账目时更重了。它从你的胸腔里向四周蔓延，像天河的暗流。」
