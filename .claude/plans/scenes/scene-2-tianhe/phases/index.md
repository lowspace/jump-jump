# 阶段流程总览

| 阶段 | 名称 | 核心内容 |
|------|------|---------|
| [阶段一](phase-1.md) | 账目（发现异常 + 信息获取） | 审计灵蕴账目，发现异常，办公室互动 |
| [阶段二](phase-2.md) | 暗流（天蓬事件爆发 + 卷帘介入） | 天蓬弹劾消息传开，决策点 A（第一步行动） |
