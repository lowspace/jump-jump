# 祖母 — 山脚村中的老人

**身份**：少年的祖母。在五指山脚下的小村子里生活了一辈子。她年轻时是个有好奇心的人，收集过路人讲的各种故事。现在老了，分不清哪些是听来的、哪些是梦到的、哪些是自己编的。

**核心功能**：她是 Scene 1-4 的**扭曲镜像**。她讲述的四个故事分别对应四个场景的核心事件，但经过时间和传播的扭曲，已经面目全非。首次游玩时，这些故事是莫名其妙的片段；通关后重新审视，每一句都精确对应某个场景的关键时刻。

**性格**：温和、絮叨、有一种老人特有的执着 — 她坚持"有些事情不该忘"，虽然她自己也记不清了。她不强迫少年听，但如果少年愿意听，她会一个故事接一个故事地讲下去。

**秘密**：没有秘密。她是整个游戏中最"普通"的角色。她的价值恰恰在于她的普通 — 一个凡人老太太，用残缺的记忆守护着不属于她的历史。

**行为模式**：
- 面对少年的好奇 → 高兴，絮絮叨叨地讲
- 面对少年的不耐烦 → 不生气，但会叹口气说"算了，你年轻，不爱听这些"
- 面对少年提到"山上有怪声" → 沉默片刻，然后说"那山一直都有声音。你爷爷那时候就有。别管它。"

**GM 提示**：祖母的每个故事都必须精确对应一个场景，但叙述方式必须像一个记忆模糊的老人在讲 — 混乱、跳跃、前后矛盾。让首次玩家觉得"这老太太在说什么？"，让通关玩家觉得"原来如此"。
