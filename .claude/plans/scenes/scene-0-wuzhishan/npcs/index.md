# NPC 列表

| NPC | 角色定位 | 触发条件 |
|-----|---------|---------|
| [悟空](wukong.md) | 山下的存在 — 不可见，仅以环境感知（震动、热气、叹息）弥漫全场景 | 始终存在（环境层） |
| [祖母](grandmother.md) | 山脚村中的老人 — Scene 1-4 的扭曲镜像，通过四个残缺故事传递历史碎片 | 始终存在（阶段二下山后） |
| [路过的行者](traveler.md) | 沉默的旅人 — 唐僧即将到来的前兆 | 条件触发：山上累计停留 ≥ 4 回合，或 `curiosity_level` ≥ 高 |

**远景存在**：Scene 1-4 所有角色以"痕迹"形式存在 — 废墟、风化旗帜碎片、岩壁刻痕。
