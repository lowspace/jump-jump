# 决策点 C：最后的行为

夕阳将落。少年站在山顶附近的一块平台上。面前是壮阔的山景，脚下是那座"有点怪"的山。他明天还会来砍柴。后天也会。但今天，他觉得应该做点什么。或者什么都不做。

| 选项 | 描述 | 效果 |
|------|------|------|
| **C1 — 种桃核** | 少年从口袋里掏出今天在山上捡到的、从那棵烧焦桃树残根旁找到的一颗干桃核。他在石缝旁的一小片土地上刨了个坑，把桃核埋下去 | `final_act` = 种桃核。→ GM 描述：「你不知道它能不能活。这里土薄，水少，日头毒。但桃核不知道这些。它只知道被埋进了土里，接下来的事不归它管。」→ 在"重新渲染"中，这颗桃核与花果山（Scene 3）的所有变量产生共鸣。 |
| **C2 — 刻名字** | 少年用柴刀在石壁字迹旁边，歪歪扭扭地刻下自己的名字（或者一个只有他自己懂的符号） | `final_act` = 刻名字。→ GM 描述：「四个风化的大字旁边，多了几个歪歪扭扭的小字。大字不知道被谁刻的，小字不知道给谁看的。但它们现在在一起了。」→ 在"重新渲染"中，这个行为与"齐天大圣"（Scene 3）的记忆变量共鸣。 |
| **C3 — 什么都不做** | 少年坐了一会儿，看了看天，然后背起柴下山了 | `final_act` = 无行动。→ GM 描述：「你走了。山没有挽留你。风没有追你。你身后什么都没发生。但你总觉得，你忘了做一件什么事。你说不上来是什么。」→ 在"重新渲染"中，这份"遗忘"与 Scene 0 的核心矛盾（遗忘 vs 铭记）构成镜像。 |
| **C4 — 对着山说一句话** | 少年站在山顶，对着整座山说了一句话。说什么由玩家自由输入 | `final_act` = 对山说话。→ **D20 + 运气检定 DC 17**：成功 — 话说完之后，山沉默了很久。然后脚下传来一声极其微弱的震动。比之前所有震动都轻，轻到也许只是你的错觉。但你选择相信那不是错觉。失败 — 风把你的话吹散了。山什么反应都没有。但你说了。这就够了。→ 在"重新渲染"中，少年的这句话与悟空的状态产生最直接的共鸣。 |
