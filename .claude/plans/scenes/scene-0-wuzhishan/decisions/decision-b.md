# 决策点 B：山体深处的声音

| 选项 | 描述 | 效果 |
|------|------|------|
| **B1 — 贴耳去听** | 少年趴在地上，把耳朵贴在岩石表面 | `mountain_voice` = 倾听。好奇心 +2。进入**核心检定**（见 [阶段二](../phases/phase-2.md) B1 核心检定）。 |
| **B2 — 跑开** | 站起来抓起柴刀就跑。腿脚快，心跳更快 | `mountain_voice` = 逃跑。好奇心 -1。少年快速下山，跳过后续山上事件，直接进入祖母部分。 |
| **B3 — 对着石缝说话** | 鬼使神差地，少年蹲在一条宽石缝旁，朝里面说了一句话。说什么由玩家决定 | `mountain_voice` = 对话。好奇心 +1。进入**石缝对话检定**（见 [阶段二](../phases/phase-2.md) B3 检定）。 |
| **B4 — 下山告诉祖母** | 记住了这件事，打算问祖母 | `mountain_voice` = 告知。好奇心 +1。祖母部分解锁额外对话。 |
