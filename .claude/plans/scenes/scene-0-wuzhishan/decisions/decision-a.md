# 决策点 A：石壁字迹

发现（或未能辨认）字迹后，少年需要决定怎么做。

| 选项 | 描述 | 效果 |
|------|------|------|
| **A1 — 描下来** | 找一块较软的石头，把字迹的轮廓描在自己的柴刀鞘上 | `wall_inscription` = 描下。好奇心 +1。少年在后续回合中会反复看刀鞘上的痕迹。这个动作在"重新渲染"中意义重大。 |
| **A2 — 试图辨认** | 蹲在石壁前仔细研究，用手指沿着笔画摸 | `wall_inscription` = 辨认。好奇心 +1。**D20 + 感知 DC 14**：成功则少年指尖触碰字迹时感到一阵微弱的温热，像是石头内部有什么在回应他的触摸。失败则什么都没感觉到。 |
| **A3 — 忽略** | 看了一眼就走了。山上奇怪的东西多了去了 | `wall_inscription` = 忽略。好奇心不变。场景继续，但少年错过了一个与悟空"隔山感应"的机会。 |
| **A4 — 抹掉** | 用柴刀刮掉字迹。山上的东西越少越好，老人们说不要碰不认识的东西 | `wall_inscription` = 抹掉。好奇心 -1。**D20 + 力量 DC 8**：成功 — 但字迹刻得太深，你只刮掉了表面，轮廓依然在。失败 — 完全刮不动。无论成功失败，你都有一瞬间觉得不应该这么做。 |
