# 重新渲染规则（核心机制）

> **设计说明**：Scene 0 在首次游玩时使用以下所有变量的**默认值**。当玩家完成 Scene 1-4 后，影响力报告将根据实际变量值"重新渲染" Scene 0 — 即改变 Scene 0 中特定细节的描述，形成叙事闭环。以下列出所有来自 Scene 1-4 的变量及其对 Scene 0 的影响。

## Scene 1（陈塘关·骨与莲）变量

| 变量 | 取值 | 对 Scene 0 的重新渲染效果 |
|------|------|--------------------------|
| `knife_choice` | 父刀（默认） | 山上的风中偶尔有金属碰撞的声音，冷而利落 |
| `knife_choice` | 师刀 | 山上的风中有一个极其模糊的声音，像是有人在说"师傅"。少年听不清，以为是鸟叫 |
| `nezha_trust` | ≥ 3 | 烧焦桃树残根旁的泥土里，有一小截布带的残片（哪吒护腕的碎片）。少年不认识，但觉得这布料质地很好，不像山里的东西 |
| `nezha_trust` | < 3 | 无变化 |
| `wushi_presence` | 高 | 某处岩壁上除了"齐天大圣"的字迹外，还有一行更小的、更新的刻痕 — 像是有人用刀刻了什么，但已经看不清了。（武师离开陈塘关后路过此地留下的痕迹） |
| `wushi_presence` | 中/低 | 无额外刻痕 |
| `armguard` | 留下 | 少年在某处废墟的沙土中看到一角布带露出来。他没有捡（或捡了），不知道那是什么 |
| `armguard` | 带走 | 无此细节 |
| `lijing_hesitation` | 高 | 祖母讲故事一时多一句："那个当爹的，说他不是自己儿子的时候……我听说他手抖了。你说他是真狠心还是假狠心？" |
| `lijing_hesitation` | 中/低 | 祖母不提此细节 |

## Scene 2（天蓬·月与逐）变量

| 变量 | 取值 | 对 Scene 0 的重新渲染效果 |
|------|------|--------------------------|
| `tenpeng_last_words` | heard（有人听到了天蓬最后的话） | 祖母讲故事二时多一句："那个将军被赶走的时候，说了一句话。什么话？我忘了。但据说有人听到了。" |
| `tenpeng_last_words` | unheard（默认） | 祖母不提此事 |
| `moon_response` | 回应 | 少年在夜晚（如果场景延长到夜间）看到的月亮比平时亮。也许是错觉 |
| `moon_response` | 沉默（默认） | 月亮如常 |
| `marshal_memory` | 记得自己是谁 | 山上有一块石头表面异常光滑，像是有人（或什么东西）在上面反复摩擦过。形状隐约像一面镜子 — 或者一面盾 |
| `marshal_memory` | 遗忘（默认） | 无此细节 |
| `clerk_choice` | 反抗体制 | 山脚村中偶尔有人提起"听说天上的规矩也不是铁打的"，语气里有一种少年听不懂的希望 |
| `clerk_choice` | 服从（默认） | 无此议论 |

## Scene 3（花果山·石与火）变量

| 变量 | 取值 | 对 Scene 0 的重新渲染效果 |
|------|------|--------------------------|
| `memory_kept` | 铭记 | 石壁上"齐天大圣"四个字明显更清晰 — 不是被重新刻过，而是像字迹本身在抵抗风化。少年辨认检定 DC 降低 2 |
| `memory_kept` | 遗忘（默认） | 字迹如常风化 |
| `peach_tree_fate` | 保留 | 少年在山上看到的不是烧焦的桃树残根 — 而是一棵活着的小桃树。很瘦，很矮，叶子稀疏，但确实活着。在五指山的岩石缝里，不可能生长的地方，长着一棵桃树 |
| `peach_tree_fate` | 毁灭（默认） | 只有烧焦的残根 |
| `monkey_survivors` | 存活 | 少年偶尔在山上看到猴子。不多，三五只。它们远远地看着少年，不靠近，也不跑。像是在等什么人 |
| `monkey_survivors` | 散尽（默认） | 山上没有猴子 |
| `huaguoshan_fire` | 未烧/控制 | 那面风化旗帜碎片上的红色纹路更完整，隐约能看出是一面旗帜的图案 — 像是某种王旗 |
| `huaguoshan_fire` | 全毁（默认） | 旗帜碎片只剩几根丝线 |

## Scene 4（经卷·字与空）变量

| 变量 | 取值 | 对 Scene 0 的重新渲染效果 |
|------|------|--------------------------|
| `final_scroll` | 自己的话 | 少年在某块石头下发现一张折叠的纸。纸很旧，但保存得很好，像是有人特意放在那里的。上面写着一句话。少年识字不多，只认出了几个 — 但他觉得这句话很重要，虽然他说不出为什么。（这是法明/唐僧写的） |
| `final_scroll` | 佛经原文（默认） | 无此发现 |
| `faming_faith` | 保持 | 祖母讲故事四时语气更笃定："那个和尚说经书上没字。别人都骂他胡说。但我觉得他说得对。什么都没写的东西，你往里面看到什么，那就是什么。" |
| `faming_faith` | 崩塌（默认） | 祖母讲完故事四后说："我听不懂。你听得懂吗？"语气困惑 |
| `scripture_truth` | 揭露 | 山上某处岩石的自然纹路在特定角度看起来像一个"空"字。也许是巧合 |
| `scripture_truth` | 隐藏（默认） | 无此细节 |
| `traveler_destination` | 继续西行 | 路过的行者（条件触发NPC）脚步更坚定，走得更快。他路过少年时，少年觉得这个人身上有一种"知道自己要去哪"的气质 |
| `traveler_destination` | 放弃/转向（默认） | 行者脚步正常，表情平静但看不出方向感 |

## 跨场景综合变量

| 条件 | 对 Scene 0 的重新渲染效果 |
|------|--------------------------|
| 四个场景中 ≥ 3 个场景的核心选择倾向"铭记/反抗/坚守" | 少年在整个场景中的"好奇心"基础值 +1。他更容易注意到细节，更容易被遗迹吸引。叙述语气更温暖 |
| 四个场景中 ≥ 3 个场景的核心选择倾向"遗忘/服从/放弃" | 少年在整个场景中感受到一种淡淡的悲伤，但说不出来源。叙述语气更沉静。山上的遗迹看起来更荒凉 |
| 所有四个场景都完成了"杨戬/杨戬线索"的条件触发 | 少年下山时看到路边石头上坐着一条黑狗。狗看了他一眼，然后跑进了树林。很普通的事。但少年觉得那条狗的眼神很奇怪 — 不像狗 |
| `grandmother_stories` = 4 且所有场景均完成 | 影响力报告的"重新渲染"中，祖母在讲完四个故事后会说一段额外的话："这些故事啊……我以前觉得是编的。但你知道吗，有时候我半夜醒来，会觉得这些故事比我的命还真。那些人 — 那个孩子、那个将军、那些猴子、那个和尚 — 他们比我活得更真。也许因为他们做了我不敢做的事。" |

## 派生变量说明

上述重新渲染表中使用的部分变量（如 `moon_response`, `marshal_memory` 等）不是由各场景直接输出，而是基于源变量通过特定规则**派生**得出。

详细派生规则见：`/Users/dnhb/Desktop/GitHub/My_Projects/jump-jump/.claude/plans/scenes/scene-0-wuzhishan/derived-variables.md`

### 派生变量速查表

| 派生变量 | 源变量 | 派生规则简述 |
|----------|--------|--------------|
| `moon_response` | `tenpeng_last_words` | 听到天蓬的话 + 选择等待/观察 → 回应 |
| `marshal_memory` | `survival_method` | 生存方式含自我记忆 → 记得 |
| `clerk_choice` | `ledger_choice` | 揭发 → 反抗体制 |
| `monkey_survivors` | `monkey_unity` | 团结→存活, 分裂→部分存活, 散去→无 |
| `huaguoshan_fire` | `peach_tree_fate` + `resistance_choice` | 砍掉 或 (反抗且不满足隐藏条件) → 全毁 |
| `faming_faith` | `faith_state` | 直接映射：坚定→保持, 动摇→困惑, 重建→重建, 崩塌→崩塌 |
| `scripture_truth` | `sutra_truth` | 直接映射：禅意→禅意, 政治/悖论→揭露, 不理解→隐藏 |
| `traveler_destination` | `tangseng_encounter` + `faith_state` | 深度对话且信仰未崩塌 → 继续西行 |
