# 阶段流程概览

| 阶段 | 名称 | 目的 | 回合数 |
|------|------|------|--------|
| [阶段一](phase-1.md) | 上山（探索 + 发现遗迹） | 建立场景氛围，通过遗迹探索让玩家接触到 Scene 1-4 的"痕迹"。培养好奇心 | 2-3 回合 |
| [阶段二](phase-2.md) | 山中（感知 + 祖母的故事） | 山上的感知体验 + 下山后祖母的四个故事（Scene 1-4 扭曲镜像） | 2-3 回合 |
| [阶段三](phase-3.md) | 黄昏（抉择 + 结尾） | 场景收束。少年做出最后的行为，种下"种子" | 1-2 回合 |

**总计**：5-7 回合 + 最多 2 回合弹性延长（当行者触发或祖母讲第 4 个故事时）
