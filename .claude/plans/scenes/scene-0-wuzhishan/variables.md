# 程度输出变量（流向影响力报告）

| 变量名 | 取值范围 | 影响去向 |
|--------|---------|---------|
| `wall_inscription` | 描下/辨认/忽略/抹掉 | 影响力报告中"齐天大圣"记忆的存续方式 |
| `mountain_voice` | 倾听/逃跑/对话/告知 | 影响力报告中少年与悟空"隔山感应"的深度 |
| `final_act` | 种桃核/刻名字/无行动/对山说话 | 影响力报告最终叙事闭环的情感支点 |
| `grandmother_stories` | 0-4 | 影响力报告中"重新渲染"时祖母段落的丰富度 |
| `curiosity_level` | 高/中/低 | 影响力报告中少年角色弧的完整度 + 行者是否出现 |
| `wukong_awareness` | 意识到/隐约感觉/完全不知道 | 影响力报告中"封印与等待"叙事线的呈现方式 |
