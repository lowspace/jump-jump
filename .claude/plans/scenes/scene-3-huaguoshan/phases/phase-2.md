# 阶段二：探索（水帘洞 + 山顶）

**场景**：石卵获得了一段独处时间 — 无论是被派去看水源还是自己找借口离开。花果山虽然残破，但石卵在这里长大，每一条暗道、每一个石缝他都记得。

**目的**：探索废墟，发现关键物件（桃木棍、桃树），触发情感记忆。

### 路线选择

石卵有两个可探索的方向。回合有限，两个都去需要消耗更多行动。

---

#### 路线 A — 回到水帘洞深处

**场景**：水帘洞。瀑布还在流，但洞口已经半塌。石卵从侧面的窄缝挤进去 — 这是他当初躲藏的那条路。

洞内的情况：前厅被天兵搜过了，桌椅砸烂，酒坛摔碎，地上还有干涸的血迹。但往里走，越走越窄，天兵的痕迹消失了 — 他们进不来。

宝座还在。

> 石头凿出来的宝座。大王以前坐在上面，一只手撑着下巴，另一只手拿着桃子。猴兵猴将排在下面，喊「大王千岁千岁千千岁」。那时候你站在最后一排，踮着脚尖才能看见大王的头顶。
>
> 现在宝座上落满了灰。蜘蛛在扶手上结了网。没有人坐在上面。

**D20 + 观察检定 DC 10**：
- **成功**：你注意到宝座旁边的石缝里插着一样东西 — 一根桃木棍。不长，大约两尺，削得很粗糙，一头尖一头圆。不是金箍棒 — 金箍棒在大王耳朵里，跟他一起被压住了。这只是……一根棍子。你想起来了 — 大王有时候无聊了会拿石头削木头玩。他削出来的东西从来不好看，但他自己很高兴。
- **失败**：你只看到宝座和灰尘。但如果你在后续回合再来，可以重新检定。

**如果找到桃木棍**：

你把棍子拿起来。桃木的纹路还在，有淡淡的香气 — 桃木的香气。你的手刚好能握住圆的那头。

> 「微光时刻」：你握着这根棍子，突然觉得 — 大王也握过这个地方。你的手和他的手，隔着时间，握在了同一个位置上。
>
> 你说不上来这算什么感觉。不是开心，不是悲伤。只是 — 好像他没有完全不在。

**玩家选择**：

| 选择 | 效果 |
|------|------|
| 把棍子带走 | `wukong_stick` = 保留。这根棍子会成为后续决策的情感锚点。 |
| 把棍子留在宝座旁 | `wukong_stick` = 留下。你觉得它应该待在这里 — 等大王回来。 |

**额外发现 — 暗线触发（Scene 1 连接）**：

**条件**：Scene 1 `armguard` = 带走

在水帘洞深处的一个角落，石卵翻到一块布料。不是旗帜，不是衣服 — 更像是一条绑带，绑在什么东西外面的那种。布料已经旧了，但缝补过的针脚还能看清。

> 你不知道这是什么。但你把它拿在手里的时候，心里浮起一个念头：「有些东西值得留着。」
>
> 你不知道这个念头从哪来的。

这是 Scene 1 中武师带走护腕的涟漪 — 「保留」的选择跨越场景回响到了石卵心中。

**条件**：Scene 1 `wushi_presence` = 高

当天夜里，石卵在洞中睡着了。他做了一个梦：梦见一个不认识的人站在一个少年旁边。那人没有动，只是看着。少年在做一件很痛的事，但那人始终没走。

石卵醒来。他不认识梦里的人，但他觉得心里踏实了一点 — 好像有人在告诉他，「在旁边看着」这件事本身是有意义的。

---

#### 路线 B — 上山顶

**场景**：花果山山顶。以前这里是桃林最密的地方。现在只剩焦黑的树桩和灰烬。天兵放火烧山的时候，桃林首当其冲。

石卵爬上山顶。风很大。能看到远处的海 — 东海。大王就是从那片海里蹦出来的。

然后他看到了那棵桃树。

> 它长在山顶背面的一处岩石夹缝里。位置太偏了，太刁钻了，藏在两块大石头的阴影里。天兵放火的时候，火烧不到这个角落。
>
> 桃树不高，枝干也不粗。叶子是绿的 — 在一片焦黑中，这一点绿刺眼得让你想哭。
>
> 树上有三颗桃子。还没熟。青的。

**无需检定**：石卵直觉知道这棵树的意义。它是花果山最后的标志。它活着，就意味着花果山还没有完全死去。

但石卵同样直觉知道另一件事：如果天兵看到这棵树，他们会知道这里还有「齐天大圣的痕迹」。一棵活着的桃树，在被烧尽的花果山上，比一面旗帜更显眼。

**玩家可选方向**：

| 选择 | 效果 |
|------|------|
| 记住位置，先不告诉任何人 | 保持信息优势。你在后续阶段可以选择告诉谁。 |
| 立刻回去告诉老猴 | 老猴会沉默很久，然后说：「……我知道有这棵树。我没跟任何人说过。」你们共享了一个秘密。老猴好感度 +1。 |
| 立刻回去告诉铁头 | 铁头的眼睛会亮起来：「大王的桃树！它还活着！我说了，大王的东西天庭毁不完！」铁头好感度 +2，但他可能会做出冲动的举动（守在桃树旁不走）。 |
