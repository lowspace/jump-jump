# 阶段三：分裂与决断（核心冲突 + 紫霞触发）

**场景**：第二天。猴群的裂痕已经无法掩盖。消息传开了 — 不管石卵告诉了谁，桃树的存在最终被所有猴子知道了。（如果石卵谁都没告诉，那是铁头自己探索时发现的。这棵树的发现是不可避免的 — 它的存在本身就是一个必须面对的事实。）

与此同时，老猴带来了消息：天兵的巡逻频率变了。

> 「以前是三天来一次。现在两天就来了。而且来的人多了 — 上次是五个，这次我数了八个。」

**条件分支（Scene 2 连接）**：
- Scene 2 `ledger_choice` = 揭发 → 天庭加强了全面管控，花果山也受到波及。天兵巡逻从三天一次变为**每天一次**，时间压力极大。老猴额外补充：「听说下面人间出了什么事，天庭那边管得更紧了。」
- Scene 2 `ledger_choice` ≠ 揭发 → 巡逻频率仅小幅增加（三天变两天），时间窗口相对宽裕。

### 决策点 A：猴群会议

猴群在岩洞中开会。说是开会，其实就是吵架。

老猴的立场：
> 「散了。各自跑。往深山里钻，不要聚在一起。天兵找的是'猴群' — 零散的猴子他们不会在意。把桃树砍了，把旗帜烧了，什么痕迹都不要留。活下来比什么都重要。」

铁头的立场：
> 「凭什么？！大王的山，大王的桃树，大王的旗 — 凭什么我们要亲手毁掉？天兵没毁掉的东西，我们自己毁？大王要是回来了，看到什么都没了，他……」

铁头说不下去了。他的嘴唇在抖。

> 「他会以为我们把他忘了。」

沉默。很长的沉默。然后幼猴中最小的那只开始哭。

### 可获取信息

| 信息 | 获取方式 | 洞察要求 |
|------|---------|---------|
| 老猴的「散」是真心的 — 他不是在逃避，是真的认为这是唯一能让大家活下来的办法 | 观察老猴的表情 | DC 9 |
| 铁头的「守」背后有恐惧 — 他不是不怕死，而是比起死更怕「大王回来后什么都没有了」 | 观察铁头在沉默时的手（在抖） | DC 12 |
| 已经有两只猴子在偷偷收拾东西，准备当夜就跑 | 注意猴群角落的动静 | DC 11 |
| 那三只投了天庭「招安」的猴子可能已经把花果山还有幸存者的消息泄露了 — 天兵巡逻增加可能跟这个有关 | 综合分析信息 | DC 14 |

### 关键交互：石卵被问到

争吵到最后，两方都看向石卵。

老猴：
> 「石卵，你说。」

铁头：
> 「你也是大王的猴子。你说。」

这一刻石卵不是「杂役」了。他是「被问到的人」。

**这不是最终决策 — 这是立场表态。最终的核心决策在决策点 B。**

**玩家可选方向**：

| 回应方向 | 效果 |
|---------|------|
| 支持老猴（「活下来最重要。」） | 老猴松了口气。铁头看着你，眼里有失望，但没有恨。猴群情绪偏向「散」，但铁头不会跟着散。他会独自留在山上。 |
| 支持铁头（「大王的东西不能丢。」） | 铁头感激地看着你。老猴摇头，叹了一口气。猴群分裂加剧 — 一部分跟老猴走，一部分跟铁头留。 |
| 说出自己的想法（需要玩家主动思考） | GM 根据玩家的具体提议判定效果。如果提出「第三条路」（例如：移植桃树到隐蔽处 / 分批撤离但约定重聚 / 把记忆藏在看不见的地方），**D20 + 说服 DC 14**：成功则双方愿意听下去，你获得主导后续决策的机会。失败则被认为「想得太多」。 |
| 「我不知道。」（诚实但无力） | 沉默。没有人怪你 — 因为没有人知道正确答案。猴群继续僵持。但你的诚实被记住了。 |

### 紫霞触发

**触发条件**：石卵在阶段二中去过山顶（路线 B），且在山顶停留时选择了「沉默/独处」而非立刻回去报告。

**时间**：猴群会议争吵得最凶的时候，石卵独自走出岩洞透气。月光很亮。

**场景**：山腰的一块平石上。石卵坐在那里看月亮。然后他听到了脚步声 — 不是猴子的脚步（猴子习惯攀爬，落地很轻），也不是天兵的脚步（天兵穿铠甲，走路有金属声）。是一双布鞋踩在石头上的声音。

他回头，看到一个女子。

> 她不像猴子 — 当然不像，她是人的样子。也不像天兵。她穿着素色的衣裳，头发散着，像赶了很远的路。
>
> 她站在那里看着花果山。看了很久。然后她看到了石卵。
>
> 她的眼睛里有一种你见过的东西 — 你在铁头眼里见过，在老猴眼里也见过。是失去了什么很重要的东西之后，还在找的那种眼神。

紫霞开口。她只问了一句话：

> 「他还好吗？」

**D20 + 洞察检定 DC 13**：
- **成功**：你隐约觉得她问的不是一般的「他」。她问的那个人对她来说很重要。你不知道她在找谁，但你感受到了她在找的那种力度 — 就像你们在找大王一样。
- **失败**：你以为她在找什么走散的亲人。

**玩家可选回应**：

| 回应方向 | 效果 |
|---------|------|
| 「你找谁？这里没有人了。」 | 紫霞安静了一会儿。「没有人了……」她重复了一遍。然后她笑了一下 — 那个笑容让你很难受，因为那不是开心的笑。「也好。没有人就不会再受伤了。」她转身走了。`zixia_encounter` = 遇到但未回答。 |
| 「你说的他是谁？山上以前有很多猴子。」 | 紫霞摇头：「不是猴子。是……」她停住了，好像在想该怎么说。最后她只是说：「是一个很傻的人。」你问她：「他怎么傻？」她说：「他明知道打不赢还要打。明知道会被压住还要闹。」你突然心里一动 — 她说的是大王吗？但她不像知道大王的人。你不确定。`zixia_encounter` = 遇到且间接回答。 |
| 告诉她关于大王的事（「你说的是……大王？齐天大圣？他被压在山下了。」） | 紫霞不说话了。很久很久不说话。月光打在她脸上，你看到她的表情没有变 — 但她的手攥紧了衣角。然后她轻声说：「谢谢你告诉我。」她的声音很稳，但你听得出来 — 那种稳是硬撑出来的。她又问：「他疼不疼？」你不知道怎么回答。她也没等你回答。她朝你点了点头，走了。`zixia_encounter` = 遇到且直接回答。 |
| 沉默，陪她坐着 | 你们并排坐在石头上，看着残破的花果山。她没有再问。你也没有说。过了很久，她站起来，轻轻摸了一下你的头顶 — 就像大猴子安抚小猴子的那种动作。她的手很温暖。然后她走了。你不知道她是谁，但你知道她跟你一样 — 在想念一个不在的人。`zixia_encounter` = 遇到且沉默陪伴。 |

> **慰藉时刻**：无论石卵选了哪个回应，在紫霞离开之后，石卵会发现自己坐着的那块石头上，不知什么时候多了一朵小花。以前没有的。石卵不知道这是怎么回事。他把花摘下来，夹在了耳朵上。
>
> 花第二天就枯了。但那个晚上，石卵觉得不那么冷了。
