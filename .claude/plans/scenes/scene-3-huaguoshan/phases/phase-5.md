# 阶段五：巡逻来了（紧迫时刻 + 终局）

**场景**：石卵的决定刚做出不久。远处传来了铠甲碰撞的声音。天兵来了。

### 天兵巡逻

天兵队长带着七名士兵沿山路上行。他们的路线经过水帘洞旧址和桃林遗迹。如果桃树还在山顶，他们的巡逻路线末端会经过。

**猴群必须做出反应**：

#### 路线 α — 隐藏（适用于「砍掉桃树」或「移植桃树」后的猴群）

猴群躲在岩洞中，屏息等待。

**D20 + 隐匿检定 DC 11**（整个猴群的隐藏效果）：
- **成功**：天兵经过，没有发现异常。队长在花果山转了一圈，对副官说：「这地方已经没什么了。回去上报吧。」猴群安全。
- **失败**：一只幼猴不小心弄出了声响。天兵停下脚步，朝岩洞方向看。

**失败后的补救**：
- **D20 + 机智检定 DC 13**：石卵可以制造干扰（扔石头引开注意力/模仿鸟叫），让天兵以为是野兽。
- 如果补救也失败：天兵发现了岩洞。进入强制交互。

#### 路线 β — 对峙（适用于「保留桃树」后铁头坚持守在树旁的情况）

铁头拒绝躲藏。他站在桃树旁边，手里握着一根削尖的木棍。

> 「来啊。」

老猴在岩洞里急得浑身发抖：「那个傻孩子！」

**石卵的选择**：

| 选择 | 效果 |
|------|------|
| 去拦铁头 | **D20 + 说服 DC 15**（在天兵到达前说服铁头撤退）：成功则铁头含泪退回。失败则铁头推开你：「你走，我不走。」 |
| 站在铁头旁边 | 你和铁头一起面对天兵。你没有武器，没有法力。但你站在那里。铁头看了你一眼 — 他的眼里有你在「齐天大圣旗」那天没见过的东西：不是怒火，是感激。 |
| 回岩洞保护其他猴子 | 你选择了保护更多的生命。铁头独自面对天兵。 |

#### 天兵队长的判定

**如果天兵发现了猴群（无论是哪条路线）**：

天兵队长走上前。他看着这群猴子 — 老的老，小的小，瘦得像柴火棍。

队长的行为取决于他看到了什么：

| 队长看到的 | 队长的反应 |
|-----------|----------|
| 只有零散的猴子，没有任何齐天大圣的标志物 | 「几只野猴子。」他对副官说。然后他走了。他选择当作没看到。**这是那颗螺丝松动了一下的时刻。** |
| 猴子 + 齐天大圣的旗帜 / 桃树 | 队长的脸色变了。「上报。」他没有动手 — 但他启动了程序。后续会有更大规模的清剿。猴群必须在增援到达前全部撤离。 |
| 铁头持棍对峙 | 队长叹了口气。他看着铁头，看了很久。然后他说了一句话：「小猴子，你打不过我的。放下棍子，走吧。我可以说没看到你。」**D20 + 洞察 DC 12**（石卵判断队长是否在说真话）：成功则石卵相信他是认真的 — 这个天兵在网开一面。失败则石卵无法确定。 |

**铁头面对队长的劝退**：

| 条件 | 铁头的反应 |
|------|----------|
| 石卵站在铁头旁边 + 石卵之前说服过铁头至少一次 | 铁头看了看石卵，看了看队长。他的手在抖，但他慢慢放下了棍子。不是因为怕了 — 是因为石卵在旁边，他不想让石卵也死。「……走。」 |
| 石卵不在旁边 / 从未成功影响过铁头 | 铁头不会放下棍子。他会冲上去。天兵队长会把他打倒 — 不会杀他，但会打断他一条腿。「我说了，放下。」铁头倒在地上，还在骂。 |
