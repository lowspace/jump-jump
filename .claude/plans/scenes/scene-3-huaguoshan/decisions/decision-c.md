# 微决策点 C：齐天大圣的名号

**所在阶段**：阶段六
**类型**：微决策

天兵走后的那天晚上。猴群 — 不管还剩几只 — 围在一起。没有人说话。幼猴已经睡了。

老猴开口。他的声音很轻，像怕惊动什么：

> 「以后不要再提'齐天大圣'了。那四个字 — 天兵听到了就是死罪。」

铁头（如果他还在且没受重伤）：

> 「你让我忘了大王？」

老猴：

> 「我没让你忘。我让你不要说出来。记在心里和说出来是两回事。」

**玩家选择**：

| 选择 | 效果 |
|------|------|
| 「老猴哥说得对。记在心里就行了。」 | `memory_kept` = 暗中传承。齐天大圣的名号从此成为花果山幸存猴群的暗语 — 不说出口，但所有猴子都记得。这个记忆会像种子一样传下去。 |
| 「不。那个名字不能只放在心里。得有人记得，得有人说。」 | `memory_kept` = 铭记。猴群中有一部分猴子会继续传颂齐天大圣的故事 — 冒着危险，但从未断绝。 |
| 「也许……换一种方式记。不用那四个字，用别的。用桃子、用山、用水帘洞的声音来记。」 | `memory_kept` = 暗中传承（变体）。猴群发明了自己的暗号系统 — 用花果山的事物替代「齐天大圣」。「桃子熟了」= 有人还记得大王。「水帘洞还在流」= 我们还在。 |
| 不表态，沉默 | `memory_kept` = 由老猴和铁头的力量对比决定。如果铁头仍在且未受重创 → 铭记。如果铁头离开或重伤 → 遗忘。 |
