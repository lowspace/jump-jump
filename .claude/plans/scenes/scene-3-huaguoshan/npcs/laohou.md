# 老猴 — 活过两个时代的记忆

**身份**：花果山最年长的猴子，悟空之前的长老。他记得花果山还没有大王的时候 — 那时候猴子们吃野果、喝山泉、怕老虎、怕猎人，日子过得战战兢兢但至少活着。他也记得悟空来了之后的日子 — 桃树满山、水帘洞里有瀑布、猴子们称王称霸。然后他记得天兵来了。

**核心动机**：让猴群活下来。不是活得好，只是活着。他见过太多东西了 — 见过悟空打遍天宫的狂喜，也见过天兵屠山的血。在他的经验里，「辉煌」和「灾难」是同一个硬币的两面。悟空带来的一切美好，最终都以十倍的代价收走了。

**底线**：不会主动出卖任何猴子给天庭。但如果天兵真的打过来，他会让猴群跪下 — 「死了就什么都没了。」

**秘密**：他曾经劝过悟空不要去天宫。悟空笑着说「老头，你怕什么？」他没敢再劝。他的愧疚不是没劝住悟空，而是 — 悟空说得对，他确实怕。他一辈子都在怕。

**行为模式**：
- 面对威胁 → 评估、退让、保存实力
- 面对铁头的激进 → 又急又心疼，语气严厉但眼神柔软
- 面对石卵 → 把石卵当「还能教的孩子」，愿意多说几句
- 面对悟空的遗物 → 回避。不敢看宝座，不敢提那个名字。

**价值优先序**：猴群存活 > 花果山的延续 > 对大王的忠诚 > 自己

**口头禅**：「大王在的时候我们活得好，大王不在了我们还得活。」

**GM 提示**：老猴不是反派，也不是懦夫。他是一个已经被恐惧耗尽但仍然在保护别人的老人。他选择「忘记」不是因为不在乎悟空，而是因为他知道记忆的代价 — 记得齐天大圣的猴子不会老老实实活着，而不老实就会死。他的每一次劝说都是在用自己的恐惧保护别人。
