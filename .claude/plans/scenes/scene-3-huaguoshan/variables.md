## 场景特定变量

### `collective_memory_tone`（集体记忆基调）

**取值范围**：敌意 / 中性 / 同情 / 怀念 / 恐惧

**派生规则**：
- 基于 `monkey_unity` 和 `memory_kept` 综合派生
- `monkey_unity`=团结 + `memory_kept`=铭记 → **怀念**：猴群公开传颂齐天大圣
- `monkey_unity`=团结 + `memory_kept`=暗中传承 → **同情**：猴群以隐喻方式延续记忆
- `monkey_unity`=分裂 → **中性**：猴群内部对齐天大圣的记忆存在分歧
- `monkey_unity`=散去 或 `memory_kept`=遗忘 → **恐惧**：齐天大圣成为禁忌话题

**用途**：影响力报告中「猴群集体记忆」叙事基调
