# 回响（Echoes）

## 入站回响（从前序场景流入）

### Scene 1 → Scene 3

**条件**：Scene 1 `armguard` = 带走

在水帘洞深处的一个角落，石卵翻到一块布料。不是旗帜，不是衣服 — 更像是一条绑带，绑在什么东西外面的那种。布料已经旧了，但缝补过的针脚还能看清。

> 你不知道这是什么。但你把它拿在手里的时候，心里浮起一个念头：「有些东西值得留着。」
>
> 你不知道这个念头从哪来的。

这是 Scene 1 中武师带走护腕的涟漪 — 「保留」的选择跨越场景回响到了石卵心中。

---

**条件**：Scene 1 `wushi_presence` = 高

当天夜里，石卵在洞中睡着了。他做了一个梦：梦见一个不认识的人站在一个少年旁边。那人没有动，只是看着。少年在做一件很痛的事，但那人始终没走。

石卵醒来。他不认识梦里的人，但他觉得心里踏实了一点 — 好像有人在告诉他，「在旁边看着」这件事本身是有意义的。

### Scene 2 → Scene 3

**条件**：Scene 2 `ledger_choice` = 揭发

天庭加强了全面管控，花果山也受到波及。天兵巡逻从三天一次变为**每天一次**，时间压力极大。老猴额外补充：「听说下面人间出了什么事，天庭那边管得更紧了。」

## 出站回响（流向后续场景 / 影响力报告）

### 桃树命运涟漪（P6 核心）

- `peach_tree_fate` = 移植到五指山附近 → 影响力报告中「五指山下被压着的悟空旁边多了一棵桃树」
- `peach_tree_fate` = 砍掉 → 花果山彻底沉寂
- `peach_tree_fate` = 保留 → 花果山仍有被清剿的风险但标志尚存

### 紫霞信息涟漪

- `zixia_encounter` = 遇到且直接回答 → 紫霞知道悟空被压在五指山，她的后续行动会改变（影响力报告/后续场景）
- `zixia_encounter` = 未遇到 → 紫霞的寻找继续，但没有线索

- `resistance_choice` 的各取值 → 影响力报告中描述石卵的后续命运
