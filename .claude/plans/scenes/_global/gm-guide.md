# GM 使用指南

> 本文档为《Jump Jump》游戏主持人（GM）提供完整的系统使用指南，包括洞察系统、回响处理、Scene 0 重新渲染等核心机制的操作说明。

---

## 章节 1：洞察系统使用指南

### 1.1 简化洞察系统概述

《Jump Jump》采用简化的洞察系统，摒弃传统的 D20 检定和复杂修正值：

- **固定配额**：每场景 2 次「真实目的」+ 2 次「幕后对话」
- **无随机性**：洞察结果确定，无需检定
- **消耗制**：每次查询消耗 1 点对应洞察

| 洞察类型 | 配额 | 效果 |
|---------|------|------|
| 真实目的 | 2 次 | 揭示当前 NPC 的隐藏意图（仅对下一次查询有效） |
| 幕后对话 | 2 次 | 揭示 DFS 对话链的隐藏层（信息流向、真实目的） |

### 1.2 Scene 2 混合机制说明

Scene 2（天河档案司）是唯一同时使用传统 D20 检定和洞察系统的场景。

#### 何时使用传统 D20

| 场景 | 检定类型 | DC | 说明 |
|------|---------|-----|------|
| 说服陆执 | 说服 | 13 | 改变陆执对某事的立场 |
| 欺骗天蓬 | 欺骗 | 11 | 对天蓬隐瞒真实意图 |
| 对抗性检定 | 对抗 | 视情况 | 与 NPC 立场直接冲突时 |
| 档案检索 | 调查 | 12 | 在档案库中查找特定信息 |

**GM 判定原则**：
- 涉及**人际关系博弈** → 使用 D20
- 涉及**信息获取/秘密揭示** → 使用洞察系统
- 两者重叠时，优先询问玩家意图，再决定机制

#### 何时使用洞察系统

| 场景 | 使用洞察 | 效果 |
|------|---------|------|
| 阅读天蓬档案 | 真实目的 | 揭示天蓬写档案时的真实心境 |
| 观察陆执微表情 | 真实目的 | 揭示陆执隐藏的担忧 |
| 追踪信息流向 | 幕后对话 | 揭示某条信息如何在天庭内部流转 |
| 理解第七窍暗示 | 幕后对话 | 揭示第七窍相关的隐藏对话层 |

### 1.3 GM 决策流程图

```
玩家行动
    │
    ▼
是否涉及信息获取/秘密揭示？
    │
    ├── 是 → 玩家是否有剩余洞察配额？
    │           │
    │           ├── 是 → 使用洞察系统，消耗配额
    │           │           │
    │           │           ▼
    │           │       直接揭示隐藏信息
    │           │
    │           └── 否 → 提供表层信息
    │                       │
    │                       ▼
    │                   提示可通过洞察获得更多信息
    │
    └── 否 → 是否涉及人际博弈/对抗？
                │
                ├── 是 → 使用 D20 检定
                │           │
                │           ▼
                │       根据结果提供信息
                │
                └── 否 → 直接描述，无需检定
                            │
                            ▼
                        提供叙事信息
```

### 1.4 洞察使用示例

**场景**：玩家想理解陆执为什么对封神榜如此执着。

**GM 处理**：

1. 判断：这属于「信息获取/秘密揭示」→ 优先洞察系统
2. 询问：「你想使用『真实目的』洞察来了解陆执的隐藏动机吗？」
3. 若使用：
   > 「陆执表面上说『这是规矩』，但他的眼神在提到『名字』时有一瞬间的恍惚。
   > 隐藏意图：陆执真正执着的不是封神榜本身，而是『被记住』——他害怕像那些无名小卒一样消失在档案里。」
4. 若不用：
   > 「陆执重复了一遍：『这是规矩。』他的语气没有变化。」

### 1.5 洞察配额管理

**记录方式**：

在每个场景开始时，GM 应在心里或笔记中记录：

```
场景：Scene X
洞察配额：
- 真实目的：[ ] [ ] （2 次）
- 幕后对话：[ ] [ ] （2 次）

使用情况：
- 第 1 次真实目的：用于 [NPC/场景]，剩余 1 次
- ...
```

**未使用洞察的处理**：

- 场景结束时仍有剩余 → 触发**完整场景复盘**
- 全部使用完毕 → 仅在游戏结束时提供完整回顾

## 章节 2：回响处理指南

### 2.1 回响级别定义

| 级别 | 定义 | 玩家感知 |
|------|------|---------|
| **显著（Prominent）** | 直接影响叙事主线或核心情感 | 必然注意到 |
| **细微（Subtle）** | 背景细节或彩蛋式线索 | 可能错过，但不影响主线 |
| **系统（Mechanical）** | 改变游戏机制（DC、修正值等） | 明确告知 |

### 2.2 快速参考表

| 回响级别 | 处理方式 | GM 话术示例 | 触发时机 |
|----------|----------|-------------|---------|
| 显著 | 直接描述，确保玩家注意 | 「你注意到……」<br>「突然，你感到……」<br>「那一刻，你清楚地看到……」 | 自动触发 |
| 细微 | 可通过好奇/洞察检定引导 | 「如果你仔细观察……」<br>「周围似乎有什么……」<br>「（可选）你想仔细看看吗？」 | 玩家主动探索时 |
| 系统 | 明确告知机制变化 | 「你发现……（DC 降低 2）」<br>「由于……，你获得 +1 修正值」 | 自动触发 + 明确说明 |

### 2.3 各级别处理详解

#### 显著回响（Prominent）

**处理原则**：
- 直接描述，不需要玩家检定
- 确保玩家注意到关键细节
- 使用感官描写（视觉、听觉、触觉）增强印象
- 适当停顿，给玩家消化信息的时间

**示例**（E06 - 石卵梦境）：

> 「那天晚上，石卵做了一个梦。
>
> 梦里，他站在水帘洞口。旁边站着一个人——他不认识那个人，看不清脸，但知道那个人始终没有走。
>
> 醒来后，石卵心里踏实了一点。他不知道那个人是谁，但『在旁边』这件事本身，好像就够了。」

**GM 要点**：
- 使用分段叙述制造停顿感
- 强调情感变化（「踏实了一点」）
- 不解释来源，保持神秘感

#### 细微回响（Subtle）

**处理原则**：
- 可通过「好奇」或「洞察」检定引导玩家发现
- 不作为主线阻碍，作为彩蛋奖励
- 玩家主动探索时给予额外信息
- 不强制玩家发现，保持探索的乐趣

**示例**（E01 - 父刀回响）：

> 「山上的风很大。
>
> （可选）你想仔细听听风声吗？
>
> [若玩家选择探索] 你停下来，仔细听。风里偶尔有金属碰撞的声音，冷而利落，像是……刀鞘撞击铠甲？你不确定。」

**GM 要点**：
- 先给出表层描述
- 提供探索选项
- 玩家主动探索后才揭示细节
- 细节保持模糊，不直接解释

#### 系统回响（Mechanical）

**处理原则**：
- 明确告知玩家机制变化（如「DC 降低 2」）
- 与叙事结合说明（如「字迹更清晰了」）
- 在机制触发时给出清晰的反馈
- 帮助玩家理解选择带来的实际影响

**示例**（E21 - 铭记回响）：

> 「石壁上的字——『齐天大圣』——比你记忆中清晰得多。
>
> 不是因为阳光。那些笔画像是……在抵抗风化。每一笔都比你上次看时更深了一点。
>
> **【系统】由于「铭记」回响，辨认字迹的 DC 降低 2。**
>
> 少年眯起眼睛。这次他几乎能看清每一个笔画了。」

**GM 要点**：
- 先叙事描述
- 然后明确标注机制变化
- 最后回到叙事
- 保持「叙事-机制-叙事」的节奏

### 2.4 回响触发检查清单

每个场景结束时，GM 应检查：

```
□ 本场景产生了哪些新变量？
□ 这些变量会影响哪些后续场景？
□ 是否有跨场景回响需要记录？
□ Scene 0 重新渲染时需要更新哪些元素？
```

## 章节 3：Scene 0 重新渲染指南

### 3.1 重新渲染概述

Scene 0（五指山少年）是游戏的**倒叙开场**和**闭环收尾**。玩家先体验 Scene 0 的初始版本，在完成其他场景后，Scene 0 会根据累积的变量**重新渲染**。

**重新渲染时机**：
- 完成 Scene 1-4 后（影响力报告前）
- 特定里程碑达成时（可选）

### 3.2 派生变量计算

Scene 0 的重新渲染依赖于**派生变量**，这些变量由 Scene 1-4 的核心变量计算得出。

#### 核心派生变量

| 派生变量 | 计算公式 | 影响范围 |
|---------|---------|---------|
| `memory_guardian_index` | (`memory_kept` + `scripture_truth` + `peach_tree_fate` 保留/移植) / 3 | 整体氛围、少年好奇心 |
| `resistance_score` | (`knife_choice` = 师刀 ? 1 : 0) + (`ledger_choice` = 揭发 ? 1 : 0) + (`monkey_unity` = 团结 ? 1 : 0) + (`final_scroll` = 自己的话 ? 1 : 0) | 叙事色温、遗迹状态 |
| `abandonment_score` | 4 - `resistance_score` | 悲伤氛围、荒凉程度 |
| `wushi_presence_derived` | `wushi_presence` + (`nezha_trust` >= 3 ? 1 : 0) | 岩壁刻痕、风的声音 |
| `faith_echo` | `faith_state` 映射值 | 祖母讲故事的语气 |

#### 变量映射表

| 源变量 | 值 | 派生影响 | Scene 0 表现 |
|--------|-----|---------|-------------|
| `knife_choice` | 父刀 | `resistance_score` +0 | 风中有金属碰撞声 |
| `knife_choice` | 师刀 | `resistance_score` +1 | 风中有模糊人声 |
| `nezha_trust` | >= 3 | `wushi_presence_derived` +1 | 焦土中有护腕碎片 |
| `wushi_presence` | 高 | `wushi_presence_derived` 高 | 岩壁有新刻痕 |
| `wushi_presence` | 低 | `wushi_presence_derived` 低 | 风声像骨头断裂 |
| `lijing_hesitation` | 高 | — | 祖母提及李靖手抖 |
| `ledger_choice` | 揭发 | `resistance_score` +1 | 村民提及天庭规矩 |
| `tenpeng_last_words` | 是 | — | 祖母提及将军的话 |
| `seventh_aperture_awareness` | 觉察 | — | 法明打坐时不安 |
| `peach_tree_fate` | 保留 | `memory_guardian_index` +1 | 活着的小桃树 |
| `peach_tree_fate` | 移植 | `memory_guardian_index` +1 | 桃树在别处活着 |
| `peach_tree_fate` | 砍掉 | `memory_guardian_index` +0 | 烧焦桃树残根 |
| `memory_kept` | 铭记 | `memory_guardian_index` +1 | 字迹抵抗风化 |
| `monkey_unity` | 团结 | `resistance_score` +1 | 山上有猴子 |
| `final_scroll` | 自己的话 | `resistance_score` +1 | 发现石头下的纸 |
| `faith_state` | 坚定 | `faith_echo` 高 | 祖母语气笃定 |
| `faith_state` | 崩塌 | `faith_echo` 低 | 祖母语气困惑 |
| `scripture_truth` | 揭露 | `memory_guardian_index` +1 | 岩壁纹路像字 |
| `tangseng_encounter` | 继续西行 | — | 行者脚步坚定 |

### 3.3 重新渲染流程

```
开始重新渲染
    │
    ▼
计算派生变量
    │
    ▼
确定回响触发列表
    │
    ▼
按优先级排序回响
    │
    ▼
逐个应用回响效果
    │
    ├── 显著回响 → 直接修改叙事
    │
    ├── 细微回响 → 标记为可选发现
    │
    └── 系统回响 → 更新机制参数
    │
    ▼
生成重新渲染后的 Scene 0 脚本
    │
    ▼
结束
```

### 3.4 重新渲染元素清单

#### 环境元素

| 元素 | 基础状态 | 可能的变化 |
|------|---------|-----------|
| 烧焦桃树残根 | 焦黑、枯死 | 活着的小桃树（E19） |
| 岩壁刻字「齐天大圣」 | 风化模糊 | 更清晰（E21）、有新刻痕（E05） |
| 旗帜碎片 | 残破、褪色 | 红色纹路更清晰（E24） |
| 风声 | 普通山风 | 金属碰撞声（E01）、模糊人声（E02）、骨头断裂声（E14） |
| 石头 | 普通山石 | 表面光滑如镜（E31） |

#### 物件元素

| 元素 | 基础状态 | 可能的变化 |
|------|---------|-----------|
| 布带残片 | 无 | 哪吒护腕碎片（E04, E07） |
| 石头下的纸 | 无 | 法明写的话（E25） |

#### NPC 元素（祖母）

| 元素 | 基础状态 | 可能的变化 |
|------|---------|-----------|
| 讲故事语气 | 平静叙述 | 笃定（E26）、困惑（E27） |
| 额外台词 | 无 | 提及李靖手抖（E09）、将军的话（E16, E32）、故事比命还真（E36） |

#### 少年状态

| 元素 | 基础状态 | 可能的变化 |
|------|---------|-----------|
| 好奇心 | 基础值 | +1（E33 触发） |
| 情绪基调 | 中性 | 温暖（E33）、悲伤（E34） |

### 3.5 GM 快速判定表

当需要快速决定 Scene 0 的某个细节时，参考以下判定优先级：

| 优先级 | 判定依据 | 示例 |
|--------|---------|------|
| 1 | 直接回响映射 | E19 触发 → 必须有活着的桃树 |
| 2 | 派生变量阈值 | `memory_guardian_index` >= 0.75 → 氛围温暖 |
| 3 | 综合条件 | 3+ 场景倾向铭记 → 少年好奇心 +1 |
| 4 | GM 自由裁量 | 其他细节由 GM 根据整体氛围决定 |

### 3.6 重新渲染示例

**场景**：完成 Scene 1-4 后，重新渲染 Scene 0 的「桃树」元素。

**假设变量状态**：
- `peach_tree_fate` = 保留
- `memory_kept` = 铭记
- `wushi_presence` = 高

**重新渲染结果**：

> 「少年走到那棵树下。
>
> 他愣住了。
>
> 他记得这棵树应该是烧焦的。上次看到的时候，它只剩下一截焦黑的残根，像是从火里伸出来的一只手。
>
> 但现在，那截残根上长出了一根新枝。很细，很矮，但确实是活的。叶子是嫩绿色的，在夕阳下几乎透明。
>
> 少年蹲下来，想摸一摸那片叶子，但又怕碰坏了它。他从来没见过这样的东西——在这么荒凉的地方，从焦土里长出来的绿色。
>
> （E19 触发：显著回响）
>
> 他抬头看向岩壁。那几个字——『齐天大圣』——比他记忆中清晰得多。他几乎能看清每一笔的走向。那些笔画像是……在抵抗着什么。风化了这么久，却没有变浅，反而更深了。
>
> （E21 触发：系统回响——辨认 DC 降低 2）
>
> 少年眯起眼睛。这一次，他看清了。四个字，每一笔都像是用什么东西刻进去的，不是石头自己的纹路。
>
> 他忽然觉得，这山上有很多故事。那些故事藏在风里、土里、树里。它们在等什么人回来。」

```

□ 真实目的 × 2

✓ 信息获取/秘密揭示 → 洞察

```

- 显著：「你注意到……」

- 系统：「你发现……（DC 降低 X）」
