# 复合变量文档

> 本文档定义《Jump Jump》游戏中用于影响力报告的复合变量。这些变量由多个源变量通过特定公式计算得出，用于生成玩家的「行为画像」。

---

## 复合变量概览

| 复合变量 | 用途 | 维度 |
|----------|------|------|
| `idealism_index` | 理想主义指数 | 影响力报告「理想主义」维度 |
| `change_participation` | 变革参与度 | 影响力报告「变革参与」维度 |
| `memory_guardian_index` | 记忆守护者指数 | 影响力报告「记忆守护」维度 |

---

## 1. 理想主义指数 `idealism_index`

### 计算公式

```
idealism_index = (
  (peach_tree_fate == "保留" ? 1 : 0) +
  (memory_kept == "铭记" ? 1 : 0) +
  (final_scroll == "自己的话" ? 1 : 0)
) / 3
```

### 源变量说明

| 源变量 | 场景 | 理想主义取值 |
|--------|------|--------------|
| `peach_tree_fate` | Scene 3 | 保留 = 1，砍掉/移植 = 0 |
| `memory_kept` | Scene 3 | 铭记 = 1，暗中传承/遗忘 = 0 |
| `final_scroll` | Scene 4 | 自己的话 = 1，照抄/空白/什么都没写 = 0 |

### 结果解释

| 指数范围 | 等级 | 影响力报告描述 |
|----------|------|----------------|
| 0.00 - 0.33 | 低理想主义 | 「你在一个务实的世界里选择了务实的生存方式。」 |
| 0.34 - 0.66 | 中等理想主义 | 「你心中有一些不愿妥协的东西，但你也学会了在必要时退让。」 |
| 0.67 - 1.00 | 高理想主义 | 「你选择了相信一些看似不可能的事物，哪怕代价是孤独。」 |

### 叙事意义

理想主义指数衡量玩家在游戏中对「不可能之事」的坚持程度：
- 保留桃树：相信花果山仍有希望
- 铭记大圣：相信记忆比生存更重要
- 写自己的话：相信个人表达胜过体制规范

## 2. 变革参与度 `change_participation`

### 计算公式

```
change_participation = (
  (knife_choice == "师刀" ? 1 : 0) +
  (ledger_choice == "揭发" ? 1 : 0) +
  (resistance_choice == "反抗" ? 1 : 0) +
  (sutra_truth == "揭露" ? 1 : 0)
) / 4
```

### 源变量说明

| 源变量 | 场景 | 变革参与取值 |
|--------|------|--------------|
| `knife_choice` | Scene 1 | 师刀 = 1（选择非传统的剔骨方式），父刀 = 0 |
| `ledger_choice` | Scene 2 | 揭发 = 1，隐瞒/部分揭露 = 0 |
| `resistance_choice` | Scene 3 | 反抗 = 1，留守/隐匿 = 0 |
| `sutra_truth` | Scene 4 | 揭露 = 1（选择政治/悖论解读），禅意/不理解 = 0 |

### 结果解释

| 指数范围 | 等级 | 影响力报告描述 |
|----------|------|----------------|
| 0.00 - 0.25 | 低参与度 | 「你选择了在体制的缝隙中生存，而非挑战体制本身。」 |
| 0.26 - 0.50 | 中等参与度 | 「你曾有机会改变什么，有时你抓住了，有时你放手了。」 |
| 0.51 - 0.75 | 较高参与度 | 「你多次站在选择的十字路口，选择了更难的那条路。」 |
| 0.76 - 1.00 | 高参与度 | 「你一次又一次地选择了行动，哪怕行动意味着代价。」 |

### 叙事意义

变革参与度衡量玩家在游戏中对「改变现状」的主动程度：
- 师刀：选择非传统的解决方式
- 揭发：选择公开真相而非沉默
- 反抗：选择直接对抗而非妥协
- 揭露：选择揭示权力运作而非接受表面解释

## 3. 记忆守护者指数 `memory_guardian_index`

### 计算公式

```
memory_guardian_index = (
  (wall_inscription != "抹掉" ? 1 : 0) +
  (tenpeng_last_words == "是" ? 1 : 0) +
  (memory_kept == "铭记" ? 1 : 0) +
  (final_scroll == "自己的话" ? 1 : 0)
) / 4
```

### 源变量说明

| 源变量 | 场景 | 记忆守护取值 |
|--------|------|--------------|
| `wall_inscription` | Scene 0 | 非「抹掉」（描下/辨认/忽略）= 1，抹掉 = 0 |
| `tenpeng_last_words` | Scene 2 | 是 = 1（选择记住天蓬的话），否 = 0 |
| `memory_kept` | Scene 3 | 铭记 = 1，暗中传承/遗忘 = 0 |
| `final_scroll` | Scene 4 | 自己的话 = 1，照抄/空白/什么都没写 = 0 |

### 结果解释

| 指数范围 | 等级 | 影响力报告描述 |
|----------|------|----------------|
| 0.00 - 0.25 | 低守护 | 「你让过去留在过去，专注于眼前的生存。」 |
| 0.26 - 0.50 | 中等守护 | 「你记住了一些事，也放走了一些事。」 |
| 0.51 - 0.75 | 较高守护 | 「你像一个拾荒者，收集着即将消逝的记忆碎片。」 |
| 0.76 - 1.00 | 高守护 | 「你是记忆的守护者，哪怕记忆会让你背负更多。」 |

### 叙事意义

记忆守护者指数衡量玩家在游戏中对「记忆传承」的重视程度：
- 不抹掉字迹：选择保留他人的痕迹
- 记住天蓬的话：选择记住被贬者的声音
- 铭记大圣：选择公开传承英雄记忆
- 写自己的话：选择创造新的记忆文本

## 复合变量使用说明

### 计算时机

所有复合变量在以下时机计算：
1. **场景结束时**：计算当前可用的复合变量（部分源变量可能尚未获得）
2. **影响力报告生成时**：计算最终复合变量值

### 部分数据情况

当部分源变量尚未获得时（如正在 Scene 2，Scene 3-4 的变量未知）：
- 仅基于已有变量计算
- 在影响力报告中标注「基于当前进度」
- 最终报告基于完整数据重新计算

### 复合变量组合解读

三个复合变量可组合成玩家的「行为画像」：

| 理想主义 | 变革参与 | 记忆守护 | 画像标签 |
|----------|----------|----------|----------|
| 高 | 高 | 高 | 「革命者」— 相信改变，主动行动，守护记忆 |
| 高 | 高 | 低 | 「理想主义者」— 相信美好，愿意行动，但选择向前看 |
| 高 | 低 | 高 | 「守夜人」— 守护记忆，但不主动挑战体制 |
| 高 | 低 | 低 | 「孤独梦想家」— 内心有理想，但选择独自坚持 |
| 低 | 高 | 高 | 「行动派」— 务实改变，同时尊重过去 |
| 低 | 高 | 低 | 「实用主义者」— 关注当下行动，不问过去未来 |
| 低 | 低 | 高 | 「史官」— 记录但不干预，见证但不行动 |
| 低 | 低 | 低 | 「幸存者」— 专注于个人生存，不问其他 |
