# 世界设定书 · 物种与存在层级（World Bible · Species & Existential Hierarchy）

> **分册说明**：本文档是 world-bible 的物种分册。宏观宇宙法则、哲学框架、权力系统概览见 [`world-bible.md`](./world-bible.md)。关键角色的详细个人档案见 [`world-bible-characters.md`](./world-bible-characters.md)。
>
> **定位**：本文档是物种定义的唯一权威来源。其他文档涉及物种特性时，应通过引用本文档章节编号（如「参见 species 2.1」）使用，不应重复定义。

---

## 一、总则

### 1.1 物种分类原则

本世界的物种不按生物学划分，而按**与秩序的关系**划分：

| 物种 | 与秩序的关系 | 核心特征 |
|------|-------------|---------|
| 神 | 秩序的维护者 | 编制内、去情感化 |
| 仙 | 秩序的边缘人 | 编制外、有修为、地位不稳 |
| 妖 | 秩序的错误/溢出 | 编制外、存在即原罪 |
| 人 | 秩序的燃料 | 认知受限、寿命有限 |
| 灵/精 | 秩序的噪声 | 微弱意识体、影响局部 |

### 1.2 物种边界的流动性

物种之间并非绝对隔绝。存在以下转化路径（均有极高代价）：

```
人 → 仙（修炼）→ 神（封神改造）
人 → 妖（意外觉醒/非正统修炼）
妖 → 神（招安 + 封神改造）
灵/精 → 妖（积累足够力量后）
神 → 妖（谪降/被贬）
```

每一条路径都意味着本质性的改变，不是简单的「升级」。

## 二、神（Gods）

### 2.1 本质

秩序的**维护者**。

重要区分：神不是创造者。创世的是盘古（开天辟地）和女娲（造人补天）。天庭是在创世之后建立的「治世机构」，神是这个机构的编制成员。天庭的权威来源不是「我创造了你」，而是「我管理这一切」——这个区别决定了天庭权威的根基并不如它自我宣称的那样天经地义。

### 2.2 成神过程（封神 / Apotheosis）

**入口条件**：
- 正式的封神仪式，由天庭高层主持
- 需要本人「自愿」接受（但在招安 vs 剿灭的二选一下，「自愿」的含金量存疑）

**仪式本质**：封神不是赐予力量，而是一种**根本性的存在改造**。进入天庭编制的代价是永久性地失去部分本质。

### 2.3 封神代价（统一定义）

> **权威定义位置**：封神代价在此统一定义。其他文档引用时请标注「参见 species 2.3」。

封神对个体造成以下不可逆改变：

#### 2.3.1 心窍消失

心窍是灵性层面的心脏通道——不是物理心脏，而是感知情感、建立联结、产生道德直觉的灵性器官。封神仪式将心窍永久抹除。

#### 2.3.2 情感处理能力丧失

心窍消失的直接后果：**丧失感受和处理情感的能力**。

措辞说明：这里刻意不使用「情感归零」或「情感消失」的表述。更准确的描述是——通往情感的通道被封死了。至于情感本身是否还存在于某个封神者无法触及的深处，这个问题保留模糊性。这种模糊性是有意为之的：

- 它为叙事留出了「封神者偶尔展现出类似情感反应」的空间（可以是残余，也可以是模仿）
- 它使「封神是否真正杀死了情感」成为一个角色和玩家可以争论的哲学问题
- 它与《悟空传》原作中对神性的批判深度一致——制度对人的改造，究竟是消灭了什么，还是压制了什么？

#### 2.3.3 记忆与人际纽带断裂

封神者不再记得曾经爱过的人、恨过的人、亏欠过的人。所有构成「我是谁」的关系性记忆被切断。保留的是功能性记忆（技能、知识、程序），失去的是情感性记忆（意义、温度、牵挂）。

#### 2.3.4 罪恶感知消失

无法产生内疚、羞耻、道德不安。这不是「选择不内疚」，而是内疚的生理基础已经不存在了。一个封神者可以下令屠城而内心毫无波澜——不是因为冷血，而是因为感知罪恶的器官已经被摘除。

#### 2.3.5 说谎无生理反应

心窍消失后，欺骗行为不会引起任何可被察觉的变化——心跳不变、表情不变、气息不变。凡人和低阶存在没有任何可靠方式识别神的谎言。这使神在所有信息博弈中处于结构性优势。

### 2.4 天数豁免

按天数（宇宙既定剧本）行事的神，不承担任何道德责任。这是制度性的免责——不是「做了坏事但被原谅」，而是「按剧本做的事根本不算坏事」。天数豁免是封神代价的回报：你交出了判断对错的能力，作为补偿，你永远不需要判断对错。

### 2.5 社会结构

等级制官僚系统。详细的权力结构、层级关系、灵蕴经济见 `world-bible-power.md`。

概要：
- **顶层**：玉帝（名义最高权威）、如来（实际制衡力量）
- **中层**：各路正神、天将——执行天数、管辖区域
- **底层**：土地神、山神、河神、城隍——直接面向凡人，负责灵蕴收割
- 权力来源于编制位置 + 灵蕴积累量
- 上级依赖下级收集灵蕴，下级依赖上级的庇护和授权

### 2.6 神的行为模式

- **对内**：等级服从，下级对上级绝对执行
- **对外**：将编制外存在视为需要管理的对象（招安或消灭）
- **对凡人**：提取资源（灵蕴），维持可控的信仰关系
- **集体心理**：没有心窍意味着没有同理心、没有犹豫、没有道德焦虑——但也没有真正的恶意。神不是恶人，神是机器。

## 三、仙（Immortals）

### 3.1 本质

通过**有意识的系统性修炼**获得长生的存在，但**未加入天庭编制**。

「有意识的系统性修炼」是仙与妖的本质区别的关键：仙是主动追求修炼的，有师承、有法门、有目标；妖的力量更多来自意外觉醒或自发进化（详见第四章）。

### 3.2 修炼路径

仙的修炼大体经过以下阶段：

| 阶段 | 特征 | 时间跨度 |
|------|------|---------|
| 筑基 | 感知灵气、开始导引 | 数十年 |
| 炼气 | 灵气内循环建立，寿命开始延长 | 数十至上百年 |
| 金丹 | 凝结内丹，获得真正意义上的长生 | 上百年 |
| 化神 | 力量质变，可干涉物质世界运转 | 数百年至千年 |
| 渡劫 | 天劫降临——这是秩序对编制外强者的自动反应 | 随时可能 |

天劫是一个关键机制：当仙的力量积累到一定程度，天道（秩序的自动执行系统）会降下雷劫。这不是考验，而是清除。通过了继续存在，通不过就灰飞烟灭。天庭对此的官方说辞是「自然法则」，但实际上天劫的强度与天庭对该仙人的态度高度相关。

### 3.3 力量等级

仙的力量范围极广：

- **下限**：刚刚突破凡人寿命限制的初修者，战力略强于凡人武者
- **上限**：修炼千年以上的大能，力量可比肩中低阶神（但没有编制带来的制度性权力）
- **与神的差距**：不在于纯粹的力量值，而在于资源和信息——神有天庭的情报网络、法宝库、部下支援；仙是单打独斗

### 3.4 在凡人世界的存在形式

仙通常以以下方式存在于世间：

- **隐居山林**：最常见。选一处灵气充沛的山谷洞府，闭门修炼，与世隔绝。偶尔下山采买或与凡人村落有最低限度的接触。
- **云游四方**：较少见。以游方道士、云游僧人的面目出现在凡人之间，寻找机缘或弟子。
- **坐镇一方**：极少见。以「山中仙人」的身份被附近凡人知晓，凡人偶尔前来求医问药。这种仙人对凡人社区有一定保护作用，但也容易被天庭注意。
- **入世伪装**：罕见。完全融入凡人社会，压制修为，过凡人的生活。通常是在躲避天庭追捕。

### 3.5 地位的不稳定性

仙的处境可以用四个字概括：**两头不靠**。

- **对天庭**：仙是潜在的不稳定因素。力量强到可以引起注意，但没有编制约束——这让天庭不安。
- **对凡人**：仙在凡人眼中是令人仰慕的传说，但凡人无法区分仙和高阶妖（详见互动矩阵）。
- **被招安的可能**：天庭对有价值的仙人会伸出橄榄枝——加入编制、获得正式地位。代价是封神改造（参见 species 2.3）。
- **被剿灭的风险**：拒绝招安、或力量过于显眼、或介入了不该介入的事务——都可能被天庭视为威胁，派天兵天将剿灭。
- **没有正式保护**：仙不属于任何体系，没有条约、没有律法、没有组织为他们说话。生死全凭自身修为和天庭心情。

### 3.6 仙的集体心理

- 警惕是底色——对天庭、对其他仙、对暴露自身
- 多数选择低调，「不出头」是第一生存法则
- 少数激进者会结成松散同盟，但凝聚力远不如天庭的组织化体系
- 对凡人的态度因人而异：有的视凡人如蝼蚁，有的心怀悲悯但无力改变什么

## 四、妖（Demons / Monsters）

### 4.1 本质

宇宙运转中**未被秩序纳入的存在**。妖不是被创造的，而是系统运转过程中出现的——有的是错误，有的是溢出，有的是被刻意放置但不被承认的。

### 4.2 妖与仙的本质区别

| 维度 | 仙 | 妖 |
|------|-----|-----|
| 力量来源 | 有意识的系统性修炼 | 意外觉醒 / 自发进化 / 天生具有 |
| 起点 | 通常从凡人开始，主动选择修炼 | 非人起点（动植物、石头、灵气凝聚体）或凡人的非正统觉醒 |
| 与秩序的关系 | 边缘但不违规——修炼本身不犯法 | 存在本身就是对秩序的冒犯 |
| 社会认知 | 「得道高人」 | 「怪物」「妖魔」 |

关键差异在于**合法性叙事**：仙的存在可以被秩序解释为「凡人通过努力提升自身」，勉强说得通；妖的存在无法被秩序框架容纳——你是石头变的猴子？你是蜘蛛成了精？秩序的规则里没有这个选项。

### 4.3 妖的三种子分类

#### 4.3.1 天生妖（Primordial Demons）

| 属性 | 描述 |
|------|------|
| **来源** | 天地灵气自然孕育。非人所生，非神所造，是宇宙运转中自发出现的存在 |
| **特征** | 系统的「错误」——不在任何造物清单上，没有被分配过角色和命运 |
| **存在处境** | 存在即原罪。不是做了什么才有罪，而是「是什么」本身就有罪 |
| **力量特点** | 通常极为强大（灵气直接凝聚的产物），远超同阶修炼妖 |
| **典型案例** | 孙悟空（花果山灵石孕育的石猴） |

天生妖是秩序最无法容忍的类型：你不在我的账本上，你的存在就是我的记录有误。对秩序而言，天生妖必须被消除——不是因为恶，而是因为不在计划内。

#### 4.3.2 修炼妖（Cultivated Demons）

| 属性 | 描述 |
|------|------|
| **来源** | 凡间动植物、甚至非生物，通过漫长的自行修炼获得灵智和力量 |
| **特征** | 从无意识到有意识的觉醒。一株藤蔓活了三千年，忽然有一天它「知道」自己在活着 |
| **存在处境** | 秩序不否认它们的存在，但也不给予合法地位——处于灰色地带 |
| **力量特点** | 与修炼时长和资质相关，参差不齐。多数较弱，少数经年累月可成大妖 |
| **典型案例** | 白骨精、蜘蛛精、各路动植物精怪 |

修炼妖的悲剧在于：它们从来没有选择「成为妖」——它们只是活着，活久了就醒了。醒来后才发现自己被划入了「错误」的类别。

#### 4.3.3 谪降妖（Descended Demons）

| 属性 | 描述 |
|------|------|
| **来源** | 天庭或灵山的编制内成员，因各种原因被贬降或被「放出」到凡间 |
| **特征** | 不是系统错误，而是**体制的溢出物**——他们曾经是体制的一部分 |
| **存在处境** | 表面上是「犯错被贬」，实际上许多是天庭/灵山默许甚至安排的 |
| **力量特点** | 通常保留大部分原有神力，远超同体量的修炼妖 |
| **典型案例** | 金角大王、银角大王（太上老君的童子）；青牛精（太上老君的坐骑）；大鹏鸟（如来的舅舅）|

**谪降妖是三类妖中叙事价值最高的类型**，因为他们揭示了秩序最虚伪的一面：

- 这些妖不是「逃出来」的，是被「放出来」的——主人的法宝被「偷走」，坐骑「挣脱」了缰绳，童子「私自」下凡——这些说辞的可信度极低。
- 他们在凡间为祸时，恰好出现在取经路上——这不是巧合，而是被安排的「劫难」。
- 取经需要「九九八十一难」，谁来提供这些劫难？谪降妖就是苦难制造机制的执行单元。
- 最终他们会被「收回」——主人下凡把坐骑/童子带走，惩罚轻微甚至没有。整个过程像一场排练好的戏。

谪降妖的存在证明了：**天庭不仅制造凡人的苦难（参见苦难制造机制），也制造取经者的苦难——且手法相同：制造灾难，然后提供「解决方案」，以维护自身的必要性。**

### 4.4 妖的存在悖论

无论属于哪个子类，所有妖最终都面临同一个不可解的二元困境：

| 路径 | 行为 | 过程 | 结果 |
|------|------|------|------|
| **反抗** | 试图证明自己有资格存在 | 反抗秩序的行为本身使妖越来越像「魔」——暴力升级、仇恨加深、形象恶化 | 成为秩序的合法打击对象 → 被消灭 |
| **顺从** | 接受自己不该存在 | 秩序的纠错逻辑开始运转——你承认自己是错误，那就让错误被修正吧 | 被秩序「温和地」抹去 |

无论选择哪条路，妖的最终命运都是被抹去。这不是惩罚——惩罚预设了「你做错了什么」；这是纠错——秩序在修复自身的漏洞。

**唯一的例外路径**是被招安/收编：交出自我，接受封神改造（参见 species 2.3），成为体制的一部分。但这本质上也是「抹去」——妖的身份被消除，取而代之的是一个全新的、去情感化的神。原来的那个「妖」已经死了。

### 4.5 谪降妖的特殊行为模式

谪降妖的行为与其他两类妖有显著不同：

- **目标明确**：不是随机作乱，而是「执行任务」——占据某处、抓住某人、制造某个劫难
- **行为有度**：通常不会无节制地毁灭——因为他们知道自己最终会被「收回」
- **与凡人的关系**：更像「被派来的灾祸」而非「偶遇的怪物」。凡人眼中他们是妖，但他们的行为逻辑更像被外派到基层的体制官员——执行命令、完成指标、等待召回
- **自我认知矛盾**：他们知道自己不是真正的妖，但也不再是完整的神——是一种悬置状态

## 五、人（Mortals）

### 5.1 本质

在神妖框架中，凡人不是参与者，而是**资源**。灵蕴的来源、苦难的承受者、信仰的提供者——凡人在这个系统中的角色，类似于土壤之于植物。

但凡人不**仅仅**是燃料。

### 5.2 核心特征

- **认知被边界限制**：凡人的世界比真实世界小得多，且凡人不知道自己的世界是小的（参见 `world-bible.md` 4.2 认知边界）
- **寿命有限**：这是秩序的一部分。有限的寿命迫使凡人在恐惧中寻求庇护，恐惧驱动供奉，供奉产生灵蕴
- **信息严重不对称**：凡人知道的远少于神、仙、妖。对超自然世界的认知是片面的、扭曲的、混合恐惧与传说的
- **对超自然力量既依赖又恐惧**：这种矛盾心理是香火经济的心理基础

### 5.3 与神的关系

寄生性的、单向的、不对等的。

- 神从凡人身上提取灵蕴
- 偶尔回馈一点「灵验」维持信仰
- 凡人没有可靠方式识别神的欺骗（参见 species 2.3.5）
- 凡人视角中的「天灾」，相当一部分是神主动制造的苦难（参见苦难制造机制）
- 这个关系的本质是**畜牧**——保持牲畜健康到足以产出，但不会健康到不再需要牧人

### 5.4 凡人中的例外：修行者

凡人并非完全没有上升通道。极少数凡人可以通过修炼突破凡人的局限：

- **成仙之路**：有意识地修炼，拜师学艺，循正统路径提升。成功者成为仙（参见第三章）。这条路极窄——需要资质、机缘、师承、数十至数百年的苦修，且随时可能在天劫中灰飞烟灭。
- **成妖之路**：非正统的觉醒。某些凡人在极端环境（濒死、极度仇恨、接触异常灵气）下发生异变，获得超自然力量但代价是偏离人的范畴。社会将他们归类为妖。
- **上升通道的意义**：这条窄路的存在是世界动态平衡的机制之一——它给凡人一丝「命运并非完全注定」的幻觉，同时因为成功率极低，实际上不会动摇秩序的根基。天庭乐于维持这个幻觉。

### 5.5 凡人的能力体系

凡人的具体能力系统（武技、术法、驱邪手段、职业分类等）详见 `world-bible-mortal.md`。

在此仅列出与物种互动相关的关键能力：

- **驱邪**：对灵/精有效，对低阶修炼妖勉强有效，对天生妖和谪降妖完全无效
- **感知**：极少数凡人天生具有感知超自然存在的能力（阴阳眼、灵觉），但无法控制且不稳定
- **信仰之力**：凡人集体的虔诚供奉可以在局部产生强大的灵蕴场，对低阶妖精有驱逐效果——讽刺的是，这种力量本质上是替神工作

---

## 六、灵/精（Spirits）

### 6.1 本质

物件或动植物长期存在后产生的意识体。是超自然存在中层级最低、力量最弱的类型，但也是**凡人最有可能直接接触的超自然存在**。

### 6.2 觉醒条件

- **时间基础**：一个物件或生物需要存在足够长的时间——通常以百年为单位。一棵百年老树、一口千年古井、一面代代相传的铜镜，都是潜在的觉醒载体。
- **触发因素**：纯粹的时间不够，还需要某种触发——
  - **灵气浓度**：所在地灵气充沛（山脉、水源、古战场、墓地附近）
  - **情感浸染**：长期被人类的强烈情感浸润（被深爱的物件、见证过巨大悲剧的场所）
  - **意外冲击**：雷击、洪水、地震等自然力量的刺激
  - **血祭/亡魂**：沾染了人血或亡魂气息
- **概率极低**：满足条件的物件成千上万，真正觉醒的万中无一

### 6.3 力量范围

灵/精的力量远弱于妖，通常只能影响极为局部的范围：

| 能力层级 | 表现 | 影响范围 |
|---------|------|---------|
| 微弱 | 物件自动位移、温度异常、异响 | 单间房屋 |
| 低等 | 制造幻觉（单一感官）、物件操控 | 一座宅院 |
| 中等 | 多感官幻觉、短暂附体、影响天气（局部） | 一个村落 |
| 较强（罕见） | 长期附体、与人对话、物理伤害 | 方圆数里 |

灵/精的力量上限远低于妖的下限。一个「较强」的灵/精，大约相当于一个刚开灵智的低阶修炼妖。

### 6.4 自我意识程度

灵/精的自我意识是一个连续谱，从近乎无到勉强可沟通：

| 程度 | 表现 | 类比 |
|------|------|------|
| **本能反应** | 只有最基本的趋利避害，无法沟通，行为重复且固定 | 类似条件反射 |
| **模糊意识** | 能感知周围环境变化，对特定刺激有非固定反应 | 类似半梦半醒 |
| **低等意识** | 有简单的好恶、记忆碎片，可被驱邪者感知到「意图」| 类似幼童 |
| **较强意识** | 能理解语言、表达意愿（通过托梦、附体、文字显现等方式） | 类似能沟通的个体 |

### 6.5 与凡人的互动方式

灵/精与凡人的互动大体分为三种模式：

**作祟（Haunting）**：
- 搞怪、制造不安、吓唬人。不一定有恶意——很多时候只是灵/精在尝试「表达」自己的存在，但因为力量和意识都有限，表达方式令凡人恐惧。
- 典型表现：深夜异响、物件自移、冷风无源、镜中异影。

**共生（Symbiosis）**：
- 保护某处或某人。通常发生在灵/精与特定地点/家族有深厚的情感联结时——比如一棵守护了村口三百年的老槐树成精后，继续保护这个村子。
- 典型表现：祸事前预警（异常声响/动物异动）、邪祟近身时的阻挡力量、特定区域内的异常平安。

**中性（Passive Existence）**：
- 只是存在。不干预凡人生活，也不被凡人察觉。大多数灵/精属于这一类——它们觉醒了，但意识太微弱，无法也无欲与外界互动。

### 6.6 与凡人的沟通

灵/精能否与凡人直接沟通取决于其意识程度：

- 本能反应级：不能。只有单向的行为表现。
- 模糊意识级：不能直接沟通，但敏感的凡人（灵觉者）可以隐约感知其「情绪」。
- 低等意识级：可以通过间接方式传达简单信息——托梦（画面模糊）、操控物件排列出文字/图案。
- 较强意识级：可以通过附体或托梦进行较为完整的对话，但持续时间短且消耗极大。

### 6.7 凡人的应对手段

凡人的驱邪手段对灵/精是**有效的**——这是灵/精与妖的一个关键区别。

- 符箓、咒语、草药（桃木、艾草、朱砂）可以驱散或压制灵/精
- 道士、巫祝等专业驱邪者可以应对大多数灵/精
- 极少数较强的灵/精需要高阶驱邪者或仙的介入
- 凡人的信仰之力（集体祈祷/供奉）也能在局部形成灵/精难以逾越的屏障

### 6.8 典型案例

- **宅中器精**：古宅中的老物件（铜镜、木梳、灯台）因年代久远且被数代人触碰使用而产生微弱意识。通常表现为物件偶尔自动位移。
- **树灵/石灵**：百年以上的古树或奇石，在灵气充沛之地产生意识。村口老树能预知风雨是常见的民间传说——在本世界中，这可能是真的。
- **战场游魂凝聚体**：古战场上大量亡魂的残余意识凝聚在某个物件（残剑、断旗、石碑）上，形成带有强烈情绪（愤怒、悲伤）的灵体。
- **供奉器灵**：长期被供奉的神像/牌位，如果供奉的「灵蕴」没有被上层神吸收（比如这位神已经衰落到无力收取），灵蕴可能积存在器物本身，催生出器灵——一个冒充神明接受供奉的灵/精。这是凡人信仰体系中最具讽刺性的现象之一。

## 七、物种互动矩阵

> 本矩阵定义每对物种之间的**默认关系**。具体个体可能偏离默认值，但偏离本身需要叙事理由。

### 7.1 矩阵总览

| | **神** | **仙** | **妖** | **人** | **灵/精** |
|--|--------|--------|--------|--------|----------|
| **神** | 等级服从 | 招安或剿灭 | 消灭或利用 | 提取资源 | 忽视 |
| **仙** | 警惕/迎合 | 松散同盟 | 因情况而异 | 偶有交集 | 忽视 |
| **妖** | 恐惧/反抗 | 因情况而异 | 弱肉强食 | 食物/利用/共处 | 可吸收 |
| **人** | 敬畏/恐惧 | 仰慕/不信 | 恐惧 | 社会关系 | 驱邪/共处 |
| **灵/精** | 无交集 | 无交集 | 被吸收风险 | 依附/作祟 | 共存 |

### 7.2 矩阵详解

#### 神 → 神：等级服从

天庭是官僚体系，神与神之间的关系由编制等级决定。下级对上级绝对服从，同级之间按管辖范围划分势力。没有私人情谊——心窍消失后，「友谊」和「忠诚」都只是功能性的合作关系。偶有权力斗争，但形式是制度内的博弈（争夺管辖区、灵蕴分配），不是个人恩怨。

#### 神 → 仙：招安或剿灭

天庭对仙的态度取决于仙的力量和「听话程度」。有价值且配合的仙，天庭会伸出招安的橄榄枝——本质是用编制换服从。不配合、力量过大、或介入了天庭事务的仙，会被视为威胁，派天兵剿灭。天庭没有「放任不管」这个选项——编制外的强者本身就是不稳定因素。

#### 神 → 妖：消灭或利用

妖在神的眼中是秩序的错误，默认处理方式是消灭。但实际操作中，天庭会利用妖——特别是谪降妖，作为苦难制造机制和取经劫难的执行工具。消灭还是利用，不取决于妖的善恶（神没有善恶判断），而取决于妖对天庭是否有用。用完即弃是常态。

#### 神 → 人：提取资源

神对凡人的态度是牧人对牲畜的态度：维持在足以产出（灵蕴/香火）的健康水平，不会多给一分关怀。偶尔的「灵验」是维护信仰的投资，不是慈悲。凡人对神而言不是个体，而是集合——「信众」「子民」——是统计数字，不是名字。

#### 神 → 灵/精：忽视

灵/精对天庭而言不值得关注。力量太弱，既不构成威胁，也没有利用价值。天庭对灵/精的存在心知肚明，但不会主动处理——除非某个灵/精恰好挡了路。

---

#### 仙 → 神：警惕/迎合

仙对天庭的态度是清醒的恐惧。他们知道天庭的实力，知道自己没有正式保护，知道招安邀请的背后是「不接受就消灭」。多数仙选择迎合（至少表面上）——不得罪天庭、不高调行事、收到招安信号时认真考虑。少数刚烈者选择隐遁或对抗，但成功案例极少。

#### 仙 → 仙：松散同盟

仙与仙之间存在松散的同道关系——分享修炼心得、交换消息、偶尔互相庇护。但这种关系远不如天庭的组织化体系牢固。仙的本性是独行者，集结只是迫于外部压力的权宜之计。背叛和出卖并不罕见——毕竟，在天庭招安的压力下，出卖同道是一个可行的投名状。

#### 仙 → 妖：因情况而异

仙对妖的态度取决于具体情况，没有统一立场。力量弱小的妖会被无视或驱赶；力量相当的妖可能成为对手或盟友；被天庭通缉的妖偶尔会成为仙的同路人——「都是体制外的」是一种脆弱的共情基础。但仙绝不会公开庇护妖——那等于自己也变成天庭的打击对象。

#### 仙 → 人：偶有交集

仙与凡人的接触频率和深度因个体差异极大。隐居仙几乎不与凡人来往；云游仙会在凡人世界穿梭；坐镇一方的仙会与附近凡人建立长期关系。多数仙对凡人有一种「俯视的温和」——不至于冷酷，但也不会把凡人视为同类。收徒是仙与凡人最深层的互动形式——一种将自己的道传递下去的方式。

#### 仙 → 灵/精：忽视

灵/精对仙而言太微弱了，不值得关注。偶尔有仙人出于好奇研究灵/精的本质，但这属于个人兴趣，不是群体行为。

---

#### 妖 → 神：恐惧/反抗

妖对天庭的态度是两极化的。多数妖选择恐惧和逃避——藏在天庭势力薄弱的角落（深山、荒漠、地下），尽量不被发现。少数强大的妖选择反抗——孙悟空的大闹天宫是最极端的案例。但即使是反抗者，内心深处也清楚力量对比的残酷性。恐惧不是软弱，而是对现实的清醒认知。

#### 妖 → 仙：因情况而异

妖对仙的态度由力量关系决定。比自己强的仙——敬畏或回避；比自己弱的仙——可能抢夺其修炼成果（丹药、法宝）；力量相当的——可能结盟、可能冲突、可能忽视。妖和仙之间没有天然的敌意，也没有天然的亲近——他们都是体制外的存在，但「体制外」不自动等于「同一阵营」。

#### 妖 → 妖：弱肉强食

妖的世界没有秩序、没有法律、没有组织。强者吞弱者的灵力以增强自身——这是妖界最基本的生存法则。偶尔有大妖建立势力（如某山某洞的「大王」），但这种秩序极不稳定，完全依赖大妖个人的力量维持。一旦大妖被杀或被收服，整个势力立刻瓦解。

#### 妖 → 人：食物/利用/共处

**这是最复杂的物种互动之一。**

妖对凡人的态度远非单一的「吃人」：

- **食物**：部分妖（尤其是低阶修炼妖）确实以凡人为食——或直接食用肉身，或吸取精气。这是最表层的互动。
- **利用**：一些较有智慧的妖会利用凡人——让凡人为自己做事、建立伪装身份混入凡人社会、甚至建立自己的「香火」体系（模仿天庭的灵蕴收割模式）。
- **共处**：不常见但存在。某些妖（特别是修炼妖中意识较为完整的）与凡人和平相处，甚至建立情感联结。它们可能化为人形生活在凡人之间，与凡人交友、通商、甚至通婚。这种和平共处是脆弱的——一旦妖的身份暴露，凡人社区的恐惧会立刻摧毁一切。

#### 妖 → 灵/精：可吸收

灵/精对妖而言是可以被吸收的灵力来源——虽然微弱，聊胜于无。低阶妖可能主动寻找灵/精吸收以增强自身。高阶妖不屑于此。极少数情况下，妖会与灵/精建立共生关系（如占据了一棵树灵栖息的古树后，利用树灵的感知能力预警外敌）。

---

#### 人 → 神：敬畏/恐惧

凡人对神的态度是复杂的混合体：敬畏、恐惧、依赖、怨恨（隐性的）。凡人知道神的力量远超自己，知道得罪神会遭殃，知道供奉可能换来庇佑。但凡人不知道苦难是被制造的，不知道祈祷几乎不会被回应，不知道「灵验」只是概率事件被赋予了意义。凡人与神的关系建立在巨大的信息不对称之上。

#### 人 → 仙：仰慕/不信

凡人对仙的态度充满矛盾。传说中的仙人是令人向往的——长生不老、法力无边、超脱世俗。但绝大多数凡人一生都不会遇到真正的仙，所以仙更像是故事和传说中的角色。**关键问题：凡人无法可靠地区分仙和妖。** 一个化为人形的高阶妖和一个隐匿修为的仙人，在凡人眼中可能毫无区别。这种辨识困难导致凡人对所有「超凡存在」持有混合的敬畏和恐惧。

#### 人 → 妖：恐惧

凡人对妖的默认态度是恐惧。在凡人的认知中，「妖」是一切超自然威胁的统称——吃人的怪物、作祟的精怪、不可理解的异类。但这种恐惧并非绝对：

- **和平共处案例**：在偏远地区，凡人与化为人形的妖和平共处的情况并非不存在。这些妖通常是修炼妖中较温和的个体，长期以人的面目生活在凡人社区中。只要不暴露真身，凡人会把它们当作普通邻居。
- **恐惧的来源**：凡人恐惧妖，与其说是因为亲身经历，不如说是因为**传说和社会教化**。天庭有意在凡人社会中传播妖的恐怖形象——这有助于凡人更依赖神的「保护」。
- **辨识困难**：如前所述，凡人无法可靠区分妖和仙。这意味着凡人可能把仙当作妖来恐惧，也可能把妖当作仙来供奉。

#### 人 → 灵/精：驱邪/共处

**这是凡人最常接触的超自然互动。**

灵/精是凡人生活中「日常超自然」的主要来源。与高高在上的神和远在天边的妖不同，灵/精就在凡人身边——在老宅的阁楼里，在村口的古树上，在传了三代的铜镜中。

- **驱邪**：当灵/精作祟影响生活时，凡人会请驱邪者处理。这是一个成熟的社会服务——有专业的道士、巫祝，有标准化的仪式和价格。驱邪对灵/精有效（区别于对妖无效），这给了凡人一种「超自然威胁可以被处理」的安全感。
- **共处**：不是所有灵/精都需要驱逐。共生型灵/精被视为「风水好」的标志——「这棵老树有灵气」「这口井有精怪但人畜无害」。凡人甚至会主动供奉一些温和的灵/精，建小祠、挂红绸、逢年过节祭拜。
- **文化内化**：灵/精的存在深刻影响了凡人文化——风水学说、物件禁忌（不随意丢弃老物件）、建筑规矩（不砍古树/不填老井）——这些文化规范的底层逻辑是「对灵/精的敬畏」。

#### 人 → 人：社会关系

凡人之间的关系是本世界中唯一「正常」的物种互动——有爱、有恨、有合作、有背叛、有制度、有混乱。凡人社会的结构、文化、经济详见其他分册。在物种互动的语境下，需要强调的是：凡人社会是**被设计的牧场**——社会结构、文化规范、信仰体系，都被天庭（直接或间接地）塑造成最有利于灵蕴产出的形态。凡人以为自己在自主运作社会，实际上社会的底层参数是被调过的。

---

#### 灵/精 → 神：无交集

灵/精的意识水平不足以认知神的存在。它们的世界极为狭小——通常只有自身栖息的物件/场所及其周边。天庭的存在对灵/精而言完全超出了认知范围。

#### 灵/精 → 仙：无交集

与对神的情况类似，灵/精不具备与仙互动的意识水平。仙可能感知到灵/精的存在（修为足够的仙可以「看到」灵/精），但灵/精对仙的感知能力极为有限——最多能感到「有一个很强的存在经过了」。

#### 灵/精 → 妖：被吸收风险

灵/精对妖而言是微弱的灵力来源。灵/精无力抵抗妖的吸收，也无法主动逃离——它们通常被绑定在自身的物件/场所上。当一个妖占据了灵/精的栖息地，灵/精要么被吸收（消亡），要么被妖的气场压制到完全沉寂。这是灵/精面临的最大生存威胁。

#### 灵/精 → 人：依附/作祟

这是灵/精最活跃的互动方向。灵/精的存在与凡人密切相关——它们的觉醒往往因人类活动而触发（情感浸染、供奉积累），它们的栖息地通常是人类的造物或人类活动区域。灵/精对凡人的态度由其意识水平和觉醒经历决定：被善待的物件产生的灵/精更倾向共生；被暴力或痛苦浸染的场所产生的灵/精更倾向作祟。

#### 灵/精 → 灵/精：共存

灵/精之间几乎不互动。它们各自被绑定在自己的栖息物上，感知范围极为有限，彼此之间没有竞争（不争夺资源）也没有合作（意识水平不足以协调）。多个灵/精在同一区域共存时，状态是各自为政的平行存在。极罕见的情况下，多个灵/精的微弱意识会在某个节点（如特殊日期、特殊事件）短暂「共振」，产生一种比单个灵/精更强的临时力量——但这不是有意的合作，更像是一种自然共振现象。

---

### 7.3 特别关注：谪降妖与凡人的互动

谪降妖与凡人的互动模式值得单独说明，因为它与其他两类妖有本质不同：

- **行为逻辑**：谪降妖的行为不是出于本能（饥饿/领地）或情感（仇恨/孤独），而是**任务驱动**——他们被放到凡间是有目的的。他们对凡人的伤害是「工作内容」，不是个人选择。
- **凡人的感知**：凡人无法区分谪降妖和其他妖。在凡人眼中，一个下凡吃人的前天庭坐骑和一个深山里修炼成精的蜘蛛没有区别——都是「妖怪」。但两者的行为模式、力量等级、最终命运完全不同。
- **戏剧性讽刺**：凡人向神祈祷以求保护不受妖害——但降妖本身就是神的安排。凡人在一个由神制造的灾难中向神求助，且深信神是自己的庇护者。这是苦难制造机制在物种互动层面的具体体现。
- **被「收回」后**：谪降妖完成任务后被主人收回，凡人以为是「神仙降妖」——又一次加固了「神是保护者」的叙事。实际上从释放到收回，都是同一批存在导演的同一出戏。

## 附录A：物种判定快速参考

在叙事和游戏判定中，判断一个存在属于哪个物种时，按以下顺序检查：

1. **是否在天庭/灵山编制内？** → 是 → **神**
2. **是否通过有意识的系统修炼获得长生？** → 是 → **仙**
3. **是否具有超越凡人的力量但不属于以上两类？** → 是 → **妖**（进一步判定子类）
4. **是否具有微弱意识但绑定于物件/场所？** → 是 → **灵/精**
5. **以上均否** → **人**

注意：这个判定流程反映的是**秩序的分类逻辑**，不是客观真理。一个存在「是什么」和秩序「说它是什么」之间可能存在差距——这正是本世界许多冲突的根源。
