# 世界设定书 — 认知与信息规则分册（World Bible: Cognition & Information）

> **本文档是 `world-bible.md` 的分册。** 宇宙法则、物种层级、权力系统、哲学框架等宏观规则见主文档。
> 本分册聚焦于游戏最核心的机制层：**信息不对称博弈的完整规则体系**。
> 所有 GM Agent 判定、NPC 信息行为、玩家洞察检定必须遵守本文档。

---

## 一、信息层级（Information Hierarchy）

```
神知道的 >> 仙知道的 > 妖知道的 >> 凡人知道的
```

**核心法则：信息即权力。** 在这个世界中，知道多少直接决定博弈优势的大小。

| 层级 | 信息范围 | 博弈地位 |
|------|---------|---------|
| **神** | 天数全貌、灵蕴运作、所有存在的档案、天庭内部决策 | 绝对信息优势，可主动制造信息差 |
| **仙** | 修炼体系、部分天庭规则（非核心机密）、灵蕴的存在（但不知完整机制） | 中等信息优势，但对天庭核心运作盲区大 |
| **妖** | 生存经验、其他妖的行为模式、部分灵蕴感知、天庭的威胁模式 | 有限信息，主要来自生存本能和经验积累 |
| **凡人** | 口耳相传的传说、直接感官经验、寺庙获取的片段信息 | 信息链最底层，所知远少于真实世界的运作 |

**GM 判定规则：**
- 当凡人试图获取超出其层级的信息时，必须通过明确的信息泄露路径（见第十节）才能实现，不可凭空获知。
- 层级之间的 `>>` 表示鸿沟，`>` 表示差距。神与凡人之间存在两道鸿沟，这是设计意图。

## 二、认知边界（Cognitive Boundary）

### 2.1 边界的本质

凡人的世界比真实世界小得多。这不是因为物理墙壁挡住了去路，而是因为**认知本身被限制了**。你看不到边界，因此不知道自己被限制。

边界通过**选项过滤**运作：
- 凡人面前的所有选择，都是边界预先允许的结果
- 凡人以为在做自主决定，实际上是在边界划定的范围内挑选
- 自由意志是幻觉 — 你不是在选择，是边界在替你选择

### 2.2 选项过滤的具体运作

| 过滤层 | 运作方式 | 举例 |
|--------|---------|------|
| **物理可达性** | 凡人的身体到不了的地方，自然不会成为选项 | 天庭、龙宫、地府 |
| **认知可见性** | 凡人的认知中不存在的事物，不会进入思考范围 | 灵蕴机制、天数运作 |
| **社会可接受性** | 社会规训过滤掉「不应该想的」选项 | 质疑神的存在、拒绝供奉 |
| **恐惧过滤** | 已知的超自然威胁抑制相关选项 | 靠近妖怪出没区、探索禁地 |

### 2.3 重要声明：边界是叙事设定，不是否定工具

> **这条规则面向 GM Agent：**
> 认知边界是世界观叙事设定，用于解释凡人为什么处于信息劣势，以及为什么「发现真相」如此困难。
> **它绝不是 GM 否定玩家行动的工具。**
> 如果玩家尝试突破常规、提出创造性方案，GM 应判定该行动的难度和后果，而不是以「边界不允许」为由直接否定。
> 玩家的主动性和创造性是游戏体验的核心，边界设定服务于制造张力，而非压制玩法。

## 三、认知突破条件（Breakthrough Conditions）

突破认知边界是两步过程，缺一不可：

### 步骤一：认知到边界存在

- 意识到自己的世界是被限制的
- 意识到自己面前的「选择」是被过滤的
- 这一步通常由外部刺激触发：遭遇超自然事件、获取矛盾信息、接触到边界外的存在

### 步骤二：采取行动跨出

- 光靠思考不够。知道边界存在但不行动，等于没有突破
- 必须做出实际的、跨出边界的行为
- 行动本身可以很小（走出村庄、追问一个不该问的问题），但必须是行动

### 突破的代价

突破不是奖励，而是一种不可逆的状态改变。突破后失去的东西：

| 失去的 | 具体表现 |
|--------|---------|
| **安全感** | 不再能相信「世界就是我看到的样子」 |
| **已知规则** | 过去赖以生存的经验法则可能全部失效 |
| **归属感** | 知道真相的人无法回到不知道真相的群体中 |
| **信仰的纯粹性** | 对神的盲目信仰被动摇（详见第八节「信念侵蚀」） |

**GM 判定规则：** 认知突破是不可逆的。一旦玩家角色经历了突破，其后续所有场景的信息获取条件、NPC 互动方式、叙事选项都应反映这一状态改变。

## 四、突破悖论（Breakthrough Paradox）

### 4.1 体制吸收悖论

```
想突破边界 → 需要力量 → 获取力量需要融入体制
→ 融入体制 → 被体制吸收 → 成为边界的执行者
→ 你变成了你想打破的东西
```

这是一个结构性的陷阱，不是个人能力问题。体制的设计就是让所有试图通过「正规途径」获取力量的人最终成为体制的一部分。

### 4.2 力量悖论

如果一个存在已经拥有突破的力量，但它恐惧自身的破坏力（因为过去的创伤或罪孽），它会**无意识地压制自己**。

表现：
- 面对弱于自己的对手时反而犹豫、失手
- 力量使用时自动降档，无法全力输出
- 在最需要突破的时刻反而退缩

**GM 判定规则：** 突破悖论是叙事工具，用于解释为什么强大的存在（如悟空）在特定场景中表现反常。对于凡人玩家角色，体制吸收悖论可以体现为：玩家为了获取信息而向体制靠拢，结果发现自己被利用。

## 五、神的不可测谎性（Divine Lie Immunity）

### 核心规则

封神后失去心窍，说谎时**没有任何生理反应**：
- 心跳不变
- 面色不变
- 语气不变
- 眼神不变
- 灵性层面无波动

### 机制后果

凡人没有**任何可靠方式**直接识别神的欺骗。所有传统测谎手段（察言观色、试探反应、心理博弈）对神完全无效。

### GM 判定规则

- 当玩家对神使用洞察检定试图测谎时，**检定自动失败**（无论骰值多高）
- 但玩家可以通过**间接手段**识别欺骗：逻辑矛盾、多方信息交叉验证、利益分析（详见第六节「凡人的不对称优势」）
- GM 不应主动告知玩家「你无法测谎」，而应描述「你观察不到任何异常」— 让玩家自己判断这意味着什么

## 六、凡人的不对称优势（Mortal Asymmetric Advantages）

> **设计意图：** 信息不对称博弈必须有博弈空间。如果凡人完全没有优势，游戏就没有可玩性。以下四项优势是凡人在这个极端不利的博弈环境中仅有的、但真实可用的筹码。

### 6.1 人情世故理解

**原理：** 神失去心窍后，情感感知归零。它们能理解「利益」「权力」「秩序」，但**无法理解凡人的情感逻辑**。

**可利用的盲区：**
- 神不理解「为了不重要的人牺牲重要利益」的行为
- 神不理解「面子」「义气」「记仇」等非理性社会机制
- 神不理解「宁死不屈」— 在神的逻辑中，生存优先于一切

**GM 判定规则：** 当玩家利用情感逻辑对抗神时，GM 应给予叙事上的合理优势。神可能会误判玩家的动机、低估情感驱动的行为力度、或对情感操作完全无防备。

### 6.2 信息网络拼图

**原理：** 凡人之间的信息传递虽然失真（见第十一节），但**数量和多样性**可以弥补质量的不足。

**运作方式：**
- 村落间的口耳相传积累了大量「反常事件」数据
- 寺庙是跨区域信息交汇点，外乡人带来各地见闻
- 除魔驱邪从业者通过来求助的外乡人积累超自然经验
- 长期观察可以拼凑出超自然存在的**行为模式**（而非本质）

**GM 判定规则：** 玩家主动进行信息收集行为时（走访、交谈、倾听），GM 应提供碎片化的线索。单个线索价值有限，但多个线索组合后可能产生有意义的推断。

### 6.3 矛盾信息利用

**原理：** 在特定条件下，凡人可以获得针对超自然存在的洞察优势。

**触发条件（满足任一即可）：**
- **矛盾信息**：超自然存在给出的信息与凡人已知事实矛盾
- **破绽暴露**：超自然存在在维持伪装时出现不一致
- **利益冲突暴露**：两个超自然存在的说法相互矛盾，暴露至少一方在说谎

**GM 判定规则：** 当上述条件满足时，玩家可获得针对该特定交互的洞察加值（+2 到 +5，由 GM 根据破绽严重程度判定）。这是凡人在信息博弈中少数能获得主动权的时刻。

### 6.4 神的盲区

**原理：** 封神后对凡间人际关系、情感博弈的理解归零。这不是偶尔的疏忽，而是**系统性的结构弱点**。

**具体盲区清单：**

| 盲区 | 表现 | 凡人可利用方式 |
|------|------|--------------|
| 情感动机 | 神只能理解利益驱动，无法理解情感驱动 | 用情感逻辑做出神无法预测的行为 |
| 社会网络 | 神不理解凡人社会的非正式权力结构（宗族、人情债、面子） | 利用社会关系网实现神预料之外的资源调动 |
| 非理性忠诚 | 神无法理解为什么凡人会为不产生任何利益的对象效忠 | 通过「不合理」的忠诚行为制造神的误判 |
| 微观人际 | 神管理宏观秩序，对个体间的复杂关系几乎不关注 | 在神的注意力盲区中行动 |

**GM 判定规则：** 当玩家的行动明确利用了以上盲区时，GM 应在叙事中体现神的困惑或误判。但注意：神虽然不理解情感逻辑，仍然可以通过暴力或权力压制凡人。优势是战术性的，不是战略性的。

## 七、凡神反比（Mortal-Divine Inverse Ratio）

> **核心设计规则。** 所有 GM Agent 在判定博弈结果时必须参照本法则。

### 7.1 定义

凡人的**物质状态**与玩家博弈结果的**状态**成反比。

**关键澄清：** 这里的衡量标准是「状态」，不是「好」或「差」。没有好差之分，只有状态的方向性。

### 7.2 运作逻辑

```
物质状态上升 → 博弈结果状态下降
物质状态下降 → 博弈结果状态上升
```

**具体表现：**

| 物质状态 | 博弈结果状态 | 场景举例 |
|---------|------------|---------|
| 获得财富、安稳、权力 | 失去选择自由、陷入更深的依附、被更大的棋局套住 | 接受了土地神的「赐福」→ 庄稼丰收 → 但从此被绑定在香火经济中无法脱身 |
| 失去财产、流离失所、身陷险境 | 获得信息、打开新路径、获得更真实的认知 | 被迫逃离村庄 → 路上遇到流浪的贬谪仙 → 获知了关键真相 |
| 社会地位提升 | 被更多势力注意、成为棋子、行动空间反而缩小 | 成为村长 → 被多方势力拉拢 → 每个选择都得罪人 |
| 社会地位下降 | 脱离关注、获得隐蔽行动空间 | 沦为乞丐 → 没人注意 → 反而能自由行动、收集信息 |

### 7.3 GM 运用指南

**校准博弈结果时的检查清单：**

1. 玩家在本次博弈中，物质状态发生了什么变化？
2. 按凡神反比法则，博弈结果状态应向相反方向偏移
3. 偏移的幅度应与物质状态变化的幅度大致成比例
4. 偏移不是惩罚或奖励 — 是世界运转的客观规律
5. 向玩家呈现时，不要直接说明法则，而是通过叙事自然体现

**禁止事项：**
- 不可用凡神反比作为惩罚玩家「玩得太好」的工具
- 不可让玩家感到「无论怎么做都一样」— 反比的具体表现应取决于玩家的选择方向
- 物质状态和博弈结果状态的变化应有因果合理性，不可强行套用公式

## 八、信念侵蚀（Faith Erosion）

> **核心设计规则。** 与认知突破构成本游戏最核心的张力对。

### 8.1 定义

凡人获知越多关于世界真相的信息，其盲目信念越薄弱。

### 8.2 关键澄清：这不是负面效果

信念侵蚀**不是惩罚**，而是一个转化过程：

```
盲目信仰（未经检验的信念）
  → 获取信息 → 盲目信仰动摇
    → 继续获取信息 → 盲目信仰瓦解
      → 如果还能做出选择 → 这个选择基于真实认知
        → 这就是「最后的信念」— 比盲目信仰更真实、更有重量
```

**核心理念：** 更真实的信念取代盲目信仰。知道了神在制造苦难还选择供奉，与不知道神在制造苦难而供奉，是完全不同的行为 — 前者是选择，后者是无知。

### 8.3 与认知突破的关系

| 机制 | 定义 | 方向 |
|------|------|------|
| **认知突破** | 获取超越认知边界的信息 | 获得 |
| **信念侵蚀** | 获取信息后盲目信念弱化 | 代价 |

两者构成核心张力：
- 想要更多信息（认知突破）→ 必然承受信念侵蚀
- 想要保持信念完整 → 必须放弃深入了解真相
- 玩家无法两全 — 这就是博弈的核心张力

### 8.4 信念侵蚀等级

| 等级 | 状态描述 | 对玩家的影响 |
|------|---------|------------|
| **0 — 完整信仰** | 对世界的认知完全符合官方叙事（神是仁慈的、天灾是惩罚、供奉有用） | 选项中不会出现质疑性选项；NPC 信任度高 |
| **1 — 微裂** | 遇到了无法解释的矛盾，但仍可以用「自己理解有误」来自洽 | 开始出现隐晦的质疑性选项 |
| **2 — 动摇** | 积累了足够多的矛盾证据，无法再用自洽逻辑解释 | 质疑性选项明确出现；与虔诚 NPC 的关系开始紧张 |
| **3 — 瓦解** | 盲目信仰已经无法维持，但尚未建立新的信念体系 | 处于信念真空状态；抉择时可能出现「虚无」选项 |
| **4 — 重建** | 在真相基础上重新构建信念 — 可能是更深的信仰，也可能是彻底的务实主义 | 最终抉择的选项和叙事呈现将反映重建后的信念方向 |

### 8.5 GM 运用指南

- 信念侵蚀等级随玩家获取关键信息自然推进，不需要显式告知玩家
- 在叙事中通过NPC反应、内心独白选项、可选行动来隐式体现等级变化
- **最终抉择（场景高潮/结局）** 时，信念侵蚀等级直接影响可用选项的种类和叙事呈现方式
- 等级 4 的「重建」方向由玩家在整个游戏过程中的选择倾向决定，GM 不应预设方向

## 九、信息可达性规则（Information Accessibility Rules）

定义不同层级信息对凡人的获取条件。GM 在判定「玩家能否获得某信息」时，以此表为依据。

### 9.1 信息分级表

| 信息类别 | 可达性 | 获取条件 | 举例 |
|---------|--------|---------|------|
| **天庭内部运作** | 凡人绝不可知（硬限制） | 无合法路径。即使通过泄露获得片段，也无法理解完整逻辑 | 天数的具体内容、封神仪式细节、灵蕴分配规则 |
| **天庭对外政策** | 极难获知 | 需要贬谪仙或叛逃神主动泄露（见第十节路径 4） | 天庭对某区域的管控策略、招安/剿灭决策 |
| **灵蕴机制** | 极特殊条件 | 长期观察 + 特殊经历 + 高洞察值检定（DC18+） | 灵蕴的存在、香火与神力的关系 |
| **苦难制造** | 困难 | 亲身经历反常天灾 + 信息拼图（DC15） | 意识到「天灾」可能是人为的 |
| **神的不可测谎性** | 困难 | 与神有过直接交互 + 事后发现矛盾（DC15） | 意识到神可以毫无破绽地说谎 |
| **妖的存在** | 中等 | 亲身经历或一手目击者转述（DC12） | 确认妖怪是真实存在的 |
| **妖的行为模式** | 中等 | 多次遭遇 + 信息交叉（DC12） | 特定妖怪的活动规律、弱点 |
| **神的存在和基本职能** | 简单 | 公共知识，无需检定 | 土地公管本地、城隍管亡魂 |
| **寺庙传闻** | 简单 | 前往寺庙交谈（DC8） | 外乡人的见闻、附近的异常事件 |

### 9.2 硬限制与软限制

- **硬限制**（标记为「绝不可知」）：无论玩家做什么、骰值多高，都无法获得完整信息。最多获得碎片，且碎片本身可能被误解
- **软限制**（标记为「困难」「极难」等）：理论上可获得，但需要满足条件并通过检定。失败不代表信息不存在，只代表这次没获取到

## 十、信息泄露路径（Information Leak Paths）

> **游戏性的核心来源。** 如果信息只按层级规则流动，凡人永远无法获得任何有价值的信息。游戏的乐趣来自信息的「非正常流动」。

### 10.1 五条泄露路径

#### 路径 1：下级神的失控泄露

**触发条件：** 下级神（土地、山神、河神）在醉酒、愤怒、恐惧等失控状态下口误。

**信息质量：** 片段性，可能不完整或被情绪扭曲。

**可获得内容：** 上级的具体指令、区域管控计划、其他神的秘密。

**GM 判定：** 玩家需要 (1) 在场 (2) 识别出这是有价值的信息（洞察检定 DC12）(3) 记住内容。下级神事后会否认或试图灭口。

#### 路径 2：妖怪之间的生存情报网

**触发条件：** 妖怪为了生存互相交换天庭动向、安全区域、猎食范围等信息。

**信息质量：** 经验性的，基于多次观察但不理解底层原因。

**可获得内容：** 天庭巡逻规律、哪些区域最近「不安全」、其他妖怪的下落。

**GM 判定：** 凡人需要与妖建立某种非对抗关系才能接入此网络。风险极高 — 妖可能利用凡人，凡人也可能被其他妖当作猎物。

#### 路径 3：寺庙/祠堂的跨层级信息交汇

**触发条件：** 寺庙作为凡人、低级神、偶尔的妖都会接触的场所，天然成为信息交汇点。

**信息质量：** 混杂的 — 真假难辨，需要玩家自己甄别。

**可获得内容：** 外乡人的见闻、僧侣的观察、供奉仪式中的异常现象、神像的反常反应。

**GM 判定：** 寺庙信息获取的 DC 较低（DC8-10），但信息可信度需要额外的洞察检定来判断。

#### 路径 4：贬谪仙的故意泄露

**触发条件：** 被天庭贬谪的仙，出于报复、不甘、或对凡人的同情，主动向凡人透露信息。

**信息质量：** 高质量，但带有强烈的个人偏见和报复动机。信息本身可能是真的，但叙述角度被扭曲。

**可获得内容：** 天庭的运作逻辑（部分）、封神的真实代价、灵蕴的存在。

**GM 判定：** 这是凡人获取高层级信息的最佳路径，但极为稀有。贬谪仙有自己的目的 — 可能想利用凡人作为对抗天庭的棋子。玩家需要判断信息的可信度和贬谪仙的真实动机。

#### 路径 5：超自然存在冲突时的双向泄露

**触发条件：** 两个超自然存在发生冲突时，双方可能向凡人透露对手的秘密，以争取凡人的支持或破坏对手的信誉。

**信息质量：** 关于对手的部分高度准确（因为攻击需要精确），但关于自身的信息会被美化或隐瞒。

**可获得内容：** 对手的弱点、真实身份、过去的劣迹、利益关系。

**GM 判定：** 这是凡人获取信息的最佳时机之一。当两个超自然存在打架，凡人反而成了双方都想争取的对象。但风险也最高 — 选错边可能被赢家清算。

### 10.2 泄露路径通用规则

- 所有泄露路径获得的信息都应通过信息传播失真规则（第十一节）进行处理
- 泄露者事后可能采取行动消除泄露（灭口、记忆操纵、威胁）
- 玩家获得泄露信息后，如何使用该信息本身就是一个博弈决策

## 十一、信息传播失真规则（Information Distortion Rules）

### 11.1 基础失真率

每次信息转述，都会产生失真。失真不是随机噪声，而是有方向性的偏移。

**失真公式（概念模型，非精确数学）：**
```
转述后信息 = 原始信息 + 转述者动机偏移 + 随机噪声
```

### 11.2 动机偏移

NPC 在传递信息时，会基于自身动机进行**定向偏移**：

| 动机类型 | 偏移方向 | 举例 |
|---------|---------|------|
| **自保** | 隐瞒对自己不利的部分 | 土地神不提自己制造过旱灾 |
| **邀功** | 夸大自己的贡献 | 除魔者夸大妖怪的实力来抬高自己 |
| **恐惧** | 夸大威胁程度 | 经历过妖袭的人描述得比实际更恐怖 |
| **利益** | 引导听者做出对自己有利的判断 | 商人夸大某路线的危险来垄断另一条路的生意 |
| **善意** | 隐瞒可能引起恐慌的部分 | 村长隐瞒妖的真实数量以免引起混乱 |

### 11.3 传播衰减

| 传播层级 | 信息可信度等级 | GM 处理方式 |
|---------|-------------|-----------|
| **一手（直接目击）** | 最高可信度 | 信息基本准确，仅受目击者自身认知水平限制 |
| **二手（认识目击者）** | 较高可信度 | 信息大致准确，但已经过一次动机偏移 |
| **三手及以上** | 自动降为「传闻」 | 信息结构可能正确但细节严重失真；可能有完全虚构的部分 |

### 11.4 GM 判定规则

- 当玩家获取信息时，GM 应在内部标记该信息的层级（一手/二手/传闻）
- 向玩家呈现信息时，通过叙事语言暗示可信度等级（「你亲眼所见」vs「张三说他听李四提过」）
- 玩家可以通过洞察检定尝试识别信息中的偏移方向（DC 因偏移隐蔽程度而异）
- 玩家主动交叉验证多个信息源时，应给予额外的洞察加值（+2）

## 十二、洞察值的世界观锚点（Insight Value: Lore Anchor）

### 12.1 世界观解释

洞察值在世界观中对应两种来源：

- **边界认知的微弱裂缝**：部分凡人天生对认知边界的感知更敏锐，能隐约感觉到「事情不对」，即使无法说出具体哪里不对
- **对灵蕴的微弱感应**：极少数凡人对灵蕴有微弱的感知能力，这种感知不足以操纵灵蕴，但足以在信息交互中获得额外的「直觉」

这两种来源都不是超自然能力，而是凡人天性中的微弱变异。

### 12.2 核心机制：D20 + 洞察修正值

所有信息交互使用统一的检定系统：**D20 + 洞察修正值 vs DC（难度等级）**

**三种信息交互类型：**

| 类型 | 描述 | 举例 |
|------|------|------|
| **主动获取** | 玩家主动寻求信息 | 询问 NPC、搜查房间、观察异常 |
| **被动甄别** | 判断已获得信息的真伪 | 识别谎言、评估传闻可信度 |
| **信息保护** | 防止自己的信息被他人获取 | 隔墙有耳检定、伪装意图 |

### 12.3 基础 DC 范围

| 难度 | DC | 适用场景举例 |
|------|-----|------------|
| **简单** | 8 | 寺庙公开传闻、NPC 明显的谎言、表面信息 |
| **中等** | 12 | 妖的存在确认、NPC 隐藏的动机、二手信息验证 |
| **困难** | 15 | 苦难制造的察觉、神的真实态度、妖怪行为模式分析 |
| **极难** | 18 | 灵蕴机制的感知、天庭政策推断、多层欺骗识别 |
| **近乎不可能** | 22+ | 天数的碎片感知（仅在极特殊叙事条件下出现） |

### 12.4 洞察修正值来源与范围

**范围：-2 到 +5**

| 修正值 | 来源描述 |
|--------|---------|
| **-2** | 认知被严重干扰（恐惧、迷惑术、信息过载） |
| **-1** | 轻微不利条件（疲劳、分心、陌生环境） |
| **+0** | 普通凡人基准 |
| **+1** | 有一定人生阅历或社交经验 |
| **+2** | 长期从事信息敏感职业（商人、除魔者、僧侣） |
| **+3** | 经历过认知突破（信念侵蚀等级 1+） |
| **+4** | 经历过多次超自然事件 + 主动信息收集者 |
| **+5** | 极罕见。对灵蕴有微弱感应的天赋凡人，或经历深度认知突破者 |

**动态修正（叠加于基础值之上）：**
- 矛盾信息利用（第六节 6.3）：+2 到 +5
- 多信息源交叉验证：+2
- 对特定 NPC 的长期观察：+1 到 +3
- 信念侵蚀等级提升时：永久 +1（每提升一级）

### 12.5 检定结果分档

| 结果 | 条件 | 效果 |
|------|------|------|
| **完全成功** | 骰值 >= DC + 5 | 获得完整信息 + 额外洞察（如信息提供者的动机） |
| **成功** | 骰值 >= DC，且差值 < 5 | 获得核心信息，但可能遗漏细节或背景 |
| **失败（无后果）** | 骰值 < DC，且差值在 1-4 之内 | 未获得信息，但对方不知道你在探查 |
| **灾难性失败** | 骰值 < DC - 4（即差值 5+） | 未获得信息 + 对方意识到你在探查 + 可能触发敌意反应 |

**GM 注意：** 灾难性失败不意味着玩家角色死亡或立即陷入绝境。它意味着信息博弈的态势发生了不利变化 — 对方知道你在打探，会调整自己的策略。

## 十三、骰子与随机性的世界观解释（Dice & Randomness in Lore）

### 13.1 核心问题

在一个「天数」决定一切的世界中，随机性意味着什么？如果所有事件都按宇宙剧本进行，骰子结果从何而来？

### 13.2 世界观解释：天数的微观模糊性

**天数管控宏观事件，不管控微观事件。**

天数规定了大的走向：取经必须完成、悟空必须被镇压 500 年、天庭的秩序必须维持。但天数不覆盖每一个凡人的每一次对话、每一个决定、每一次遭遇的具体结果。

骰子结果是**天数在微观层面的模糊表达**：
- 天数留下了「余地」— 在宏观轨迹不变的前提下，微观事件的具体展开有多种可能
- 骰子掷出的结果，就是这种微观模糊性的具象化
- 凡人的博弈空间，正是存在于这片模糊地带之中

### 13.3 设计意义

这个解释服务于两个设计目标：

1. **保持世界观一致性**：天数不是假的，宏观事件确实按剧本进行。但游戏的可玩性存在于微观层面
2. **赋予玩家行动意义**：虽然你改变不了大局，但你在微观层面的每个选择都是真实的。骰子结果体现了这种「有限但真实的自由」

### 13.4 GM 运用指南

- 当玩家问「这有什么用，反正天数已定」时，通过叙事（不是直接说教）体现：天数管的是河流的方向，不是每一滴水的轨迹
- 骰子结果应被叙述为「命运的微妙转向」「事情恰好如此发生」，而不是「你运气好/差」
- 在叙事高潮时刻，骰子结果可以被描述为「天数留下的一线缝隙」— 凡人正是从这道缝隙中争取到了存在的意义

### 信息交互检定流程

```
1. 确定交互类型（主动获取 / 被动甄别 / 信息保护）
2. 确定 DC（参照 12.3 基础 DC 表 + 场景调整）
3. 检查特殊规则：
   - 对神测谎？→ 自动失败（第五节）
   - 满足矛盾信息条件？→ 加值（第六节 6.3）
   - 信息层级是否允许？→ 参照第九节
4. 投掷 D20 + 洞察修正值（参照 12.4）
5. 对比结果分档（参照 12.5）
6. 对获得的信息应用传播失真规则（第十一节）
7. 更新信念侵蚀等级（如果获得了关键信息，参照第八节）
8. 检查凡神反比（如果博弈产生了物质状态变化，参照第七节）
```

### 核心法则优先级

当规则冲突时，按以下优先级处理：

1. **玩家体验优先** — 规则服务于体验，不是体验服务于规则
2. **神的不可测谎性** — 硬规则，不可被任何加值或能力覆盖
3. **信息可达性硬限制** — 标记为「绝不可知」的信息不可通过任何检定获得
4. **凡神反比** — 在判定博弈结果时始终参照
5. **信念侵蚀** — 在玩家获得关键信息后始终更新
6. **其他规则** — 按具体场景灵活运用
