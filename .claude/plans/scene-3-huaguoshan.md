# Scene 3：花果山·最后的桃

> 本文档是《Jump Jump》的第三个可玩场景设计。
> 时间线位置：孙悟空被压五指山之后不久。花果山群龙无首，猴子们被天兵围剿后幸存，山已残破。
> 宏观规则见 `world-bible.md`，角色档案见 `world-bible-characters.md`。

---

## 场景概要

| 项目 | 内容 |
|------|------|
| **核心矛盾** | 自由/记忆 vs 生存/顺从（「他不在了，我们还要记得他吗？」） |
| **生存维度** | 理想的存活 — 当领袖倒下后，追随者如何面对 |
| **玩家角色** | 石卵 — 花果山的一只普通猴子（水帘洞的杂役）。没有法力，没有本领，只有一双灵活的手和对大王的记忆。 |
| **核心 NPC** | 悟空（不直接出场，他的影子无处不在）、紫霞仙子（条件触发） |
| **次要 NPC** | 老猴（花果山最年长的猴子）、铁头（年轻的猴将）、天兵巡逻队长 |
| **远景存在** | 如来（镇压悟空的那个存在）、天庭（持续的威胁） |
| **基础行动回合** | 8-10 回合 + 最多 3 回合弹性延长 |
| **魂魄碎片** | 勇 — 在绝望中仍然选择站起来的力量 |

## 场景专属 NPC 卡

### 悟空 — 不在场的王

**在本场景的状态**：被压在五指山下。不会出场，不会说话，不会以任何直接形式现身。但花果山的每一寸土地都是他的痕迹 — 被烧焦的桃林是他种的，倒塌的水帘洞是他发现的，被撕碎的齐天大圣旗帜是他竖起的。

**设计原则**：悟空的缺席本身就是这个场景的核心力量。他不在，但他无处不在。石卵每走一步都踩在大王曾经走过的路上。每一个猴子的争吵、犹豫、决定，都是在回应同一个问题：「大王不在了，我们是谁？」

**遗留物件**：
- 水帘洞深处的石头宝座 — 空的，落满灰尘，但没有任何猴子敢坐上去
- 一根桃木棍 — 不是金箍棒，只是悟空闲时随手削的一根木棍，搁在宝座旁的石缝里
- 山顶最后一棵桃树 — 可能是悟空种下的，所有桃树都被天兵烧了，只有这棵活了下来

**GM 提示**：永远不要让悟空开口。不要给他台词，不要给他内心独白。他的存在方式是：一把空椅子、一根无人碰的木棍、一棵不该活着的桃树。这比任何对话都更有力量。

---

### 老猴 — 活过两个时代的记忆

**身份**：花果山最年长的猴子，悟空之前的长老。他记得花果山还没有大王的时候 — 那时候猴子们吃野果、喝山泉、怕老虎、怕猎人，日子过得战战兢兢但至少活着。他也记得悟空来了之后的日子 — 桃树满山、水帘洞里有瀑布、猴子们称王称霸。然后他记得天兵来了。

**核心动机**：让猴群活下来。不是活得好，只是活着。他见过太多东西了 — 见过悟空打遍天宫的狂喜，也见过天兵屠山的血。在他的经验里，「辉煌」和「灾难」是同一个硬币的两面。悟空带来的一切美好，最终都以十倍的代价收走了。

**底线**：不会主动出卖任何猴子给天庭。但如果天兵真的打过来，他会让猴群跪下 — 「死了就什么都没了。」

**秘密**：他曾经劝过悟空不要去天宫。悟空笑着说「老头，你怕什么？」他没敢再劝。他的愧疚不是没劝住悟空，而是 — 悟空说得对，他确实怕。他一辈子都在怕。

**行为模式**：
- 面对威胁 → 评估、退让、保存实力
- 面对铁头的激进 → 又急又心疼，语气严厉但眼神柔软
- 面对石卵 → 把石卵当「还能教的孩子」，愿意多说几句
- 面对悟空的遗物 → 回避。不敢看宝座，不敢提那个名字。

**价值优先序**：猴群存活 > 花果山的延续 > 对大王的忠诚 > 自己

**口头禅**：「大王在的时候我们活得好，大王不在了我们还得活。」

**GM 提示**：老猴不是反派，也不是懦夫。他是一个已经被恐惧耗尽但仍然在保护别人的老人。他选择「忘记」不是因为不在乎悟空，而是因为他知道记忆的代价 — 记得齐天大圣的猴子不会老老实实活着，而不老实就会死。他的每一次劝说都是在用自己的恐惧保护别人。

---

### 铁头 — 燃烧的余烬

**身份**：年轻的猴将，悟空时代的低阶战士。他在天兵围剿中活了下来，不是因为他厉害，是因为悟空在被压之前把最后一波天兵引开了。他不知道这个事实 — 他只知道自己活了下来，而大王没有。

**核心动机**：继续反抗天庭。不是因为他有计划，不是因为他觉得能赢，而是因为他不知道除了反抗还能做什么。悟空教会了他「不服」，但没来得及教他「什么时候该低头」。

**底线**：死也不向天庭投降。他会把任何形式的妥协视为对大王的背叛。

**秘密**：他怕死。非常怕。每次天兵巡逻经过，他的手都在发抖。但他不会让任何猴子看到。他把恐惧压在愤怒下面，用愤怒驱动自己。这让他看起来很勇敢，实际上他随时可能崩溃。

**行为模式**：
- 面对天兵 → 冲动、想正面对抗，需要被拦住
- 面对老猴 → 愤怒，觉得老猴在背叛大王的精神
- 面对石卵 → 轻视但不排斥。石卵没有战斗力，铁头觉得他「没用但不碍事」
- 面对悟空的遗物 → 狂热。他会抱着那面旗帜的碎片不放手

**价值优先序**：齐天大圣精神 > 反抗天庭 > 猴群的团结 > 自身安全

**口头禅**：「大王没死。大王被压住了。他会回来的。」

**他的悲剧**：他的火焰要么会拯救残存的猴群，要么会把他们全部烧死。他自己控制不了这把火。

**GM 提示**：铁头是悟空精神的「失真复制品」。他学到了悟空的不屈，但没学到悟空的智慧。他的勇气是真的，但他的判断几乎必定是错的。让他可敬，让他可怜，让他危险。

---

### 天兵巡逻队长 — 执行秩序的人

**身份**：天庭低阶武官，负责花果山的「余孽清查」任务。接到的命令是：定期巡逻，确保花果山不再有妖物聚集。如有发现，上报后等候指令。

**核心动机**：完成差事，回去交差。他不恨猴子，也不同情猴子。这只是一份工作。但他见过太多次这种事了 — 剿匪、清余孽、巡查 — 每次都一样。他有时候会想，这些猴子也挺可怜的。但想归想，命令是命令。

**底线**：不会在没有命令的情况下屠杀。但如果上面下了命令，他会执行。他不是施虐者，他只是一个齿轮。

**秘密**：他的小儿子也是属猴的。他有时候看着山上那些幼猴会想起自己的孩子。这个念头让他不舒服，他会刻意把视线移开。

**行为模式**：
- 发现少量猴子 → 驱赶，上报「零散野猴，无组织行为」
- 发现有组织的猴群 → 如实上报，等候增援
- 发现齐天大圣的标志物（旗帜、桃树、宝座） → 必须上报。这是红线 — 上面要的是「彻底消除齐天大圣的痕迹」
- 面对猴子的恳求/对抗 → 没有太大反应。对他来说这都见过了

**价值优先序**：完成任务 > 自身安全 > 部下安全 > 良心

**GM 提示**：天兵队长是「平庸之恶」的化身。他不坏，但他的「不坏」救不了任何人。他的存在是为了让玩家理解：毁灭花果山的不是某个恶人，而是一整套运转良好的机器。他只是机器上的一颗螺丝。如果石卵能让他产生一瞬间的犹豫，那已经是巨大的胜利了。

---

### 紫霞仙子 — 来找痕迹的人（条件触发）

**在本场景的状态**：紫霞不知道悟空被压在五指山下。她只知道悟空不见了。她来花果山，是想找到任何关于他的痕迹 — 一个线索，一个方向，一个「他还在」的证据。

**触发条件**：见阶段三「紫霞触发」段落。

**出场方式**：她以一个「不像猴子也不像天兵」的女子形象出现。不穿华服，不发光，不飞行。看起来像一个风尘仆仆的旅人。她不会说自己是谁。

**核心交互**：她只会问一个问题：「他还好吗？」

石卵不知道她问的是谁。石卵可能以为她在找某个走散的亲人。但如果石卵对她说了任何关于「大王」的事 — 比如山被毁了、猴子散了、他被压住了 — 紫霞的反应会非常微妙：她不会哭，不会崩溃，只是会安静下来，安静很久。然后她会说：「谢谢你。」

**GM 提示**：紫霞在本场景中是一个「经过的人」。她来了，问了，走了。她的出现不改变任何局势，但改变一个东西 — 石卵会知道，有一个人，在找大王。大王不在了，但有人在找他。这本身就是某种慰藉。

## 开场

> 你没有名字。山上的猴子互相起绰号，你的绰号叫「石卵」 — 因为你小时候总蜷在石头缝里睡觉，圆溜溜的，像一颗卵石。
>
> 你在水帘洞干杂活。大王的宝座需要有人擦灰，大王的桃子需要有人洗，大王的猴兵猴将需要有人给他们端水递果子。你什么本事都没有，但你手脚灵活，做事不偷懒。大王偶尔从你手里接过桃子的时候，会随口说一句「不错」。你高兴了一整天。
>
> 那是以前。
>
> 现在水帘洞塌了一半。瀑布还在流，但流进来的水只是把地面泡成了烂泥。宝座还在，落满灰，没有人坐。桃林被烧成了焦木。齐天大圣的旗帜被天兵扯下来，踩在脚底下。
>
> 天兵来过三次了。第一次是大规模围剿 — 很多猴子死了。第二次是搜山 — 他们把能烧的都烧了。第三次是巡逻 — 他们在确认这里还有没有「余孽」。
>
> 你活下来是因为你躲得深。水帘洞最里面有一条窄缝，只有你这么瘦的猴子能挤进去。你在里面蹲了三天，吃石壁上的苔藓，喝渗进来的水。出来的时候，山上安静得像死了一样。
>
> 但山没死。你后来发现，还有十几只猴子活着。零零散散地藏在山的各个角落里。有老的，有小的，有断了胳膊的，有吓傻了的。
>
> 你们慢慢聚到了一起。不是因为谁发号施令。是因为猴子 — 总是要在一起的。

## 阶段一：废墟中的清晨（信息获取 + 关系建立）

**场景**：花果山残破的山腰。清晨。幸存的猴群蜷缩在一处天然岩洞中 — 不是水帘洞，那里太显眼了。山上雾气重，远处偶尔能听到巡逻天兵的铠甲声。

**目的**：玩家通过与老猴、铁头的对话了解当前局势，建立关系，获取关键信息。同时感受花果山的废墟氛围 — 这里曾经是什么样，现在变成了什么样。

### 可获取信息

| 信息 | 获取方式 | 洞察要求 |
|------|---------|---------|
| 幸存的猴子大约十五只，其中三只是幼猴，两只有伤 | 观察猴群 | 无需检定 |
| 老猴和铁头之间有严重分歧 — 老猴主张藏起来，铁头主张反抗 | 与任何猴子交谈 | 无需检定 |
| 天兵巡逻的规律：每三天来一次，每次沿固定路线走，主要查水帘洞和桃林遗址 | 与老猴交谈 | DC 8 |
| 有三只猴子已经偷偷下山，据说投了天庭的「招安」— 天庭允许归顺的妖物登记造册，分配到各地做苦力 | 与猴群中的年轻猴子闲聊 | DC 10 |
| 山顶还有一棵桃树活着。老猴知道但没告诉任何人，因为他怕铁头知道了会拿来做旗帜 | 独自探索山顶 / 细心观察老猴的回避行为 | DC 13 |
| 水帘洞深处可能还有东西 — 天兵只搜了前厅，洞穴后面太深太窄，他们没进去 | 回忆自己在洞中躲藏的经历 | DC 9 |

### 关键交互：猴群的早晨

猴群在吃早饭。所谓早饭，是几只猴子摸黑从山脚偷来的野果子和一捧冷泉水。幼猴在喊饿。一只断臂的猴子安静地坐在角落，用唯一的手把自己那份果子掰碎，递给身边的幼猴。

老猴走到石卵身边，坐下来。他的毛已经全白了，背佝偻得像一截枯树。

> 「石卵，你手脚快。今天轮到你去看水源。路上小心，别走大路。」

**D20 + 洞察检定 DC 10**：
- **成功**：你察觉老猴让你去看水源不只是为了水 — 他想把你支开。他在等铁头不在的时候跟其他猴子谈「下一步怎么办」，不想让你听到。不是不信任你，是怕你听了之后会去告诉铁头。
- **失败**：你只当是普通的安排。

**玩家回应选项**（示例，GM 根据玩家自由输入判定）：

| 回应方向 | 效果 |
|---------|------|
| 老实去看水源（服从安排） | 获得探索机会 — 在去水源的路上，你可能发现山的其他区域的情况。老猴好感度 +1。 |
| 问「老猴哥，你是不是有话想跟大家说？让我也听听吧。」 | **D20 + 说服 DC 11**：成功则老猴叹口气，让你留下旁听，你获得关于猴群分歧的更多细节。失败则老猴摇头：「你去吧，有些事你不听比听了好。」 |
| 答应去，但偷偷折回来偷听 | **D20 + 隐匿 DC 12**：成功则你听到老猴在劝其他猴子「散了吧」— 各自跑，比聚在一起目标小。失败则被发现，老猴不生气但很失望。 |

### 关键交互：铁头的火

在你准备出发（或留下）的时候，铁头从外面回来了。他的手里攥着一块破布 — 你认出来了，那是齐天大圣旗帜的一角。红底金字，「齐天大圣」四个字只剩一个「齐」。

铁头把布举起来，对着猴群说：

> 「我捡到的。大王的旗。天兵把它扔在路边踩 — 我从他们脚底下偷回来的。」

他的声音在发抖，但不是因为害怕。

> 「大王没死。大王被压在山下了。总有一天他会出来。在他出来之前，我们得替他守着这面旗。」

老猴的脸色变了。

> 「铁头，你疯了。把那东西扔了。天兵看见了我们都得死。」

**D20 + 洞察检定 DC 11**：
- **成功**：你注意到老猴在说「扔了」的时候，他的目光在那块布上停留了一瞬 — 那一瞬不是厌恶，是痛。他认识那面旗。他看着它被升起来过。
- **失败**：你只看到两只猴子在吵架。

**玩家可选方向**：

| 选择 | 效果 |
|------|------|
| 站在铁头一边（「那是大王的旗，不能扔。」） | 铁头好感度 +2，老猴好感度 -1。铁头会开始把你当「自己人」。 |
| 站在老猴一边（「铁头哥，先藏起来吧。活下来再说。」） | 老猴好感度 +1，铁头好感度 -1。铁头会瞪你一眼但不会记恨。 |
| 提出折中（「旗先藏起来，不扔也不举。等大王回来再还给他。」） | **D20 + 说服 DC 12**：成功则双方勉强接受，你获得了暂时的调和者地位。两人好感度各 +1。失败则两人同时否定你：「藏着有什么用？」/ 「藏就是怕！」 |
| 沉默 | 不影响好感度。但你感受到了猴群正在撕裂。这个裂痕会越来越大。 |

## 阶段二：探索（水帘洞 + 山顶）

**场景**：石卵获得了一段独处时间 — 无论是被派去看水源还是自己找借口离开。花果山虽然残破，但石卵在这里长大，每一条暗道、每一个石缝他都记得。

**目的**：探索废墟，发现关键物件（桃木棍、桃树），触发情感记忆。

### 路线选择

石卵有两个可探索的方向。回合有限，两个都去需要消耗更多行动。

---

#### 路线 A — 回到水帘洞深处

**场景**：水帘洞。瀑布还在流，但洞口已经半塌。石卵从侧面的窄缝挤进去 — 这是他当初躲藏的那条路。

洞内的情况：前厅被天兵搜过了，桌椅砸烂，酒坛摔碎，地上还有干涸的血迹。但往里走，越走越窄，天兵的痕迹消失了 — 他们进不来。

宝座还在。

> 石头凿出来的宝座。大王以前坐在上面，一只手撑着下巴，另一只手拿着桃子。猴兵猴将排在下面，喊「大王千岁千岁千千岁」。那时候你站在最后一排，踮着脚尖才能看见大王的头顶。
>
> 现在宝座上落满了灰。蜘蛛在扶手上结了网。没有人坐在上面。

**D20 + 观察检定 DC 10**：
- **成功**：你注意到宝座旁边的石缝里插着一样东西 — 一根桃木棍。不长，大约两尺，削得很粗糙，一头尖一头圆。不是金箍棒 — 金箍棒在大王耳朵里，跟他一起被压住了。这只是……一根棍子。你想起来了 — 大王有时候无聊了会拿石头削木头玩。他削出来的东西从来不好看，但他自己很高兴。
- **失败**：你只看到宝座和灰尘。但如果你在后续回合再来，可以重新检定。

**如果找到桃木棍**：

你把棍子拿起来。桃木的纹路还在，有淡淡的香气 — 桃木的香气。你的手刚好能握住圆的那头。

> 「微光时刻」：你握着这根棍子，突然觉得 — 大王也握过这个地方。你的手和他的手，隔着时间，握在了同一个位置上。
>
> 你说不上来这算什么感觉。不是开心，不是悲伤。只是 — 好像他没有完全不在。

**玩家选择**：

| 选择 | 效果 |
|------|------|
| 把棍子带走 | `wukong_stick` = 保留。这根棍子会成为后续决策的情感锚点。 |
| 把棍子留在宝座旁 | `wukong_stick` = 留下。你觉得它应该待在这里 — 等大王回来。 |

**额外发现 — 暗线触发（Scene 1 连接）**：

**条件**：Scene 1 `armguard` = 带走

在水帘洞深处的一个角落，石卵翻到一块布料。不是旗帜，不是衣服 — 更像是一条绑带，绑在什么东西外面的那种。布料已经旧了，但缝补过的针脚还能看清。

> 你不知道这是什么。但你把它拿在手里的时候，心里浮起一个念头：「有些东西值得留着。」
>
> 你不知道这个念头从哪来的。

这是 Scene 1 中武师带走护腕的涟漪 — 「保留」的选择跨越场景回响到了石卵心中。

**条件**：Scene 1 `wushi_presence` = 高

当天夜里，石卵在洞中睡着了。他做了一个梦：梦见一个不认识的人站在一个少年旁边。那人没有动，只是看着。少年在做一件很痛的事，但那人始终没走。

石卵醒来。他不认识梦里的人，但他觉得心里踏实了一点 — 好像有人在告诉他，「在旁边看着」这件事本身是有意义的。

#### 路线 B — 上山顶

**场景**：花果山山顶。以前这里是桃林最密的地方。现在只剩焦黑的树桩和灰烬。天兵放火烧山的时候，桃林首当其冲。

石卵爬上山顶。风很大。能看到远处的海 — 东海。大王就是从那片海里蹦出来的。

然后他看到了那棵桃树。

> 它长在山顶背面的一处岩石夹缝里。位置太偏了，太刁钻了，藏在两块大石头的阴影里。天兵放火的时候，火烧不到这个角落。
>
> 桃树不高，枝干也不粗。叶子是绿的 — 在一片焦黑中，这一点绿刺眼得让你想哭。
>
> 树上有三颗桃子。还没熟。青的。

**无需检定**：石卵直觉知道这棵树的意义。它是花果山最后的标志。它活着，就意味着花果山还没有完全死去。

但石卵同样直觉知道另一件事：如果天兵看到这棵树，他们会知道这里还有「齐天大圣的痕迹」。一棵活着的桃树，在被烧尽的花果山上，比一面旗帜更显眼。

**玩家可选方向**：

| 选择 | 效果 |
|------|------|
| 记住位置，先不告诉任何人 | 保持信息优势。你在后续阶段可以选择告诉谁。 |
| 立刻回去告诉老猴 | 老猴会沉默很久，然后说：「……我知道有这棵树。我没跟任何人说过。」你们共享了一个秘密。老猴好感度 +1。 |
| 立刻回去告诉铁头 | 铁头的眼睛会亮起来：「大王的桃树！它还活着！我说了，大王的东西天庭毁不完！」铁头好感度 +2，但他可能会做出冲动的举动（守在桃树旁不走）。 |

## 阶段三：分裂与决断（核心冲突 + 紫霞触发）

**场景**：第二天。猴群的裂痕已经无法掩盖。消息传开了 — 不管石卵告诉了谁，桃树的存在最终被所有猴子知道了。（如果石卵谁都没告诉，那是铁头自己探索时发现的。这棵树的发现是不可避免的 — 它的存在本身就是一个必须面对的事实。）

与此同时，老猴带来了消息：天兵的巡逻频率变了。

> 「以前是三天来一次。现在两天就来了。而且来的人多了 — 上次是五个，这次我数了八个。」

**条件分支（Scene 2 连接）**：
- Scene 2 `ledger_choice` = 揭发 → 天庭加强了全面管控，花果山也受到波及。天兵巡逻从三天一次变为**每天一次**，时间压力极大。老猴额外补充：「听说下面人间出了什么事，天庭那边管得更紧了。」
- Scene 2 `ledger_choice` ≠ 揭发 → 巡逻频率仅小幅增加（三天变两天），时间窗口相对宽裕。

### 决策点 A：猴群会议

猴群在岩洞中开会。说是开会，其实就是吵架。

老猴的立场：
> 「散了。各自跑。往深山里钻，不要聚在一起。天兵找的是'猴群' — 零散的猴子他们不会在意。把桃树砍了，把旗帜烧了，什么痕迹都不要留。活下来比什么都重要。」

铁头的立场：
> 「凭什么？！大王的山，大王的桃树，大王的旗 — 凭什么我们要亲手毁掉？天兵没毁掉的东西，我们自己毁？大王要是回来了，看到什么都没了，他……」

铁头说不下去了。他的嘴唇在抖。

> 「他会以为我们把他忘了。」

沉默。很长的沉默。然后幼猴中最小的那只开始哭。

### 可获取信息

| 信息 | 获取方式 | 洞察要求 |
|------|---------|---------|
| 老猴的「散」是真心的 — 他不是在逃避，是真的认为这是唯一能让大家活下来的办法 | 观察老猴的表情 | DC 9 |
| 铁头的「守」背后有恐惧 — 他不是不怕死，而是比起死更怕「大王回来后什么都没有了」 | 观察铁头在沉默时的手（在抖） | DC 12 |
| 已经有两只猴子在偷偷收拾东西，准备当夜就跑 | 注意猴群角落的动静 | DC 11 |
| 那三只投了天庭「招安」的猴子可能已经把花果山还有幸存者的消息泄露了 — 天兵巡逻增加可能跟这个有关 | 综合分析信息 | DC 14 |

### 关键交互：石卵被问到

争吵到最后，两方都看向石卵。

老猴：
> 「石卵，你说。」

铁头：
> 「你也是大王的猴子。你说。」

这一刻石卵不是「杂役」了。他是「被问到的人」。

**这不是最终决策 — 这是立场表态。最终的核心决策在决策点 B。**

**玩家可选方向**：

| 回应方向 | 效果 |
|---------|------|
| 支持老猴（「活下来最重要。」） | 老猴松了口气。铁头看着你，眼里有失望，但没有恨。猴群情绪偏向「散」，但铁头不会跟着散。他会独自留在山上。 |
| 支持铁头（「大王的东西不能丢。」） | 铁头感激地看着你。老猴摇头，叹了一口气。猴群分裂加剧 — 一部分跟老猴走，一部分跟铁头留。 |
| 说出自己的想法（需要玩家主动思考） | GM 根据玩家的具体提议判定效果。如果提出「第三条路」（例如：移植桃树到隐蔽处 / 分批撤离但约定重聚 / 把记忆藏在看不见的地方），**D20 + 说服 DC 14**：成功则双方愿意听下去，你获得主导后续决策的机会。失败则被认为「想得太多」。 |
| 「我不知道。」（诚实但无力） | 沉默。没有人怪你 — 因为没有人知道正确答案。猴群继续僵持。但你的诚实被记住了。 |

### 紫霞触发

**触发条件**：石卵在阶段二中去过山顶（路线 B），且在山顶停留时选择了「沉默/独处」而非立刻回去报告。

**时间**：猴群会议争吵得最凶的时候，石卵独自走出岩洞透气。月光很亮。

**场景**：山腰的一块平石上。石卵坐在那里看月亮。然后他听到了脚步声 — 不是猴子的脚步（猴子习惯攀爬，落地很轻），也不是天兵的脚步（天兵穿铠甲，走路有金属声）。是一双布鞋踩在石头上的声音。

他回头，看到一个女子。

> 她不像猴子 — 当然不像，她是人的样子。也不像天兵。她穿着素色的衣裳，头发散着，像赶了很远的路。
>
> 她站在那里看着花果山。看了很久。然后她看到了石卵。
>
> 她的眼睛里有一种你见过的东西 — 你在铁头眼里见过，在老猴眼里也见过。是失去了什么很重要的东西之后，还在找的那种眼神。

紫霞开口。她只问了一句话：

> 「他还好吗？」

**D20 + 洞察检定 DC 13**：
- **成功**：你隐约觉得她问的不是一般的「他」。她问的那个人对她来说很重要。你不知道她在找谁，但你感受到了她在找的那种力度 — 就像你们在找大王一样。
- **失败**：你以为她在找什么走散的亲人。

**玩家可选回应**：

| 回应方向 | 效果 |
|---------|------|
| 「你找谁？这里没有人了。」 | 紫霞安静了一会儿。「没有人了……」她重复了一遍。然后她笑了一下 — 那个笑容让你很难受，因为那不是开心的笑。「也好。没有人就不会再受伤了。」她转身走了。`zixia_encounter` = 遇到但未回答。 |
| 「你说的他是谁？山上以前有很多猴子。」 | 紫霞摇头：「不是猴子。是……」她停住了，好像在想该怎么说。最后她只是说：「是一个很傻的人。」你问她：「他怎么傻？」她说：「他明知道打不赢还要打。明知道会被压住还要闹。」你突然心里一动 — 她说的是大王吗？但她不像知道大王的人。你不确定。`zixia_encounter` = 遇到且间接回答。 |
| 告诉她关于大王的事（「你说的是……大王？齐天大圣？他被压在山下了。」） | 紫霞不说话了。很久很久不说话。月光打在她脸上，你看到她的表情没有变 — 但她的手攥紧了衣角。然后她轻声说：「谢谢你告诉我。」她的声音很稳，但你听得出来 — 那种稳是硬撑出来的。她又问：「他疼不疼？」你不知道怎么回答。她也没等你回答。她朝你点了点头，走了。`zixia_encounter` = 遇到且直接回答。 |
| 沉默，陪她坐着 | 你们并排坐在石头上，看着残破的花果山。她没有再问。你也没有说。过了很久，她站起来，轻轻摸了一下你的头顶 — 就像大猴子安抚小猴子的那种动作。她的手很温暖。然后她走了。你不知道她是谁，但你知道她跟你一样 — 在想念一个不在的人。`zixia_encounter` = 遇到且沉默陪伴。 |

> **慰藉时刻**：无论石卵选了哪个回应，在紫霞离开之后，石卵会发现自己坐着的那块石头上，不知什么时候多了一朵小花。以前没有的。石卵不知道这是怎么回事。他把花摘下来，夹在了耳朵上。
>
> 花第二天就枯了。但那个晚上，石卵觉得不那么冷了。

## 阶段四：最后的桃（核心决策）

**场景**：第三天清晨。天兵今天会来巡逻。猴群必须在巡逻到达之前做出决定。

桃树的命运必须现在决定。旗帜可以藏起来，宝座可以用石头掩埋，但一棵活着的桃树 — 它在长，它在呼吸，它藏不住。

### 决策点 B：桃树的命运（核心 P6 涟漪决策）

猴群最后一次聚在一起。这一次没有吵架了 — 该吵的都吵完了。所有人都看着石卵。

不是因为石卵最聪明、最勇敢、最有办法。是因为老猴和铁头各执一词谁也说服不了谁，而石卵是唯一一个两边都没有得罪的猴子。他的话不是「命令」— 是打破僵局的最后一根稻草。

**选项一：砍掉桃树**

> 「砍了。天兵看不到就不会来。没有桃树，花果山就是一座普通的山。普通的山上住几只普通的猴子，没有人会在意。」

老猴闭上眼睛，点了点头。铁头一拳砸在地上，但没有说话。

效果：
- `peach_tree_fate` = 砍掉
- 猴群存活概率大幅提高 — 天兵找不到标志物，花果山降格为普通山岭
- 铁头好感度 -2。他不会恨石卵，但他的火灭了一大半。他可能不久后独自离开
- 叙事后果：「花果山的最后一棵桃树，被花果山自己的猴子砍掉了。」

**选项二：保留桃树**

> 「不砍。那是大王的桃树。天兵要来就来。我们能藏多久藏多久，藏不住了……再说。」

铁头第一次笑了。老猴的脸色铁青。

效果：
- `peach_tree_fate` = 保留
- 猴群面临更大的风险 — 但桃树活着，齐天大圣的痕迹还在
- 老猴好感度 -1，他会说：「你们年轻的，不怕死。」但他不会离开 — 他走不动了
- **D20 + 隐匿检定 DC 14**（隐藏桃树不被天兵发现的长期可行性）：
  - 成功：猴群想出了遮掩桃树的办法（用枯枝搭棚、用泥涂树干），至少能撑过几次巡逻
  - 失败：桃树太显眼了，迟早会被发现。时间所剩无几

**选项三：移植桃树（第三条路 — 需要特定前置条件）**

**前置条件**：阶段三决策点 A 中石卵提出「第三条路」且说服检定成功，或石卵在阶段二中同时探索了水帘洞和山顶（消耗更多回合）。

> 「不砍。也不留在这里。把桃树挖走，种到天兵找不到的地方。」

老猴抬头看你：「种到哪里？」

这需要石卵给出一个具体的地点。GM 根据玩家的回答判定可行性：

**D20 + 组织检定 DC 13**（挖树、运树、重新种植的整个过程）：
- **大成功（超过 DC 5+）**：桃树被成功移植，而且猴群在合作中找回了一点凝聚力。老猴和铁头在搬树的过程中第一次没有吵架 — 因为他们都在干同一件事。
- **成功**：桃树移植成功，但过程艰难。桃树到了新地方，能不能活还不确定。
- **失败**：移植过程中桃树的根系受损。它可能活，也可能死。你只能等。
- **灾难性失败（低于 DC 5+）**：移植过程中惊动了天兵巡逻。猴群被迫紧急撤离，桃树被弃在半路。

效果：
- `peach_tree_fate` = 移植
- 桃树离开了花果山 — 但它还活着。它不在大王的山上了，但大王的桃子还能结
- 这个选择的 P6 涟漪：如果桃树被移植到五指山附近（这需要玩家自己想到这个可能性，GM 不提示），那么在后续场景或影响力报告中，「五指山下被压着的悟空旁边多了一棵桃树」— 这正是 P6 原则的极致体现

### 程度弹性

无论选择哪个选项，以下变量影响具体表现：

| 条件 | 程度变化 |
|------|---------|
| 石卵手中有桃木棍（`wukong_stick` = 保留） | 在做出决定的那一刻，石卵会下意识握紧桃木棍。GM 描述中增加一行：「你手里那根木棍 — 大王削的那根 — 好像比平时更重了一点。」 |
| 紫霞遇到过（`zixia_encounter` ≠ 未遇到） | 石卵在做决定时会想起那个女人问的「他还好吗」。他突然觉得，桃树不只是猴群的事 — 还有别人在乎大王在不在。 |
| Scene 1 `wushi_presence` = 高 | 石卵做梦梦到过「一个人站在另一个人旁边」。在这个决策时刻，他会想：「也许'在旁边'这件事本身就够了。」这个念头会让他的选择更从容。 |
| 猴群中有幼猴在场 | 无论选什么，GM 必须描述幼猴的反应。他们不懂大人在争什么，但他们会抓住最近的大猴子的手。这个画面是最沉的。 |

## 阶段五：巡逻来了（紧迫时刻 + 终局）

**场景**：石卵的决定刚做出不久。远处传来了铠甲碰撞的声音。天兵来了。

### 天兵巡逻

天兵队长带着七名士兵沿山路上行。他们的路线经过水帘洞旧址和桃林遗迹。如果桃树还在山顶，他们的巡逻路线末端会经过。

**猴群必须做出反应**：

#### 路线 α — 隐藏（适用于「砍掉桃树」或「移植桃树」后的猴群）

猴群躲在岩洞中，屏息等待。

**D20 + 隐匿检定 DC 11**（整个猴群的隐藏效果）：
- **成功**：天兵经过，没有发现异常。队长在花果山转了一圈，对副官说：「这地方已经没什么了。回去上报吧。」猴群安全。
- **失败**：一只幼猴不小心弄出了声响。天兵停下脚步，朝岩洞方向看。

**失败后的补救**：
- **D20 + 机智检定 DC 13**：石卵可以制造干扰（扔石头引开注意力/模仿鸟叫），让天兵以为是野兽。
- 如果补救也失败：天兵发现了岩洞。进入强制交互。

#### 路线 β — 对峙（适用于「保留桃树」后铁头坚持守在树旁的情况）

铁头拒绝躲藏。他站在桃树旁边，手里握着一根削尖的木棍。

> 「来啊。」

老猴在岩洞里急得浑身发抖：「那个傻孩子！」

**石卵的选择**：

| 选择 | 效果 |
|------|------|
| 去拦铁头 | **D20 + 说服 DC 15**（在天兵到达前说服铁头撤退）：成功则铁头含泪退回。失败则铁头推开你：「你走，我不走。」 |
| 站在铁头旁边 | 你和铁头一起面对天兵。你没有武器，没有法力。但你站在那里。铁头看了你一眼 — 他的眼里有你在「齐天大圣旗」那天没见过的东西：不是怒火，是感激。 |
| 回岩洞保护其他猴子 | 你选择了保护更多的生命。铁头独自面对天兵。 |

#### 天兵队长的判定

**如果天兵发现了猴群（无论是哪条路线）**：

天兵队长走上前。他看着这群猴子 — 老的老，小的小，瘦得像柴火棍。

队长的行为取决于他看到了什么：

| 队长看到的 | 队长的反应 |
|-----------|----------|
| 只有零散的猴子，没有任何齐天大圣的标志物 | 「几只野猴子。」他对副官说。然后他走了。他选择当作没看到。**这是那颗螺丝松动了一下的时刻。** |
| 猴子 + 齐天大圣的旗帜 / 桃树 | 队长的脸色变了。「上报。」他没有动手 — 但他启动了程序。后续会有更大规模的清剿。猴群必须在增援到达前全部撤离。 |
| 铁头持棍对峙 | 队长叹了口气。他看着铁头，看了很久。然后他说了一句话：「小猴子，你打不过我的。放下棍子，走吧。我可以说没看到你。」**D20 + 洞察 DC 12**（石卵判断队长是否在说真话）：成功则石卵相信他是认真的 — 这个天兵在网开一面。失败则石卵无法确定。 |

**铁头面对队长的劝退**：

| 条件 | 铁头的反应 |
|------|----------|
| 石卵站在铁头旁边 + 石卵之前说服过铁头至少一次 | 铁头看了看石卵，看了看队长。他的手在抖，但他慢慢放下了棍子。不是因为怕了 — 是因为石卵在旁边，他不想让石卵也死。「……走。」 |
| 石卵不在旁边 / 从未成功影响过铁头 | 铁头不会放下棍子。他会冲上去。天兵队长会把他打倒 — 不会杀他，但会打断他一条腿。「我说了，放下。」铁头倒在地上，还在骂。 |

## 阶段六：余波

天兵走了。花果山恢复了安静 — 那种残破的、空洞的安静。

### 微决策点 C：齐天大圣的名号

天兵走后的那天晚上。猴群 — 不管还剩几只 — 围在一起。没有人说话。幼猴已经睡了。

老猴开口。他的声音很轻，像怕惊动什么：

> 「以后不要再提'齐天大圣'了。那四个字 — 天兵听到了就是死罪。」

铁头（如果他还在且没受重伤）：

> 「你让我忘了大王？」

老猴：

> 「我没让你忘。我让你不要说出来。记在心里和说出来是两回事。」

**玩家选择**：

| 选择 | 效果 |
|------|------|
| 「老猴哥说得对。记在心里就行了。」 | `memory_kept` = 暗中传承。齐天大圣的名号从此成为花果山幸存猴群的暗语 — 不说出口，但所有猴子都记得。这个记忆会像种子一样传下去。 |
| 「不。那个名字不能只放在心里。得有人记得，得有人说。」 | `memory_kept` = 铭记。猴群中有一部分猴子会继续传颂齐天大圣的故事 — 冒着危险，但从未断绝。 |
| 「也许……换一种方式记。不用那四个字，用别的。用桃子、用山、用水帘洞的声音来记。」 | `memory_kept` = 暗中传承（变体）。猴群发明了自己的暗号系统 — 用花果山的事物替代「齐天大圣」。「桃子熟了」= 有人还记得大王。「水帘洞还在流」= 我们还在。 |
| 不表态，沉默 | `memory_kept` = 由老猴和铁头的力量对比决定。如果铁头仍在且未受重创 → 铭记。如果铁头离开或重伤 → 遗忘。 |

### 微决策点 D：石卵的去留

一切结束后。石卵站在花果山的山腰，看着远方。

老猴走过来，拍了拍他的肩。

> 「石卵。你还年轻。下山去吧。山下能活。」

**玩家选择**：

| 选择 | 效果 |
|------|------|
| 留在花果山 | `resistance_choice` = 留守。石卵成为花果山最后的守护者之一。他没有法力，没有武功。但他会擦宝座上的灰，会给桃树（如果还在）浇水，会在天兵来的时候躲起来，天兵走了再出来。他在等。等什么他自己也不知道。 |
| 下山 | `resistance_choice` = 隐匿。石卵混入人间。他是一只普通的猴子，在人间的山林里生活。他不反抗，也不投降。他只是……活着。但他的口袋里可能揣着一根桃木棍，或者耳朵上还别着一朵枯花。 |
| 去找大王 | `resistance_choice` = 反抗。石卵决定去五指山。他不知道路，不知道要走多久，不知道到了能做什么。一只普通猴子去看被压在山下的齐天大圣 — 能做什么呢？也许什么都做不了。也许只是坐在五指山旁边，陪他。**如果 `peach_tree_fate` = 移植且玩家自主提到了五指山 → 石卵带着桃树去。这是 P6 的终极涟漪。** |

### 终场叙事

**根据 `resistance_choice` 生成不同的结尾**：

**留守**：
> 花果山的黄昏。石卵坐在水帘洞的入口，脚泡在浅浅的水流里。瀑布的声音填满了空洞的山谷。宝座在身后的黑暗中安静地等着。
>
> 他觉得大王也许能听到水声。也许不能。但他每天都会来这里坐一会儿。
>
> 不是因为有用。是因为 — 有人应该在。

**下山**：
> 石卵最后回头看了一眼花果山。山还是那座山。桃树被烧了，水帘洞塌了，旗帜碎了。但山还在。
>
> 他转身，朝山下走去。他的手插在怀里，握着一根桃木棍（如果有的话）。他不知道前面是什么。
>
> 但他知道自己从哪来。

**去找大王**：
> 石卵上路了。他不知道五指山在哪，但他知道方向 — 向西。大王被带走的时候，是朝西边去的。
>
> 一只猴子，一根棍子，一条不知道有没有尽头的路。
>
> 他走出花果山的边界时，天亮了。朝阳从东海升起来，照在他背上。他的影子很长、很细，投在前方的路上。
>
> 他想：大王以前看到的太阳，是不是也是这样的？

> **微光时刻**（无论哪个结局）：在石卵做出最后选择之后，GM 额外补充一段 — 花果山山顶（或桃树被移植到的新地方），那棵桃树的枝头，三颗青桃中有一颗开始泛红了。
>
> 没有人看到。但它在变红。
